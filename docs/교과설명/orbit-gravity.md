### 1장. 이 단원에서 배우는 것 (goal)

**제목**: 위성은 왜 떨어지지 않을까?
**오늘의 질문**: 얼마나 빨리 쏘면 포탄이 땅에 떨어지지 않고 지구를 돌까? 더 빨리 쏘면 어떻게 될까?

**본문 (3문장)**
- 달과 인공위성은 중력에 끌리면서도 지구로 떨어지지 않고 돌아요. 핵심은 옆으로 가는 속력에 있어요.
- 같은 중력으로 높이에 따라 위성의 속력과 주기가 어떻게 달라지는지, 어떤 속력이면 지구를 벗어나는지 알아봐요.
- 행성의 공전 주기와 태양까지의 거리 사이의 규칙도 자료로 확인해요.

**성취기준 칩 `성취기준 3 ▸`**: [12역학01-03] 힘과 운동 방향(원운동) · [12역학01-04] 인공위성·행성 운동(원운동에 한해 정량) · [12역학01-05] 행성마다 다른 탈출 속도.
**얻을 것(3줄)**: ① 위성은 낙하 중 ② *v* = √({{frac:*GM*|*r*}}) ③ 탈출 속도 ④ *T*² ∝ *a*³

**그림**: 지구 중심 (400,260), 반지름 110(채움 primary-tint). 궤도 점선 반지름 170(--sim). 위성(작은 사각형) (400,90), 오른쪽 속도 화살표(청록, 길이 70, 라벨 *v* 끝에서 바깥 10), 아래 지구 중심 방향 **구리 굵은 화살표**(길이 55, 라벨 *F*). 지구 중심에서 위성까지 얇은 선에 *r*, 중심에서 표면까지 짧은 선에 *R*. 상단 중앙에 질문 말풍선(y≈40).
**교사 메모**: 1분. "우주에는 중력이 없다" 같은 예상을 받아 두었다가 10장에 쓴다.

### 2장. 뉴턴의 대포: 떨어지며 돌기 (cannon)

**본문 (3문장)**
- 포탄은 쏜 뒤에 중력만 받아 포물선으로 떨어져요. 속력이 클수록 땅에 닿는 곳이 멀어지고, 둥근 땅이 아래로 휘어요.
- 약 7.9 km/s 면 떨어지는 만큼 땅도 휘어서 포탄이 땅에 닿지 않아요. 위성은 "계속 떨어지는 물체"예요.
- 실험 조건: 공기가 없고, 높이 *h* = 20 km 산(*r* = *R* + 20 km)에서 수평으로 쏴요.

**식·기호 (1~2개)**: *v*₀ 발사 속력(km/s). 지표 부근 원궤도 속력 ≈ 7.9 km/s(제1 우주 속도)
**결과 구간(실험 화면 속력 띠와 같은 말)**: 4·6 km/s 추락 / 7.9 km/s 거의 원궤도 / 10 km/s 타원(지구에서 가장 먼 곳이 *R* 의 약 4배) / 11.2 km/s 이상 탈출.

**그림 — 뉴턴의 대포(모식도, 축척 아님)**: 지구는 큰 원의 윗부분(중심 (400,700) 밖 → 호만 보임). 산꼭대기 (400,170)에 작은 대포. 궤적 네 개: ① 짧은 포물선 "느리게"(추락), ② 더 긴 포물선 "조금 더 빠르게"(추락), ③ 지구를 감싸는 원(점선 굵게) "7.9 km/s: 땅에 닿지 않아요", ④ 바깥쪽 타원(옅은 점선·일점쇄선) "더 빠르게". **오른쪽 위 작은 확대 상자**: 산 높이 *h* = 20 km, 중심에서 산꼭대기까지 *r* = *R* + *h*(그림은 크게 과장, 모식도). 선 모양(실선/점선/일점쇄선)으로 구분하고 라벨은 지시선으로. 오른쪽 아래 범례: 추락 / 궤도 / 타원.

### 3장. 중력은 멀어질수록 약해진다 (inverse-square)

**본문 (3문장)**
- 지구가 위성을 당기는 힘과 위성이 지구를 당기는 힘은 크기가 같고 방향이 반대예요(작용·반작용).
- 중심에서의 거리 *r* 가 2배가 되면 힘은 1/4, 3배면 1/9 로 줄어요. 0 이 되지는 않아요.
- 우주에도 중력이 있어요. ISS 높이(400 km)에서 중력은 지표의 약 89 % 예요.

**식 (2개)**: *F* = {{frac:*GMm*|*r*²}} / 중력 가속도 *g* = {{frac:*GM*|*r*²}}
**3차**: 계기는 *F* 를 지표의 중력과 비교한 %로 보여 줘요(ISS 89 %).
**기호**: *G* 만유인력 상수, *M* 지구 질량, *m* 위성 질량, *r* 지구 중심에서의 거리(*r* = *R* + *h*, *R* = 6,371 km). 지표 *g* = 9.8 m/s², ISS(*r* = 6,771 km) 약 8.7 m/s².

**그림**: 지구 중심 (160,225), 반지름 70. 오른쪽으로 *r*, 2*r*, 3*r*(x=300, 440, 580)에 같은 모양 위성 세 개. 각 위성에서 지구 쪽(왼쪽)을 향한 **구리 굵은 화살표**, 길이 **90 / 22.5 / 10** (1 : 1/4 : 1/9 비). 라벨은 쌓은 분수 *F*, *F*/4, *F*/9 (÷ 표기 폐기). 지구 중심에서 세 위성까지 거리선(점선 수직 안내를 세 위성 아래로 연장, 양끝 화살머리). 오른쪽 아래 빈 자리 요약 칩 "거리 2배 → 힘 1/4".
**[해 보기] 카드 ②** `preset 1` + `set {alt:6400}`: 계기 "중력(지표 대비)" ≈ 25 %, "중심까지 거리" 2.00 *R*. (고도 6,400 km ≈ *r* = 2*R*)
**더 보기**: 달의 중력이 만드는 조석 / 400 km 와 36,000 km 에서 중력 비교.
**교사 메모**: 수식 암기가 아니라 "멀수록 약해지고 0 은 아니다".

### 4장. 원궤도 속력 (orbit-speed)

**본문 (3문장)**
- 원운동을 하려면 중심을 향한 구심력이 필요한데, 위성에서는 중력이 그 힘이에요.
- 중력 {{frac:*GMm*|*r*²}} 와 구심력 {{frac:*mv*²|*r*}} 을 같게 놓으면 *m* 이 양쪽에서 약분돼요. 그래서 속력 *v* 는 위성의 질량 *m* 에는 상관없고, 중심 천체의 질량 *M* 과 거리 *r* 로 정해져요.
- *r* 가 클수록 *v* 가 작고 주기 *T* 가 길어요.

**식 (2개)**: {{frac:*GMm*|*r*²}} = {{frac:*mv*²|*r*}} → *v* = √({{frac:*GM*|*r*}}) / 주기 *T* = {{frac:2π*r*|*v*}}
**조건 칩(3차)**: 원궤도 가정.
**예**: ISS *h* = 400 km → *r* = 6,771 km, *v* ≈ 7.7 km/s, *T* ≈ 92 분. 위성 질량을 100 → 10,000 kg 으로 바꿔도 *v* 는 같아요.

**그림 — 중력 = 구심력**: 왼쪽에 지구 일부와 위성 하나. 중심 방향 구리 굵은 화살표 "중력 *F*", 같은 화살표에 "= 구심력". 오른쪽에 식 상자: 큰 글씨 *v* = √(*GM*/*r*), 기호표(기호/뜻/단위: *v* km/s, *G*, *M* kg, *r* km). 위성 질량 *m* 은 상자에서 **취소선**으로 지워진 모습("약분"). 화살표 길이 눈금 "1칸 = 1 km/s".
**[해 보기] 카드 ②** `preset 1`: mode sat, alt 400, mass 100 → 1,000 → 10,000, gaxis lin. 속력 약 7.7 km/s·주기 약 92분 그대로.
**교사 메모**: 위성 모드에서 질량만 바꾸는 순서 칩(100 → 1,000 → 10,000)과 연결.

### 5장. 높은 궤도일수록 느려요 (orbit-heights) — 4장에서 분리

**본문 (3문장)**
- 높이 올라갈수록 중력이 약해져서 천천히 돌아도 궤도를 지켜요.
- ISS(*h* 400 km)는 7.7 km/s 로 약 92분, GPS 위성(20,200 km)은 3.9 km/s 로 약 12시간, 정지궤도(35,786 km)는 3.1 km/s 로 약 24시간이에요.
- 정지궤도 위성은 지구 자전과 같은 주기라서 적도 위 한 곳에 머물러 보여요.

**식 (1~2개)**: *v* = √({{frac:*GM*|*r*}}), *T* = {{frac:2π*r*|*v*}} (4장과 같은 식을 *r* 만 바꿔 읽기)
**표(3행)**: 이름 | *h* | *r* | *v* | *T* — ISS 400 / 6,771 / 7.7 / 약 92분; GPS 20,200 / 26,571 / 3.9 / 약 12시간; 정지궤도 35,786 / 42,157 / 3.1 / 약 24시간.

**그림 — 높이에 따른 세 궤도(모식도)**: 지구 중심 (260,225) 반지름 70. 세 점선 원 궤도 반지름 100(ISS), 170(GPS), 215(정지궤도). 각 궤도에 위성과 속도 화살표(길이 80 / 55 / 40). **라벨은 궤도 바깥에서 지시선으로**(오른쪽 x≥560 에 세 줄로 정렬): "ISS 7.7 km/s · 약 92분", "GPS 3.9 km/s · 약 12시간", "정지궤도 3.1 km/s · 약 24시간". 라벨 바탕은 옅은 면. 화살표 눈금 "1칸 = 1 km/s".
**[해 보기] 카드 ③** `preset 2`: mode sat, mass 1000, alt 400 → 20,200 → 35,786. 속력 7.7 → 3.9 → 3.1, 주기 92분 → 12시간 → 24시간.
**더 보기(교육과정 밖·정성)**: 에너지를 더해 가속하면 더 높은 궤도로 올라가지만, 새 원궤도에서의 속력은 처음보다 **작아요**. 반대로 공기 저항으로 에너지를 잃으면 궤도가 낮아지며 속력은 커져요.

### 6장. 무중력의 정체 (weightless)

**본문 (3문장)**

- 줄이 끊긴 엘리베이터 안에서 몸이 뜨는 느낌과 같아요. 다만 ISS 는 옆으로 빨라서 떨어져도 땅에 닿지 않고 계속 돌아요.
- "무중력"은 중력이 0이 아니라 바닥이 나를 받치지 않는 상태예요.

**식·기호**: 위성과 우주인의 가속도 모두 *g*′ = {{frac:*GM*|*r*²}} ≈ 8.7 m/s² (ISS). 겉보기 무게 = 0 (받치는 힘 0).

**[해 보기] 카드 ②** → 계기 "중력(지표 대비)" 89 % 확인 후 이 장으로 돌아와 결론 정리.

### 7장. 탈출 속도 (escape)

**본문 (3문장)**
- 위로 던진 공은 다시 떨어지지만 충분히 빨리 던지면 돌아오지 않아요. 그 경계가 탈출 속도 *v*_esc 예요.
- 에너지 보존으로 보면, 처음 운동 에너지 ½*mv*² 가 중력 위치 에너지의 크기 {{frac:*GMm*|*r*}} 이상이어야 해요. 그래서 *v*_esc = √(2*GM*/*r*) 이고, 같은 *r* 에서 원궤도 속력의 √2 배(약 1.41배)예요.
- 천체마다 다르고(달 2.4, 화성 5.0, 지구 11.2, 목성 59.5 km/s), 탈출해도 중력이 0이 되는 건 아니에요.

**식 (2개)**: ½*mv*² = {{frac:*GMm*|*r*}} → *v*_esc = √({{frac:2*GM*|*r*}}) = √2 × *v*(**같은 *r* 에서** 원궤도 속력) / (*r*: 출발점의 중심에서의 거리. 지표에서 쏘면 *r* = *R*)
**구간(속력 띠, 지구 기준)**: *v*₀ < 7.9 추락 / 7.9 ≤ *v*₀ < 11.2 궤도(원 또는 타원) / *v*₀ ≥ 11.2 탈출.

**그림 — 속력 띠와 탈출**: 위쪽 가로 속력 띠(x=60~740, y=120, 높이 40). 0~7.9 옅은 주홍 면 "추락", 7.9~11.2 --sim-tint "궤도", 11.2 이상 회갈색 빗금 "탈출". 눈금 숫자 7.9, 11.2 는 띠 **아래 별도 줄**(띠 밖으로 나오지 않게, 아래 여백 8 이상). 아래쪽 천체 4개 막대(탈출 속도 비례): 달 2.4, 화성 5.0, 지구 11.2, 목성 59.5(막대 끝 꺾임 표시 + 숫자). 천체 아이콘은 실험 천체 칩과 같은 색.
**[해 보기] 카드 ⑤** `preset 4`: mode cannon, v₀ 3, body moon → mars → earth, cview far. 달만 탈출(2.4 < 3).
**더 보기**: 달에 대기가 거의 없는 이유(약한 중력에서 기체가 벗어남).
**교사 메모**: 정량 유도는 ½*mv*² = {{frac:*GMm*|*r*}} 한 줄로 충분.

### 9장. T²과 a³은 같은 비율 (kepler-2)

**본문 (3문장)**
- 주기 *T* 의 제곱과 긴반지름 *a* 의 세제곱을 계산하면 거의 같은 값이 돼요(케플러 제3법칙).
- 그래서 *T*² 대 *a*³ 그래프는 원점을 지나는 기울기 1 직선이에요.
- 원궤도라면 4장의 식에서 같은 결론이 나와요.

**식 (2개)** `관측 규칙`: *T*² ∝ *a*³ (*a* 는 궤도의 긴반지름, 원궤도에서는 *r*) / 원궤도: *v* = √({{frac:*GM*|*r*}}), *T* = {{frac:2π*r*|*v*}} → *T*² = {{frac:4π²|*GM*}} *r*³
**예**: 화성 *a*³ ≈ 3.54, *T*² ≈ 3.54(*a* = 1.524, *T* = 1.881).
**그림 — T²–a³ 그래프**: 가로 *a*³(AU³), 세로 *T*²(년²). 6점이 기울기 1 직선(보조색 점선 "기울기 1") 위. 이름은 8장과 같은 배치. 구석에 작은 표 3행(지구·화성·목성: *a*, *T*, *a*³, *T*²).
**[해 보기] 카드 ④** + `set {gaxis:'sq'}`: 그래프 축을 *T*²–*a*³ 으로.
**더 보기**: 달의 공전 주기로 달 궤도 반지름 구하기.

**오늘 알아낸 것(한 줄, 1차 문장 정정)**: 위성은 중력을 구심력 삼아 계속 떨어지며 돈다. **원궤도 속력은 위성 자신의 질량과는 무관하고, 중심 천체의 질량 *M* 과 중심에서의 거리 *r* 로 정해진다(*v* = √(*GM*/*r*)).** 탈출하려면 천체마다 정해진 속력 *v*_esc 이상이 필요하다.

### 8-2. 정확성·문장 수정
- 1장 본문 "비밀은" → "**핵심은** 옆으로 가는 속력에 있어요".

- 용어표 '탈출 속도': **"같은 *r* 에서 원궤도 속력의 √2 배"**. '제1·제2 우주 속도': 기호 칸 *v*₁, *v*₂(칸 비움 금지), 뜻에 "지표(*r* = *R*) 값 7.9, 11.2 km/s" 를 붙임. 7장 본문 둘째 문장에도 "(같은 *r* 에서)" 삽입.

- 식: *F* = {{frac:*GMm*|*r*²}}, *g* = {{frac:*GM*|*r*²}}, *v* = √({{frac:*GM*|*r*}}), *T* = {{frac:2π*r*|*v*}}, *v*_esc = √({{frac:2*GM*|*r*}}). 용어표·퀴즈 why 의 `/`·`÷` 도 같은 분수로(9.8 ÷ 4 → "9.8 × {{frac:1|4}}").
