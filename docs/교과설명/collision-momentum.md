## 1. 용어·기호 사전 (`glossary`)

| 용어 | 기호 | 단위 | 한 줄 뜻 | 실험 화면 대응 |
|---|---|---|---|---|
| 질량 | *m*₁, *m*₂ | kg | 수레 A, B | 슬라이더 `m1`, `m2` |
| 처음 속도 | *v*₁, *v*₂ | m/s | 충돌 전 속도(오른쪽 +) | 슬라이더 `v1`, ⚙ `v2` |
| 나중 속도 | *v*₁′, *v*₂′ | m/s | 충돌 후 속도 | 기록 표 `v1f`, `v2f` |
| 운동량 | *p* = *mv* | kg·m/s | 질량 × 속도, 방향 있음 | 계기 "운동량 *p* 합(전 → 후)", 탭 "운동량" |
| 운동량 변화 | Δ*p* | kg·m/s | *p*′ − *p* | — |
| 충격량 | *I* | N·s | *F*Δ*t* = Δ*p* | 기록 표 "충격량" |
| 시간 | Δ*t* | s | 힘이 작용한 시간 | 범퍼 칩 `tau`(0.01/0.05/0.2 s) |
| 평균 힘 | *F* | N | {{frac:Δ*p*\|Δ*t*}} | 탭 "힘-시간"(곡선 꼭대기는 최대 힘) |
| 운동 에너지 | *E*_k | J | ½*mv*² | 계기 "운동 에너지 *E*_k 합", 탭 "운동 에너지" |
| 속도 변화 | Δ*v* | m/s | *v*′ − *v* = {{frac:Δ*p*\|*m*}} | — |

구현 지시(용어 통일): ① 실험의 충격량 기호 `J` → ***I***, 계기 'K 보존?' → '*E*_k 보존?', 범퍼 라벨 → "범퍼(부딪쳐 있는 시간 Δ*t*)". ② *v*′(나중 속도)와 Δ*v*(속도 변화)는 서로 다른 말이다 — 해설에 항상 둘을 구분해서 쓴다.
**힘 크기 표기 정리**: 설명의 *F* 는 **평균 힘** = {{frac:Δ*p*|Δ*t*}}(딱딱 200 N, 푹신 10 N). 실험 힘-시간 그래프의 꼭대기는 반 사인 펄스의 **최대 힘**(= π/2 × 평균: 314 N, 15.7 N). 비는 둘 다 20 : 1. 해설 카드가 "최대 힘 314 N"을 말할 때 설명 3장의 "평균 200 N"과 어떻게 다른지 한 줄 덧붙인다(§4).

### 1장. 이 단원에서 배우는 것 (goal)

**제목**: 부딪치면 무엇이 그대로일까?
**오늘의 질문(부제 한 문장)**: 부딪치기 전과 뒤에 안 변하는 것은?

**본문 (3문장)**
- 같은 질량의 수레가 부딪치면 어떻게 될까요? 속도는 크게 바뀌어도 "그대로인 것"을 찾으면 충돌을 예측할 수 있어요.
- 그대로인 것(운동량)과 그대로가 아닌 것(운동 에너지)을 구분해 봐요.
- 부딪치는 순간 서로 주는 힘과, 에어백이 힘을 줄이는 이유도 살펴봐요.

**성취기준 칩 `성취기준 ▸`**: [12물리01-03] 작용·반작용과 운동량 보존을 여러 상황에 적용(탐구: 일차원 충돌에서 운동량 보존 확인).
**얻을 것(3줄)**: ① *p* = *mv* 와 부호 ② 충돌 전후 *p* 의 합이 같다 ③ *E*_k 는 튕기느냐에 따라 다르다

**그림**: 에어 트랙의 두 수레, 충돌 직전과 직후를 위아래 두 줄. 위 줄 "부딪치기 전": 트랙선 y=150, A(--sim, 100×50) x=180~280, 오른쪽 화살표(길이 80, 라벨 "2 m/s" 끝에서 오른쪽 10), B(회갈색) x=480~580 정지 "0". 아래 줄 "부딪친 뒤": 트랙선 y=330, A x=330~430 정지 "0", B x=520~620 + 오른쪽 화살표 "2 m/s". 가운데 말풍선 "그대로인 것은?".
**교사 메모**: 1분. 학생이 "속도가 바뀌었다"를 먼저 말하게 한 뒤 "그대로인 것"으로.

### 2장. 운동량: 움직임의 양 (momentum)

**본문 (3문장)**
- 무겁고 빠른 물체일수록 멈추기 어려워요. 그 정도를 운동량 *p* 라고 해요.
- 운동량의 방향은 속도의 방향이에요. 오른쪽을 +, 왼쪽을 −로 약속해 부호로 방향을 나타내요.
- 속도가 같으면 질량이 큰 쪽이, 질량이 같으면 속도가 큰 쪽이 운동량이 커요.

**식 (2개)**: *p* = *mv* (kg·m/s) / 두 물체의 합 *p* = *p*₁ + *p*₂ (부호 포함해서 더한다)
**예**: 1 kg·+2 m/s → +2. 3 kg·+2 m/s → +6. 1 kg·−2 m/s → −2 kg·m/s.

**그림 — 운동량 막대**: 가운데(x=400)에 굵은 세로선 "0". 오른쪽 +, 왼쪽 −. 세 행: ① 1 kg·+2 m/s → 0 에서 오른쪽 길이 80 라벨 "+2", ② 3 kg·+2 m/s → 길이 240 "+6", ③ 1 kg·−2 m/s → 왼쪽 80 "−2". 각 행 왼쪽에 수레와 속도 화살표(1칸 = 1 m/s). 막대 색은 --sim(+)와 보조색(−), **라벨에 부호를 반드시 적는다**.
**[해 보기] 새 `x-sign`**: mode collide, kind stick, m₁ 1, v₁ 0, **m₂ 2, v₂ −3**(⚙ 더 많은 설정). B 가 왼쪽으로 다가오는 장면; 계기 *p* 합 = −6 kg·m/s. 예측: "B(2 kg, 왼쪽 3 m/s)의 운동량은?" ['+6','−6','−1.5'] answer 2(1부터 센 번호).
**더 보기**: 느린 대형 트럭과 빠른 야구공은 둘 다 멈추기 어렵다.
**교사 메모**: 부호 약속을 칠판에 한 번 적는다.

### 3장. 반대 방향이면 합은? (sign-sum) — 신설

**본문 (3문장)**
- 운동량은 방향이 있는 양이라서 합할 때 부호까지 더해요. 오른쪽 +2 와 왼쪽 −2 를 더하면 4가 아니라 0이에요.
- 합이 0 이면 부딪쳐 달라붙은 뒤 두 수레는 멈춰요. 이때 운동량이 사라진 게 아니라, 처음부터 합이 0 이었던 거예요.
- 합이 0 이어도 각 수레의 *p* 는 0 이 아니고, 운동 에너지는 남아 있다가 열·소리로 바뀌어요.

**식 (2개)**: *p* = *p*₁ + *p*₂ = (+2) + (−2) = 0 kg·m/s / 달라붙으면 (*m*₁ + *m*₂)*v*′ = 0 → *v*′ = 0
**예**: *m*₁ = *m*₂ = 1 kg, *v*₁ = +2, *v*₂ = −2 달라붙기 → *v*′ = 0, *E*_k 4 J → 0 J. 튕기기면 *v*₁′ = −2, *v*₂′ = +2, *E*_k 4 J → 4 J.

**3차**: 그림 제목은 "크기가 아니라 부호까지 더해요"(§0-B).
**그림**: 위 줄: 두 수레가 마주 보며 접근. A(--sim) 오른쪽 화살표 "+2"(길이 80), B(회갈색) 왼쪽 화살표 "−2"(길이 80). 가운데 아래에 운동량 막대 두 개: A 오른쪽 +80, B 왼쪽 −80, 사이에 "합 = (+2) + (−2) = 0". 아래 줄: 붙은 수레 한 덩어리 정지, 라벨 "*v*′ = 0". 큰 글씨 "크기를 더하면 4? ✗ 부호까지 더하면 0 ✓".
**[해 보기] 새 `x-opposite`**: mode collide, kind stick, e 0, tau 0.05, m₁ 1, m₂ 1, **v₁ +2, v₂ −2**. 예측: "A(+2)와 B(−2)가 정면으로 부딪쳐 달라붙으면?" ['오른쪽으로 움직여요','제자리에 멈춰요','왼쪽으로 움직여요'] answer 2. 확인: 합쳐진 수레 정지, *p* 합 0 → 0, *E*_k 4 → 0 J. 이어서 [튕기기로 바꿔 보기](kind elastic): 둘이 속도를 맞바꿔 돌아감, *E*_k 4 → 4 J.
**교사 메모**: "정지하면 운동량이 사라졌나?" 가 이 장의 질문. 정답: 아니다, 합이 처음부터 0(보존).

### 4장. 충격량과 힘 (impulse)

**본문 (3문장)**
- 공을 손을 뒤로 빼며 받으면 덜 아파요. 공의 운동량이 0이 되는 일은 같은데 걸리는 시간 Δ*t* 가 길어졌기 때문이에요.
- 힘 *F* 가 Δ*t* 동안 작용하면 충격량 *I* = *F*Δ*t* 이고, 이것이 운동량 변화 Δ*p* 와 같아요.
- 같은 Δ*p* 에서는 Δ*t* 가 길수록 평균 힘이 작아요. 에어백, 푹신한 매트가 그 예예요.

**식 (2개)**: *I* = *F*Δ*t* = Δ*p* = *mv*′ − *mv* (N·s = kg·m/s) / *F* = {{frac:Δ*p*|Δ*t*}} (평균 힘)
**예(카드 ⑤)**: *m* = 1 kg, *v* = 2 m/s, 벽에서 멈춤 → |Δ*p*| = 2 N·s. 딱딱(Δ*t* = 0.01 s) 평균 힘 200 N, 푹신(0.2 s) 10 N(1/20). 실험 곡선의 꼭대기(최대 힘)는 314 N, 15.7 N 으로 나타나요(평균의 π/2 배, 비는 같음).

**그림 — 힘-시간 그래프 두 개**(3차: 곡선은 반 사인, §0-B): 같은 크기의 좌표계 두 개(가로 *t*, 세로 *F*). 왼쪽 "딱딱한 범퍼": 폭 좁고 키 큰 반 사인 모양, 라벨 "Δ*t* = 0.01 s", 안쪽 --sim-tint 면. 오른쪽 "푹신한 범퍼": 폭 넓고 키 작음 "Δ*t* = 0.2 s", 같은 면 색. 가운데 "= 넓이가 같아요 (충격량 2 N·s)". 아래 작은 일러스트: 벽과 수레, 에어백 단면. (꼭대기 숫자는 적지 않고 "높음/낮음" + 평균 힘 200 N / 10 N 점선 가로선.)
**[해 보기] 카드 ⑤** `preset 4`: mode wall, kind stick, tau 0.01 → 0.2, m₁ 1, v₁ 2. 딱딱·푹신 두 번 기록.
**더 보기**: 에어백·안전띠·낙법·글러브 뒤로 빼기 [12물리01-02] 교통안전. 벽에서 운동량이 변해도 보존이 깨진 게 아니다(5장·오해 4).

### 5장. 바깥 힘이 없으면 합은 일정 (conserve)

**본문 (3문장)**
- 부딪칠 때 두 물체가 서로 주는 힘은 크기가 같고 방향이 반대이고 작용 시간도 같아서, 충격량도 크기가 같고 방향이 반대예요.
- 그래서 A 의 *p* 가 줄어든 만큼 B 의 *p* 가 늘어 합은 그대로예요(바깥 힘이 없을 때).
- 처음에 붙어 있다가 밀어내는 경우(대포)도 같아요. 처음 합이 0 이면 나중에도 0 이에요.

**식 (2개)**: *m*₁*v*₁ + *m*₂*v*₂ = *m*₁*v*₁′ + *m*₂*v*₂′ / `조건` 칩: 알짜 외력 없음(마찰 없는 트랙), 일직선 위의 운동
**예(카드 ④)**: 대포 2 kg, 포탄 0.5 kg, 처음 정지. 포탄 +4 m/s → +2 kg·m/s → 대포 −2 kg·m/s → 대포 속도 −1 m/s(뒤로 1 m/s).

**그림 — 보존 도식**: 위 절반(충돌): 전후 두 줄. 각 줄 오른쪽에 "합 = +2" 큰 라벨(--sim). 전: A +2, B 0. 후: A 0, B +2. 합 막대 하나(전후 같은 길이). 아래 절반(분리): 전: 붙은 두 수레 "합 0". 후: 대포 ← 막대(길이 80, "−2"), 포탄 → 막대(길이 80, "+2"), 사이 "(−2) + (+2) = 0". 모든 막대 "1칸 = 1 kg·m/s".
**[해 보기] 카드 ④** `preset 3`: mode separate, m₁ 2, m₂ 0.5, u 4. 확인: 포탄 +4, 대포 −1 m/s, 합 0 → 0.
**더 보기**: 총의 반동, 보트에서 뛰어내리면 보트가 뒤로, 로켓. 벽: 수레만 보면 *p* 가 변하지만 벽(지구)이 반대로 같은 운동량을 받는다.
**교사 메모**: "보존"은 계의 합이 일정하다는 뜻이지 각 물체의 *p* 가 같다는 뜻이 아니다.

### 6장. 튕기기와 달라붙기 (bounce-stick)

**본문 (3문장)**
- 같은 질량 A(2 m/s)가 정지한 B 에 부딪쳐 튕기면 두 수레가 속도를 서로 바꿔요(A 는 서고 B 는 2 m/s).
- 달라붙으면 합쳐진 수레가 1 m/s 로 가요. *p* 의 합은 2 kg·m/s 로 둘 다 그대로예요.
- 하지만 *E*_k 는 튕기면 2 J → 2 J, 달라붙으면 2 J → 1 J. 줄어든 1 J 은 소리·열·찌그러짐으로 바뀌어요(총에너지는 보존).

**식 (2개)**: 튕기기: *m*₁*v*₁ + *m*₂*v*₂ 일정, *E*_k 합 일정 / 달라붙기: *m*₁*v*₁ + *m*₂*v*₂ = (*m*₁ + *m*₂)*v*′, *E*_k 합 감소
**예(*m* 1 kg 둘, *v*₁ = 2, *v*₂ = 0)**: 튕기기 *v*₁′ = 0, *v*₂′ = 2. 달라붙기 *v*′ = 1. 중간(*e* = 0.5, 심화) *v*₁′ = 0.5, *v*₂′ = 1.5, *E*_k = 1.25 J.

**그림 — 비교 표 + 막대**: 위에 3행×3열 표(열 = 운동량 합 / 운동 에너지 합, 행 = 튕기기 / 중간 / 달라붙기). 칸마다 ○ + "그대로" 또는 ✕ + "줄어듦"(**글자 병행, 색만으로 구분 금지**). 운동량 합 열은 모두 ○. 아래에 에너지 막대: 튕기기 전 2 J → 후 2 J, 달라붙기 전 2 J → 후 1 J(사라진 1 J 부분에 점선 상자 "열·소리").
**[해 보기] 카드 ① → ②** `preset 0`, `preset 1`. 두 번째는 그래프 탭을 "운동 에너지"로.
**더 보기**: 당구공(거의 탄성)과 찰흙(완전 비탄성), 범퍼가 찌그러지며 에너지를 흡수. 반발 계수 *e*(심화): *e* = 1 튕기기, *e* = 0 달라붙기(⚙ `e`).
**교사 메모**: 카드 ① 과 ② 를 이어서.

### 7장. 서로 미는 두 힘 (action-reaction)

**본문 (3문장)**
- 트럭이 승용차를 밀 때 승용차도 같은 크기로 트럭을 밀어요. 누가 더 큰 힘을 받느냐의 답은 "서로 같다"예요.
- 힘도 시간도 같으니 충격량도, 운동량 변화 Δ*p* 의 크기도 같아요.
- 다만 Δ*v* = {{frac:Δ*p*|*m*}} 이라 질량이 작은 승용차의 속도가 훨씬 크게 바뀌어요.

**식 (2개)**: 작용·반작용: 두 힘의 크기가 같고 방향이 반대 / Δ*p*_A = −Δ*p*_B, Δ*v* = {{frac:Δ*p*|*m*}}
**예(카드 ③ 튕기기)**: 트럭 A 3 kg·+2 m/s, 승용차 B 1 kg·−2 m/s. 충돌 후 *v*₁′ = **0**, *v*₂′ = **+4** m/s. 속도 변화: 트럭 Δ*v* = 0 − 2 = **−2**, 승용차 Δ*v* = +4 − (−2) = **+6** m/s. Δ*p*: 트럭 −6, 승용차 +6. *p* 합 4 → 4, *E*_k 합 8 J → 8 J. (**나중 속도 *v*′ 와 속도 변화 Δ*v* 를 구분**: 승용차의 *v*′ 는 +4, Δ*v* 는 +6.)

**그림 — 두 힘 화살표 + Δ*v* 비교**: 윗부분: 큰 사각형 A(트럭, --sim)와 작은 B(승용차, 회갈색)가 접촉. 접촉면에서 A 쪽으로 왼쪽 굵은 구리 화살표 *F*, B 쪽으로 오른쪽 굵은 구리 화살표 *F* — **길이 같음**, 라벨 "같은 크기, 반대 방향". 아랫부분: 속도 변화 막대 한 쌍: A 의 Δ*v* 짧게 왼쪽(길이 40, "−2 m/s"), B 의 Δ*v* 길게 오른쪽(길이 120, "+6 m/s"). 제목 "속도 변화는 가벼운 쪽이 커요".
**[해 보기] 카드 ③** `preset 2`: m₁ 3, v₁ +2, m₂ 1, v₂ −2, kind elastic. 힘-시간 탭에서 두 곡선이 겹침.
**더 보기**: 스케이트보드에서 벽을 밀면 내가 뒤로 / 가벼운 아이와 어른이 서로 밀기.

**오늘 알아낸 것(한 줄)**: 바깥 힘이 없으면 충돌 전후 운동량의 합(부호 포함)은 일정하고, 운동 에너지의 합은 튕기는 충돌에서만 일정하다. 부딪친 두 물체가 서로 주는 힘의 크기는 항상 같다.

**형성평가 3문항**

1. (개념) 수레 B(질량 2 kg)가 왼쪽으로 3 m/s 로 달린다. 오른쪽을 +로 할 때 B 의 운동량은?
   - 보기: ① −6 kg·m/s ② +6 kg·m/s ③ −1.5 kg·m/s
   - **answerIdx 0(①)**. why: *p* = *mv* = 2 × (−3) = −6. 왼쪽이라 부호가 −. `chapter: momentum`. try: `x-sign`.
2. (값 계산) 1 kg 수레 A(+2 m/s)가 정지한 1 kg 수레 B 와 부딪쳐 달라붙었다. 합쳐진 수레의 속도와 운동 에너지의 변화는?
   - 보기: ① 2 m/s, *E*_k 2 J 그대로 ② 1 m/s, *E*_k 2 J → 1 J ③ 1 m/s, *E*_k 2 J 그대로
   - **answerIdx 1(②)**. why: 2 = (1+1)*v*′ 에서 *v*′ = 1 m/s. *E*_k = ½(2)(1)² = 1 J. 줄어든 1 J 은 소리·열로. `chapter: bounce-stick`. try: `preset 1`.
3. (오개념 판정) "무거운 트럭이 가벼운 승용차를 더 큰 힘으로 민다." 옳은 판단은?
   - 보기: ① 맞다. 질량이 큰 쪽이 더 큰 힘을 준다 ② 틀렸다. 승용차가 더 큰 힘을 준다 ③ 틀렸다. 두 힘의 크기는 같고, 달라지는 것은 속도 변화다
   - **answerIdx 2(③)**. why: 작용·반작용으로 두 힘은 크기가 같다. 가벼운 승용차의 Δ*v* 가 더 크다. `chapter: action-reaction`. try: `preset 2`.
   - (정답 위치가 ①·②·③으로 분산되도록 위와 같이 배치. 구현에서 섞더라도 `answerIdx` 를 함께 바꾼다.)

**더 생각하기(교사 공개, 심화·선택)**
- 푹신한 범퍼가 평균 힘을 작게 하는 이유? 정답: 충격량(= 운동량 변화)은 같고 Δ*t* 가 길어지므로 *F* = {{frac:Δ*p*|Δ*t*}} 이 작다. chapter impulse.
- +2 와 −2 가 달라붙어 멈추면 운동량은 어디로 갔나? 정답: 사라진 게 아니다. 처음 합이 0 이라 나중 합도 0. chapter sign-sum.

**교사 [정답 공개]**: 한 번에 + 문항별, 문항마다 "설명 N장 ↩".

## 6. 검증한 값

식: *v*₁′ = {{frac:(*m*₁−*m*₂)*v*₁ + 2*m*₂*v*₂|*m*₁+*m*₂}}, *v*₂′ = {{frac:(*m*₂−*m*₁)*v*₂ + 2*m*₁*v*₁|*m*₁+*m*₂}}. 카드 ③ → *v*₁′ = (4 − 4)/4 = 0, *v*₂′ = (4 + 12)/4 = 4 ✓. 대포 −1 m/s ✓. 벽: 평균 힘 200 / 10 N, 코드의 최대 힘 = π*I*/(2Δ*t*) = 314 / 15.7 N ✓. x-opposite: 4 J → 0 J ✓.

2. **힘 숫자**: 설명 평균 힘(200 / 10 N)과 실험 최대 힘(314 / 15.7 N) 병기 방식(권장: 해설에 "평균의 π/2 배" 한 줄).

### 8-2. 문장·정확성 수정
- 용어표 '튕기기' 정의 비문 수정. 새 문장: "**탄성 충돌 — 운동량의 합과 운동 에너지의 합이 그대로예요**". '달라붙기' 와 같은 문형: "**완전 비탄성 충돌 — 운동량의 합은 그대로이고, 운동 에너지의 합은 줄어요**".
- 1장 부제 한 문장(§0-B). 본문 첫 문장 "같은 질량의 수레가 부딪치면 어떻게 될까요? 부딪치기 전과 뒤에 변하지 않는 것은 무엇일까요?"
- 4장 힘 그림과 본문 수치 일치: 그림 = 반 사인, 최대 힘 = 평균 × π/2(314 N, 15.7 N). 코드·그래프 모양과도 같다(검증 §6).
- 평균 힘 식: *F* = {{frac:Δ*p*|Δ*t*}}, Δ*v* = {{frac:Δ*p*|*m*}}, 정리 문항·해설 why 도 같은 쌓은 분수. 충격량 기호는 *I* 로 통일(실험 `J` → *I*, 계기 'K 보존?' → '*E*_k 보존?').
- 5장 `조건` 칩: "알짜 외력 없음, 일직선 위의 운동".
- 교사 메모(채움): 1장 "'속도가 바뀐다'를 먼저 말하게", 2장 "오른쪽 +, 왼쪽 − 약속을 칠판에", 3장 "정지하면 운동량이 사라졌나? → 합이 처음부터 0", 4장 "에어백: Δ*p* 같고 Δ*t* 길게", 5장 "보존 = 합이 일정, 각 *p* 가 같다는 뜻 아님", 6장 "카드 ①→② 연속", 7장 "힘은 같고 Δ*v* 가 다르다".
- 실험 화면(구현 몫): 실행 전 빈 그래프 자리는 한 줄 "실행하면 그래프가 나와요" 로 낮추고 트랙을 키운다.
