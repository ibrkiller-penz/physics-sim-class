### 1장. 이 단원에서 배우는 것 (goal)

**제목**: 던진 공은 어떻게 움직일까?
**오늘의 질문**: 공을 비스듬히 던지면 날아가는 동안 속도와 에너지는 어떻게 바뀔까?

**본문 (3문장)**
- 손을 떠난 공에는 중력만 작용해요(공기 저항은 일단 무시). 이때 공의 길이 왜 포물선인지 식으로 말해 봐요.
- 얼마나 멀리·오래 가는지는 *v*₀, *θ*, *h* 로 정해져요.
- 날아가는 동안 *E*_k 와 *E*_p 는 서로 바뀌지만 합 *E* 가 어떻게 되는지도 알아봐요.

**성취기준 `성취기준 3 ▸`(접힘, 누르면 펼침)**: [12역학01-02] 뉴턴 운동 법칙으로 포물선 운동을 정량적으로 설명하고 역학적 에너지를 구한다. / [12물리01-04] 역학적 에너지 보존. / 연계 [12물리01-05] 열로 바뀌어도 총에너지 보존(정성, 7장).

**이 장에서 얻을 것(3줄)**: ① 수평과 수직을 따로 생각하기 ② 최고점에서도 가속도는 *g* ③ *E* 가 일정해지는 조건

**그림**: 땅선 y=380(회갈색 2), 발사점 (100,380), 최고점 (400,150), 착지점 (700,380). 궤적 점선(--sim 2). 발사점에 속도 화살표(위 45°, 길이 70, 라벨 *v*₀ — 화살 끝 오른쪽 위 10 띄움). 최고점에 수평 화살표(길이 60, 라벨 *v*ₓ 를 화살 **위** 14), 아래 구리 굵은 화살표(길이 40, 라벨 *g* 오른쪽). 질문 말풍선은 그림 위쪽 중앙(y≈60).
**교사 메모**: 1분. 학생 예상을 손들기로 받아 9장 예측과 잇는다.

### 2장. 한 번에 두 가지 운동 (two-motions)

**본문 (3문장)**
- 옆으로 가는 방향에는 힘이 없어서 속도 *v*ₓ 가 변하지 않아요. 이런 운동이 등속도 운동이에요.
- 아래위 방향에는 중력이 늘 작용해서, 가속도 *g* 가 일정한 등가속도 운동이에요.
- 두 운동은 서로 영향을 주지 않아서, 옆으로 던져도 떨어지는 시간은 그냥 떨어뜨릴 때와 같아요.

**식 (2개)**: 수평 *x* = *v*ₓ *t* (*v*ₓ 일정) / 수직 *y* = *h* + *v*_{y0} *t* − ½ *g t*²(위를 +)
**기호**: *x* 수평 위치(m), *y* 높이(m), *t* 시간(s), *g* 중력 가속도(m/s²), *h* 던지는 높이(m). 대응은 §2.

**그림 — 섬광 사진 두 줄**: 땅선 y=390, 왼쪽 절벽 상단 (80,110). 던진 공(--sim, 반지름 10) 7개를 0.1 s 간격으로 (80,110)→(160,114)→(240,128)→(320,152)→(400,186)→(480,230)→(560,284). 떨어뜨린 공(회색)은 x=80 고정, y 가 같은 값. 같은 높이 두 공을 가는 점선으로 이어 "같은 높이" 라벨. 아래: "옆으로: 같은 간격 →", "아래로: 점점 벌어짐 ↓"(실험 섬광 사진과 같은 모양).

**[해 보기] 카드 ①** `preset 0`: planet earth, air off, h 20, v₀ 10, θ 0, cmp·flash·shadow 켬. 예측 창은 카드 ① 질문으로.
**후속(해설 카드 끝)**: "이제 *v*₀ 를 20 m/s 로 바꿔 다시 실행해 봐요. 비행 시간 *T* 는 2.02 s 그대로, 수평 거리만 2배(20.2 → 40.4 m)예요." → [v₀ 20 으로 해 보기]: `preset 0, set {v0:20}`.

**더 보기(접힘)**: 생활 속 예 — 책상 모서리에서 구슬을 굴릴 때와 떨어뜨릴 때 소리가 거의 같이 들린다 / 물대포 물줄기.
**교사 메모**: 결론 "속도를 키워도 떨어지는 시간은 그대로". 그림자(⚙ 바닥·벽 그림자)로 수평·수직 따로 보기.

### 3장. 속도를 둘로 나누기 (split-v)

**본문 (3문장)**
- 던지는 각이 *θ* 이면 처음 속도의 수평 성분은 *v*₀ cos*θ*, 수직 성분은 *v*₀ sin*θ* 예요.
- *v*ₓ 는 내내 같고, *v*_y 는 1초마다 *g* 씩 줄다가 0이 된 뒤 아래로 커져요.
- 최고점에서는 *v*_y = 0 이지만 *v*ₓ 가 남아 있어 속도는 0이 아니고, 가속도는 그때도 아래로 *g* 예요.

**식 (2개)**: *v*ₓ = *v*₀ cos*θ* (일정) / *v*_y = *v*₀ sin*θ* − *g t*
**기호**: *v*₀ 처음 속력(m/s), *θ* 던지는 각도(°), *v*ₓ 수평 속도, *v*_y 수직 속도, *t* 시간. (최고점은 *v*_y = 0, 이때 *t* = {{frac:*v*₀ sin*θ*|*g*}} — 더 보기)

**그림 — 속도 벡터 분해**: 궤적 점선, 발사점 (120,370), 최고점 (400,140), 착지점 (680,370). 발사점: *v*₀ 실선 화살표(45°, 길이 100), 아래에 *v*ₓ(점선, 길이 70)·*v*_y(점선, 길이 70)로 직각삼각형, 각도 호 *θ*. 최고점: 수평 화살표 *v*ₓ(길이 70) 하나, 라벨 "*v*_y = 0, *v*ₓ 그대로", 구리 굵은 화살표 *g*(길이 45). 착지점: 아래 45° 화살표(길이 100, "처음과 속력 같음(같은 높이)"). 하단 눈금 "화살표 길이 = 속도 크기".

**[해 보기] 카드 ⑤** `preset 4`: v₀ 20, θ 45, topStop·showV·showA 켬. 확인: 최고점에서 *v*ₓ ≈ 14.1 m/s 화살표는 남고 가속도 화살표는 아래 *g*.
**더 보기**: 생활 속 예 — 농구 슛에서 공이 림 위에서 느려 보이는 것은 *v*_y = 0 이라서 / 동영상 분석 탐구(프레임별 위치 읽기).

### 4장. 얼마나 멀리, 얼마나 오래 (range)

**본문 (3문장)**
- 땅에서 던져 같은 높이로 돌아오면, 올라가는 시간과 내려오는 시간이 같아요.
- 사거리는 (수평 속도) × (비행 시간)이에요. *θ* 가 클수록 오래 날지만 옆으로 느려서, 균형이 맞는 곳(*h* = 0 일 때 45°)에서 가장 멀리 가요.
- 아래 식은 *h* = 0 이고 공기 저항이 없을 때만 써요.

**식 (2개, 쌓은 분수)**: *T* = {{frac:2*v*₀ sin*θ*|*g*}}, *H* = {{frac:(*v*₀ sin*θ*)²|2*g*}} / *R* = {{frac:*v*₀² sin2*θ*|*g*}}
**조건 칩(3차)**: "*h* = 0, 공기 저항 없음일 때만" — *h* > 0 은 5장, 공기는 7장.
**예**: *v*₀ = 20 m/s, *θ* = 45°, *g* = 9.8 → *T* ≈ 2.89 s, *H* ≈ 10.2 m, *R* ≈ 40.8 m.

**그림 — 사거리 비교**: 땅선 y=380, 발사점 (60,380). 같은 *v*₀ 로 세 포물선: 30°(실선 연함, 최고 y≈300, 착지 x≈560), 45°(--sim 굵은 실선, 최고 y≈180, 착지 x≈700, 별표 "가장 멀리"), 60°(일점쇄선, 최고 y≈100, 착지 x≈560). 오른쪽 아래 범례: 30° 연한 실선 / 45° 굵은 실선 / 60° 일점쇄선. 하단 눈금 "100 = 10 m".

**[해 보기] 카드 ③** `preset 2`: h 0, v₀ 20, θ 30. 기록 표로 비교(5장에서 이어서).
**교사 메모**(접힘): 이 장은 식을 외우게 하지 않는다. "*R* 이 *θ* 에 어떻게 달라질까?"만. 한계: 식은 *h* = 0, 공기 없음에서만.

### 5장. 30°와 60°, 그리고 45°의 조건 (symmetry) — 신설

**본문 (3문장)**
- 합이 90°인 두 각도(30°와 60° 등)는 사거리가 같아요. sin2*θ* 가 같기 때문이에요.
- 하지만 높이가 다르면 비행 시간이 달라서, 처음 높이 *h* 가 0 일 때만 이 대칭이 맞고 45°가 가장 멀어요.
- 절벽 위(*h* > 0)에서 던지면 가장 멀리 가는 각도는 45°보다 작아져요.

**식 (1~2개)**: *R*(*θ*) = *R*(90° − *θ*) — `조건` 칩 "*h* = 0 일 때만" / *h* > 0 이면 착지 시간 *T* 가 달라져 위 식은 성립하지 않는다.
**예**: *v*₀ = 20 m/s, *h* = 0: 30°와 60° 모두 *R* ≈ 35.3 m. *h* = 40 m: 30° → 70.2 m(슬라이더 눈금 안에서 가장 멀리), 45° → 65.7 m, 60° → 51.3 m.

**그림**: 위 반쪽 "땅에서"(*h* = 0): 4장과 같은 30°·60° 두 궤적, 착지 x=560에 두 점을 점선으로 이어 "같은 거리". 아래 반쪽 "절벽 위에서"(*h* = 40 m): 절벽 상단 (60,200), 같은 30°·60° 궤적, 30°가 훨씬 멀리(x≈640), 60°가 짧게(x≈480). 라벨 "*h* 가 있으면 달라요".
**[해 보기]**
- Q-a (카드 ③) 30°를 기록한 뒤 θ만 60°로 바꿔 기록 → 둘 다 35.3 m.
- Q-b 새: `x-cliff` = planet earth, air off, **h 40, v₀ 20**, θ 30 → (θ 45 → 30 → 60 기록). "높이 *h* = 40 m 에서는 30°·45°·60° 중 어디가 가장 멀까?" 확인: 30° 70.2 m > 45° 65.7 m > 60° 51.3 m. 해설 카드: "*h* 가 있으면 최적 각도가 45°보다 작아요 → 설명 5장 ↩".
**교사 메모**: 최적 각도 자체(h=40 에서 약 30°)는 심화. 학생이 "45°가 항상 최대"에서 벗어나게 하는 것이 목표.

### 6장. 에너지는 어디로 가나 (energy)

**본문 (3문장)**
- *E*_k 는 속력이 클수록, *E*_p 는 높을수록 커요.
- 공기 저항이 없으면 중력만 일을 해서, 올라갈 때 *E*_k 가 *E*_p 로 바뀌고 내려올 때 반대로 바뀌며 합 *E* 는 일정해요.
- 최고점에서 *E*_p 가 가장 크고 *E*_k 는 가장 작지만 0은 아니에요(*v*ₓ 가 남음).

**식 (2개)**: *E*_k = ½ *m v*², *E*_p = *m g h*(땅 기준) / *E* = *E*_k + *E*_p = 일정(공기 저항 없을 때)
**예(카드 ②)**: *m* = 1 kg, *v*₀ = 10 m/s, *θ* = 30°, *h* = 20 m, *g* = 9.8 → 처음 *E*_k 50 J, *E*_p 196 J, *E* = 246 J. 최고점(약 21.3 m)에서 *E*_k ≈ 37.5 J, *E*_p ≈ 208.5 J, 합 246 J. 착지 직전 *E*_k = 246 J(속력 약 22.2 m/s).

**그림 — 에너지 막대 3장면**: 가로로 발사·최고점·착지 세 장면, 각 장면 위에 작은 공, 아래에 세로 쌓은 막대 하나(*E*_k = 에너지 운동 색, *E*_p = 위치 색 + 빗금). 발사: *E*_k 20%·*E*_p 80%(50:196), 최고점: *E*_k 15%·*E*_p 85%(37.5:208.5), 착지: *E*_k 100%. **세 막대의 꼭대기를 한 점선에 맞추고 "합 *E* = 246 J 같음"**. 숫자(J) 막대 옆. (1차 원고의 70:30 은 틀린 값이어서 위 값으로 고쳤다.)
**[해 보기] 카드 ②** `preset 1`: h 20, v₀ 10, θ 30, m 1, flash·energy 켬. 확인: 막대 합 246 J 일정.
**더 보기**: 롤러코스터 첫 언덕 이후 속력 / 질량을 3 kg 으로(⚙ `m`) 바꾸면 궤적은 같고 에너지만 3배(738 J).

### 7장. 중력이 달라지면, 공기가 있으면 (g-air)

**본문 (3문장)**
- 사거리와 비행 시간은 *g* 가 작을수록 커져요. 달의 *g* 는 지구의 약 1/6 이라 같은 던지기로 약 6배 멀리 가요.
- 공기 저항이 있으면 *E* 는 줄어들어요. 사라진 것이 아니라 열로 바뀐 것이라 **총에너지는 보존**돼요.
- 그래서 *E* = *E*_k + *E*_p 일정은 "중력만 일을 할 때"의 식이에요.

**식**: *R* ∝ {{frac:1|*g*}} (*v*₀, *θ* 같을 때) / 공기 저항이 있을 때 *E* 감소, *E* + 열 = 일정 [12물리01-05, 정성]
**예(카드 ④)**: *v*₀ = 10 m/s, 45°. 지구 *R* ≈ 10.2 m, 달(*g* = 1.62) *R* ≈ 61.7 m → 약 6배, 달 *T* ≈ 8.7 s.

**그림**: 같은 발사점 (60,380)에서 같은 *v*₀·45°. 달 궤적(--sim 실선, 착지 x=700, 최고 y=130), 지구 궤적(회갈색 실선, 착지 x=200, 최고 y=330). 라벨 "지구 *g* = 9.8", "달 *g* = 1.62", 가운데 화살표 "약 6배". 오른쪽 작은 상자 "공기 있음": 이상 궤적(점선)보다 낮고 짧은 실선 + "*E* 일부 → 열".
**[해 보기] 카드 ④** `preset 3`: planet moon, v₀ 10, θ 45, h 0. 확인: *R* ≈ 61.7 m.
**교사 메모**: 공기 저항(⚙ air)은 심화. 교사 발문 "공기 저항이 있으면 최적 각도는 45°보다 큰가 작은가?" **정답: 작다(탁구공 *v*₀ = 20 m/s: 35° 10.4 m, 40° 10.3 m, 45° 10.0 m, 50° 9.5 m)**.

**오늘 알아낸 것(한 줄 정리, 모달 맨 위)**: 포물선 운동은 "수평 등속 + 수직 등가속"이고, 중력만 일을 하면 *E*_k + *E*_p = *E* 는 일정하다.

**형성평가 3문항**

1. (개념) 수평으로 던진 공이 땅에 닿을 때까지 걸리는 시간 *T* 는 무엇으로 정해질까?

2. (값 계산) **[이 값으로 해 보기]** *g* = 10 m/s²(계산 편하게), *h* = 20 m, *θ* = 0°, *v*₀ = 10 m/s 로 던진 공은 몇 m 앞에 떨어질까?
