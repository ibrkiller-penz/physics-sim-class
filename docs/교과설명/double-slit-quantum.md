**R7 2차에서 바뀐 것 (1차 원고 대비)**
- 장 11개 → 설명 11장 + 정리 1(정리는 **설명 순서에 넣지 않고** [정리] 모달에서만 연다). 긴 장(1·4)을 덜고 4장을 '식'과 '식 쓰는 법' 두 장으로 나눔. 번호가 바뀌므로 아래 〔옛 N장〕 표기를 참고.

- 정리 = 형성평가 3문항(개념·값 계산·오개념 판정), 학생은 고르면 바로 정오와 해설, 교사 모드는 [정답 공개].
- 장당 상한: 본문 3문장 이내(심화·생활 예·성취기준은 접힘), 식 2개, 그림 1개. 1920×1080 한 화면.

**성취기준(docs/01 에서 확인된 것만)**: [12물리03-01] 빛의 중첩·간섭으로 파동성 / [12물리03-03] 이중성이 전자 현미경 등 기술에 활용(연계) / [12전자03-01] 단일 양자 이중 슬릿 → 입자-파동 이중성, 확률 파동 간섭(드브로이 관계식, 정성). [12전자03-02](중첩·측정)는 8장에서 '연계' 한 줄만. 교과서 쪽수·활동명은 미확인이라 쓰지 않는다.

**구성**: 1~10 설명, 11 확인 질문(해 보기), 〔정리〕 모달 전용. 〔심플〕 = 심플 모드 포함(1·2·3·4·7장). 교사 메모는 교사 모드에서만 접힘 상자로. 첫 진입 순서: 1→11장 → [실험 시작]. 머리줄 보조 문구는 '3 / 11 · 이중 슬릿'만(장 제목은 본문에만).

## 1장. 이 단원에서 배우는 것 〔심플〕
**제목**: 빛과 전자는 두 틈을 지나 무엇을 만들까?
**본문(3문장)**
- 빛이 두 개의 좁은 틈(슬릿)을 지나면 스크린에 밝은 줄과 어두운 줄이 번갈아 생겨요. 이것이 간섭 무늬예요.
- 이 장면으로 빛이 파동임을 확인하고, 무늬 간격이 무엇에 달려 있는지 알아봐요.
- 마지막에는 전자와 광자를 한 개씩 보내도 무늬가 생기는지 확인해요.

**오늘의 질문(큰 글씨 한 줄)**: "전자를 한 개씩 보내도 무늬가 생길까?"
**배울 것 체크 목록(3개)**: 간섭 무늬가 생기는 까닭 / 무늬 간격 *Δy* 와 *λ*·*d*·*L* 의 관계 / 하나씩 보낸 전자·광자가 만드는 무늬
**성취기준 칩(접힘 1개)**: '성취기준 3 ▸' → [12물리03-01] 빛의 간섭 · [12전자03-01] 입자-파동 이중성(정성) · (연계) [12물리03-03] 이중성의 활용
**그림**: 왼쪽 레이저(작은 사각형, x=80, 광축 y=225) → 점선 빔 → 가운데 얇은 판(x=380, 틈 두 곳 y=195·255) → 오른쪽 스크린(x=700)에 밝은 세로 막대 5개(가운데 가장 굵음). 라벨 "레이저 — 이중 슬릿 — 스크린". 오른쪽 아래 '탐구 흐름' 4칸 아이콘 띠(간섭 → 간격 식 → 하나씩 쏘기 → 측정기)는 그림 칸 아래 빈 자리에 둔다.
**교사 메모**: 설명 10분 + 실험 20분 + 정리 10분. 레이저를 눈에 직접 비추지 않기를 한 줄 환기.

## 2장. 파동의 말: 파장, 보강과 상쇄 〔심플〕
**제목**: 두 파동이 만나면?
**본문(3문장)**
- 파장 *λ* 는 마루에서 다음 마루까지 거리예요. 빨간빛은 약 650 nm, 파란빛은 약 450 nm 예요.
- 두 파동이 만나면 더해져요(중첩). 마루끼리, 골끼리 만나면 커지는 보강 간섭, 마루와 골이 만나면 지워지는 상쇄 간섭이 일어나요.
- 마루와 골이 어긋난 정도를 위상 차라고 해요. 꼭 한 파장만큼 어긋나면 다시 같은 모양이라 보강이 돼요.

**sym**: *λ* 파장(nm, 1 nm = 10⁻⁹ m) → 실험 변수 **빛의 파장 λ 슬라이더**(빛 모드).
**용어 칩(탭 → 작은 팝업)**: 파장, 진동수, 위상, 중첩, 보강 간섭, 상쇄 간섭.
**그림**: 위아래 두 칸. 위 칸 "보강": 사인파 두 개(회갈색 가는 선)의 마루가 일치, 합성파(`--sim` 굵은 선)는 진폭 2배. 아래 칸 "상쇄": 한 파동을 반 파장 이동, 합성파는 평평한 선. 파장 *λ* 는 마루-마루 양끝 화살표 치수선(2.5).
**생활 속 예(접힘)**: 소음 제거 이어폰은 소리와 반대 위상의 소리를 내어 상쇄한다.

## 3장. 두 틈에서 오는 빛: 경로차 〔심플〕
**제목**: 밝은 줄과 어두운 줄은 왜 번갈아 생길까?
**본문(3문장)**
- 두 슬릿이 새 파동의 출발점이 되어 둥글게 퍼져 나가요(회절).
- 스크린의 한 점까지 두 틈에서 가는 거리가 달라요. 그 차이가 경로차예요.
- 경로차가 파장의 정수배(0, *λ*, 2*λ* …)이면 밝은 줄(보강), 반 파장의 홀수배(½*λ*, 1½*λ* …)이면 어두운 줄(상쇄)이에요.

**식 1개**: 밝은 줄 — 경로차 = *mλ* (*m* = 0, 1, 2 …) / 어두운 줄 — 경로차 = (*m* + ½)*λ*.
**sym**: 경로차(m) 두 길의 길이 차 / *m* 정수 / *λ* 파장(m). *m* 은 실험 변수가 아니므로 강조 대상 없음(팝업에서는 '실험 화면에 슬라이더 없음' 표시).
**그림**: 왼쪽 슬릿판(두 틈 S₁, S₂, 간격 *d* 치수선), 오른쪽 스크린. S₁·S₂ 에서 스크린 위 점 P 로 가는 실선 두 개(S₂ 쪽이 약간 길게, 차이 부분을 굵은 구리색 짧은 선으로 표시). 스크린 가운데 O 라벨 "경로차 0 — 중앙 밝은 줄", 위 P₁ 라벨 "경로차 *λ* — 첫 밝은 줄". 틈 오른쪽에 반원 파면 3겹(가는 점선).
**생활 속 예(접힘)**: 비누막의 무지갯빛.
**교사 메모**: "중앙은 왜 늘 밝은가?" → 두 길이 같아 경로차 0.

## 4장. 무늬 간격 식 Δy = λL/d 〔심플〕
**제목**: 무늬 간격은 무엇에 달려 있을까?
**본문(3문장)**
- 이웃한 밝은 줄 사이 간격 *Δy* 는 *λL*/*d* 예요.
- 파장이 길수록, 스크린이 멀수록 넓어지고, 슬릿 간격이 넓을수록 촘촘해져요.
- 이 식은 *d* 가 *L* 보다 훨씬 작고 무늬가 중앙 가까이일 때 쓰는 근사식이에요.

**식 1개(큰 글자, 분수 쌓기)**: *Δy* = *λL* / *d*
**sym 표(식 팝업과 동일)**
| 기호 | 뜻 | 단위 | 실험 화면의 대응(강조할 것) |
|---|---|---|---|
| *Δy* | 무늬 간격(이웃한 밝은 줄 사이) | m(화면 mm) | 측정 띠의 '무늬 간격' 값 칩(재기 결과) |
| *λ* | 파장 | m(화면 nm) | 슬라이더 '빛의 파장 λ' |
| *L* | 스크린 거리 | m | 슬라이더 '스크린 거리 L' (전자 모드는 L 칸) |
| *d* | 슬릿 간격 | m(화면 mm) | 슬라이더 '슬릿 간격 d' (전자 모드는 d 칸) |
**비례 한 줄 칩 3개**: *λ* ↑ → *Δy* ↑ / *L* ↑ → *Δy* ↑ / *d* ↑ → *Δy* ↓.
**그림**: 스크린 단면 세로선에 밝은 줄 5개(같은 간격), 이웃한 두 줄 사이 치수선 "*Δy*"(2.5). 왼쪽 슬릿판과 거리 치수선 *L*, 틈 간격 치수선 *d*. 식의 *λ·L·d* 를 누르면 해당 치수선이 강조(각 치수선에 id).
**생활 속 예(접힘)**: 무늬 간격을 재어 레이저의 파장을 구한다(*λ* = *Δy·d*/*L*).
**더 알아보기(접힘, 교육과정 밖)**: 아래 '경로차에서 Δy 식까지'.

## 5장. 식으로 계산해 보기 (옛 4장 계산 예)
**제목**: 단위를 맞춰 넣어요
**본문(3문장)**
- 먼저 단위를 m 로 바꿔요. 650 nm = 6.5×10⁻⁷ m, 0.25 mm = 2.5×10⁻⁴ m.
- 이 값과 *L* = 2.0 m 를 식에 넣어요.
- 시뮬레이터 기본값이라 확대창에서 직접 잰 값과 맞춰 볼 수 있어요.

**계산 예 카드**: *Δy* = (6.5×10⁻⁷ × 2.0) ÷ (2.5×10⁻⁴) = 5.2×10⁻³ m = **5.2 mm**.
**표(바꿔 보기, 3행)**: *λ* 650 → 450 nm: 5.2 → 약 3.6 mm / *d* 0.25 → 0.50 mm: 2.6 mm / *L* 2.0 → 3.0 m: 7.8 mm. 각 행에 [해 보기] 1개(11장 질문과 같은 실험 ②③④).
**그림**: 4장 그림의 축소판(높이 160)을 왼쪽에, 오른쪽에 계산 카드. 단위 변환 화살표(nm → m, mm → m)를 작은 칩으로.
**주의(정답 누출 방지)**: 실험 화면에서는 학생이 **측정해 기록하기 전에는 이 계산 결과를 대입해 보여 주지 않는다**(식 팝업의 '지금 값 대입'은 기록 뒤에만 숫자까지 표시, 전에는 기호 형태만).

## 6장. 빛도 알갱이처럼 와요: 광자 (옛 5장)
**제목**: 약한 빛을 한 개씩 보내면?
**본문(3문장)**
- 아주 약한 빛은 광자라는 에너지 알갱이로 도착해요. 광자 하나의 에너지는 *E* = *hf* 예요.
- 광자를 한 개씩 보내면 점이 하나씩 찍히고, 어디에 찍힐지는 미리 알 수 없어요.
- 수천 개가 쌓이면 레이저 빛과 같은 줄무늬가 드러나요. 한 개는 입자처럼 도착하고, 쌓이면 파동의 무늬가 돼요.

**식 1개**: *E* = *hf*. **sym**: *E* 광자 에너지(J) / *h* 플랑크 상수 6.63×10⁻³⁴ J·s / *f* 진동수(Hz). 실험 대응 없음(팝업에 '관찰만' 표시).
**그림**: 스크린 3장 가로 나열(각 폭 약 220). 라벨 "10개 / 200개 / 2,000개". 10개: 점이 흩어짐. 200개: 줄 조짐. 2,000개: 선명한 세로 줄무늬. 점 색 `--sim`, 스크린 배경 짙은 잉크. 하단 한 줄: "점 하나는 예측 불가, 쌓인 모양은 늘 같음".
**생활 속 예(접힘)**: 어두운 곳에서 찍은 사진이 거칠다가 노출이 길면 선명해진다.
**교사 메모**: "점이 어디 찍힐지 정하는 규칙은?" → 확률로만 말할 수 있음. 광전 효과는 '빛이 알갱이로 에너지를 준다는 증거' 한 줄만.

## 7장. 전자도 파동이에요: 물질파 〔심플〕 (옛 6장)
**제목**: 전자도 두 틈에서 간섭할까?
**본문(3문장)**
- 전자를 하나씩 보내도 점이 쌓여 줄무늬가 생겨요. 전자도 파동처럼 간섭해요.
- 움직이는 입자의 물질파 파장은 *λ* = *h*/*p* 예요. 운동량 *p* 가 클수록 파장이 짧아요.
- 전압 *V* 를 높이면 전자의 *p* 가 커져 파장이 짧아지고, 무늬 간격이 좁아져요.

**식 2개**: *λ* = *h*/*p*, *p* = √(2*meV*). **sym**
| 기호 | 뜻 | 실험 대응 |
|---|---|---|
| *λ* | 물질파 파장 | (자동 계산 값, 전자 모드 측정 띠) |
| *p* | 전자의 운동량 | — |
| *V* | 가속 전압 | 슬라이더 '전자 가속 전압 V' |
| *m*, *e* | 전자 질량, 기본 전하 | — |
**수치 카드**: *V* = 1000 V → *λ* ≈ 38.8 pm (1 pm = 10⁻¹² m). *V* 를 4배로 하면 *p* 2배, *λ* ½.

## 더 알아보기(접는 심화, 4장 아래, 교육과정 밖 표시)
**경로차에서 *Δy* 식까지**: 스크린 위 높이 *y* 인 점에서 두 틈까지 경로차 ≈ *d* sin*θ*. 밝은 줄 조건 *d* sin*θ* = *mλ*. *θ* 가 작으면 sin*θ* ≈ tan*θ* = *y*/*L* 이므로 *y_m* = *mλL*/*d*, 이웃한 줄 간격 *Δy* = *λL*/*d*. 조건: *d* ≪ *L*, *θ* 작음. 한계 질문: *d* 를 0.10 → 0.50 mm 로 바꿔도 이 근사가 잘 맞을까? (시뮬레이터 범위에서는 *θ* 가 매우 작아 잘 맞음.)
