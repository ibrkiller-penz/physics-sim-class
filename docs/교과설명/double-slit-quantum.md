## 1장. 이 단원에서 배우는 것 〔심플〕
**제목**: 빛과 전자는 두 틈을 지나 무엇을 만들까?
**본문**
- 빛이 두 개의 좁은 틈(슬릿)을 지나면 스크린에 밝고 어두운 줄이 번갈아 생겨요. 이것이 간섭 무늬예요.
- 이 장면으로 (1) 빛이 파동임을 보여 주는 증거, (2) 무늬 간격이 파장·슬릿 간격·거리와 어떻게 이어지는지, (3) 전자와 광자도 파동처럼 무늬를 만든다는 사실을 배워요.

**오늘의 질문(큰 글씨 한 줄)**: "전자를 한 개씩 보내도 무늬가 생길까?"
**성취기준 칩 3개**: [12물리03-01] 빛의 간섭 · [12전자03-01] 입자-파동 이중성(정성) · 연계 [12물리03-03]
**순서 띠(작은 아이콘 4개)**: 간섭 → 간격 식 → 하나씩 쏘기 → 측정기
**그림**: 왼쪽에 레이저(작은 사각형, x=80, 광축 y=225) → 점선 빔 → 가운데 얇은 판(x=380)에 틈 2개 → 오른쪽 스크린(x=700)에 밝은 세로 막대 5개(가운데가 가장 굵음). 라벨 "레이저 — 이중 슬릿 — 스크린".
**교사 메모**: 설명 10분 + 실험 20분 + 정리 10분 흐름. 레이저를 눈에 직접 비추지 않기를 한 줄 환기.

## 2장. 파동의 말: 파장, 위상, 보강과 상쇄 〔심플〕
**본문**
- 파장 *λ* 는 마루에서 다음 마루까지 거리예요. 빛은 파장에 따라 색이 달라서 빨강은 약 650 nm, 파랑은 약 450 nm 예요. (1 nm = 10⁻⁹ m)
- 두 파동이 만나면 더해져요(중첩). 마루끼리, 골끼리 만나면 커지는 보강, 마루와 골이 만나면 지워지는 상쇄가 일어나요.
- 마루와 골이 어긋난 정도를 위상 차라고 해요. 정확히 한 파장만큼 어긋나면 다시 같은 모양이라 보강이 돼요.

**용어 칩(탭하면 작은 팝오버)**: 파장, 진동수, 위상, 중첩, 보강 간섭, 상쇄 간섭.
**그림**: 위아래 두 칸. 위 칸 "보강": 사인파 두 개(회갈색 가는 선)의 마루가 일치, 합성파(`--sim` 굵은 선)는 진폭 2배. 아래 칸 "상쇄": 한 파동을 반 파장 이동, 합성파는 평평한 선. 파장 *λ* 는 양끝 화살표 치수선.
**생활 속 예**: 소음 제거 이어폰은 소리와 반대 위상의 소리를 내어 상쇄한다. 수조에서 물결 두 개가 겹치는 모습.

## 3장. 두 틈에서 오는 빛: 경로차 〔심플〕
**본문**
- 레이저 빛이 두 슬릿에 닿으면 두 틈이 새 파동의 출발점이 되어 둥글게 퍼져 나가요(회절).
- 스크린의 한 점까지 두 틈에서 가는 거리가 다르고, 그 차이를 경로차라고 해요.
- 경로차가 파장의 정수배(0, *λ*, 2*λ* …)이면 마루끼리 만나 밝은 줄(보강), 반 파장의 홀수배(½*λ*, 1½*λ* …)이면 어두운 줄(상쇄)이 돼요.

**식**: 밝은 줄 경로차 = *mλ* (*m* = 0, 1, 2 …), 어두운 줄 경로차 = (*m* + ½)*λ*. 기호표: 경로차(m) / *m* 정수 / *λ* 파장(m).
**그림**: 왼쪽 슬릿판(두 틈 S₁, S₂, 틈 간격 *d* 치수선), 오른쪽 스크린. S₁·S₂ 에서 스크린 위 점 P 로 가는 실선 두 개(S₂ 쪽이 약간 길게). 스크린 가운데 점 O 라벨 "경로차 0 — 중앙 밝은 줄", 위쪽 점 P₁ 라벨 "경로차 *λ* — 첫 밝은 줄". 틈 오른쪽에 반원 파면 3겹(가는 점선). 아래 한 줄: "경로차 = 두 길의 길이 차".
**생활 속 예**: 비누막의 무지갯빛(얇은 막 앞뒤에서 반사한 빛의 간섭).
**교사 메모**: "중앙은 왜 늘 밝은가?" → 두 길이 같아 경로차 0.

## 4장. 무늬 간격 식 Δy = λL/d 〔심플〕
**본문**
- 이웃한 밝은 줄 사이 간격 *Δy* 는 *λL/d* 예요. 파장이 길수록, 스크린이 멀수록 넓어지고, 슬릿 간격이 넓을수록 촘촘해져요.
- 단위를 먼저 맞춰요. 650 nm = 6.5×10⁻⁷ m, 0.25 mm = 2.5×10⁻⁴ m 로 바꿔 넣으면 돼요.
- 이 식은 슬릿 간격 *d* 가 스크린 거리 *L* 보다 훨씬 작고(*d* ≪ *L*) 무늬가 중앙 가까이일 때 쓰는 근사식이에요.

**식(큰 글자 1줄, 분수 세로 쌓기)**: *Δy* = *λL* / *d*
**기호표**: *Δy* 이웃한 밝은 줄 간격(m, 화면은 mm) / *λ* 파장(m) / *L* 슬릿~스크린 거리(m) / *d* 두 슬릿 사이 간격(m).
**계산 예 카드**: *λ* 650 nm, *d* 0.25 mm, *L* 2.0 m → *Δy* = (6.5×10⁻⁷ × 2.0) ÷ (2.5×10⁻⁴) = 5.2×10⁻³ m = 5.2 mm. (시뮬레이터 기본값, 확대창에서 직접 재어 확인)
**비례 표(3행)**: *λ* ↑ → *Δy* ↑ / *L* ↑ → *Δy* ↑ / *d* ↑ → *Δy* ↓.
**그림**: 스크린 단면 세로선에 밝은 줄 5개를 같은 간격으로, 이웃한 두 줄 사이 치수선 "*Δy*". 왼쪽에 슬릿판과 거리 치수선 *L*, 틈 간격 치수선 *d*. 식의 *λ·L·d* 를 누르면 해당 치수선이 강조(식↔도식 연결용 id 부여).
**생활 속 예**: 무늬 간격을 재면 레이저 파장을 구할 수 있다(*λ* = *Δy·d/L*).
**교사 메모**: 근사 조건은 한 줄만. 유도는 아래 '더 알아보기'.

## 5장. 빛도 알갱이처럼 와요: 광자와 하나씩 쏘기
**본문**
- 아주 약한 빛은 광자라는 에너지 알갱이로 도착해요. 광자 하나의 에너지는 *E* = *hf* (*h* 플랑크 상수, *f* 진동수)예요.
- 광자를 한 개씩 보내면 스크린에 점이 하나씩 찍혀요. 어디에 찍힐지는 미리 알 수 없어요.
- 그런데 수천 개가 쌓이면 레이저 빛과 같은 줄무늬가 드러나요. 한 개는 입자처럼 도착하고, 많이 모이면 파동의 무늬가 돼요.

**식·기호**: *E* = *hf* (*E* 광자 에너지 J, *h* 6.63×10⁻³⁴ J·s, *f* 진동수 Hz). 광전 효과는 "빛이 알갱이로 에너지를 준다는 증거" 한 줄만.
**그림**: 스크린 3장 가로 나열(각 폭 약 220). 라벨 "10개 / 200개 / 2,000개". 10개: 점이 흩어짐. 200개: 줄 조짐. 2,000개: 선명한 세로 줄무늬. 점 색 `--sim`, 스크린 배경 짙은 잉크. 하단 한 줄: "점 하나는 예측 불가, 쌓인 모양은 늘 같음".
**생활 속 예**: 어두운 곳에서 찍은 디지털 사진이 거칠다가(광자가 적음) 노출이 길면 선명해진다.
**교사 메모**: "점이 어디 찍힐지 정하는 규칙은?" → 확률로만 말할 수 있음.

## 6장. 전자도 파동이에요: 물질파 λ = h/p 〔심플〕
**본문**
- 전자를 하나씩 보내도 점이 쌓여 줄무늬가 생겨요. 전자도 파동처럼 간섭해요.
- 움직이는 입자의 파장을 물질파 파장이라 하고 *λ* = *h*/*p* 로 써요. 운동량 *p* 가 클수록 파장이 짧아요.
- 전자를 전압 *V* 로 가속하면 운동량이 커져 파장이 짧아지고, 무늬 간격이 좁아져요.

**식**: *λ* = *h*/*p*, 가속된 전자의 *p* = √(2*meV*). 기호표(*m* 전자 질량, *e* 기본 전하, *V* 가속 전압).
**수치 카드**: *V* = 1000 V → *λ* ≈ 38.8 pm (1 pm = 10⁻¹² m). *V* 를 4배로 하면 *p* 2배, *λ* ½.
**그림**: 왼쪽 전자 총(작은 사각형 + 전압 기호 *V*) → 이중 슬릿 → 스크린 줄무늬. 아래에 막대 두 개 "*V* 1000 V: 파장 길다 / *V* 4000 V: 파장 ½"(길이 2:1). **필수 한 줄**: "화면의 줄 간격은 보기 좋게 키운 모형 단위(칸)예요. 실제 간격은 훨씬 좁아요."
**생활 속 예**: 전자 현미경은 파장이 아주 짧은 전자의 파동성으로 빛 현미경보다 작은 것을 본다([12물리03-03] 연계).
**교사 메모**: 야구공의 물질파는 너무 짧아 관측 불가 → 일상에서 파동성이 안 보이는 이유(카드 ③ 작은 구슬과 연결).

## 7장. 어느 슬릿을 지났는지 알아내면?
**본문**
- 전자가 어느 슬릿을 지났는지 알아내는 측정기를 켜면 줄무늬가 사라지고 넓은 띠가 돼요.
- 사람이 지켜봐서가 아니에요. 어느 길인지 정보가 장치에 남으면 두 길이 겹칠 수 없어서 간섭이 일어나지 않아요.
- 무늬는 점이 닿을 확률의 모양이에요(확률 파동). 두 길의 가능성이 열려 있을 때만 간섭이 생겨요.

**식**: 없음.
**그림**: 위 칸 "측정기 끔": 가로축 위치, 세로축 밝기 곡선에 봉우리 여러 개. 아래 칸 "측정기 켬": 넓은 봉우리 하나. 같은 가로 눈금. 켬 쪽에는 눈 아이콘 대신 '기록 장치' 사각형을 슬릿 옆에 둔다(눈 = 사람이 봐서 오개념 방지).
**생활 속 예**: 양자 기술의 바탕이 되는 성질([12전자03-02] 연계, 정성 한 줄).
**교사 메모**: 시간이 부족하면 건너뛰고 카드 ④ 에서 직접 보여 줘도 됨.

## 8장. 생활 속 간섭과 이중성

## 9장. 흔한 오개념 (말풍선 3개: '흔한 오해 → 왜')
1. **"전자 하나가 둘로 쪼개져 두 슬릿을 지나간다."** → 전자는 늘 한 개로 도착한다(스크린에 점 하나). 무늬는 전자 하나가 어디에 닿을 확률이 두 길의 간섭으로 정해져서 생긴다.
2. **"빛은 파동이라서 입자성은 없다."** → 약한 빛은 광자가 하나씩 점으로 도착한다(5장). 빛은 상황에 따라 파동과 입자의 성질을 모두 보인다.
3. **"무늬 간격은 슬릿 하나의 폭이 정한다."** → 이웃한 밝은 줄 간격은 *λL/d*, 곧 두 슬릿 사이 간격 *d* 로 정해진다. 슬릿 하나의 폭은 무늬 전체의 퍼짐(바깥 윤곽)에 영향을 준다.

**교사용 접힘 보조 오개념**: "측정기를 켜면 사람이 봐서 사라진다" / "밝은 줄은 슬릿 수만큼 2개" / "슬릿 하나만 열면 줄 수가 반".
**강조 규칙**: 오개념 라벨 '흔한 오해' + 옅은 주홍 띠, 바른 설명은 `--sim-tint` 카드. 한 장에 강조 3곳 이하.

| 어느 슬릿인지 측정기를 켜면? | quantum ④ 측정기를 켜면? | send 'electron', rate 1000, det true |
| 전자도 슬릿 하나면 줄무늬가 사라질까? | quantum ⑤ 슬릿 하나만? | send 'electron', rate 1000, slit 'top' |
| 가속 전압을 4배로 하면 간격은? | quantum ① 적용 후 *V* 만 바꿈 | *V* 1000 → 4000 (*λ* ½, 간격 ½). 카드가 아니라 '카드 ① + 값 덮어쓰기' 로 연결 |

**장별 연결**: 3·4장 = physics ①②③④ / 5장 = quantum ②·① / 6장 = quantum ① + *V* 변경 / 7장 = quantum ④ / 9장 오해 1 = quantum ①, 오해 2 = quantum ②, 오해 3 = physics ⑤.

## 11장. 실험 뒤 정리 (정리 팝업과 공용)
**오늘 알아낸 것(기록 표 자동 인용 + 직접 쓰기 칸)**: 무늬 간격은 *λ·L* 에 비례, *d* 에 반비례 / 전자·광자는 하나씩 와도 쌓이면 무늬 / 어느 길인지 정보가 남으면 무늬가 사라짐.

**확인 문제**
1. (개념 확인, 4장) 슬릿 간격 *d* 를 0.25 mm 에서 0.50 mm 로 두 배로 하면 무늬 간격은? 보기: 두 배 / 반 / 그대로. **정답: 반(½).** 해설: *Δy* = *λL/d* 에서 *d* 가 분모라 두 배면 ½. 5.2 → 2.6 mm.
2. (값 계산, 4장) 초록 빛 *λ* 500 nm, *d* 0.20 mm, *L* 1.6 m 이면 *Δy* 는? 보기: 2.0 / 4.0 / 6.4 mm. **정답: 4.0 mm.** 해설: (500×10⁻⁹ × 1.6) ÷ (0.20×10⁻³) = 4.0×10⁻³ m.
3. (오개념 판정, 7·9장) "전자 한 개가 둘로 쪼개져 두 슬릿을 지난다"는 말은? **정답: 아니다.** 해설: 전자는 한 개로 도착한다. 도착할 확률이 두 길의 간섭으로 정해져 쌓이면 무늬가 된다. 측정기로 어느 길인지 알면 무늬가 사라진다.

**한 줄 자기 평가(글자 선택지, 이모지 금지)**: "잘 이해했어요 / 조금 헷갈려요 / 다시 보고 싶어요". 세 번째를 고르면 관련 설명 장 링크.
**해설 → 설명 복귀 링크**: '경로차·보강·상쇄' → 3장, 'Δy 식' → 4장, '점이 쌓임·확률' → 5·6장, '측정기' → 7장, '슬릿 하나' → 9장.

## 더 알아보기(접는 심화, 4장 아래)
**경로차에서 Δy 식까지**: 스크린 위 높이 *y* 인 점에서 두 틈까지 경로차 ≈ *d* sin*θ*. 밝은 줄 조건 *d* sin*θ* = *mλ*. *θ* 가 작으면 sin*θ* ≈ tan*θ* = *y/L* 이므로 *y_m* = *mλL/d*, 이웃한 줄 간격 *Δy* = *λL/d*. 조건은 *d* ≪ *L* 이고 *θ* 가 작을 때. 한계 질문: *d* 를 0.10 → 0.50 mm 로 바꿔도 이 근사가 잘 맞을까? (시뮬레이터 범위에서는 *θ* 가 매우 작아 잘 맞음.)
