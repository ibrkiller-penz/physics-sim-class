# 난이도 체계 (R9) — 초급 · 중급 · 고급

기획C 작성. 5종(projectile-energy, double-slit-quantum, collision-momentum, orbit-gravity, convex-lens) 공통 규칙이다. R9 구현 후 **설계서 `docs/개선/R9_중학교연계_난이도.md` §0-2 의 팀장 결정 20개**로 갱신했다(맨 끝 '확정' 절과 '구현 형식' 절이 우선). 아래 본문 중 확정과 다른 표현은 확정 절 기준으로 읽는다.

## 1. 한 줄 결론

- [심플|자세히]를 없애고 **[초급|중급|고급] 하나**로 합친다. 두 선택이 겹쳐 '심플인데 고급' 같은 모순 조합이 생기는 것을 막는다.
- 내부 값은 `level = 'basic' | 'mid' | 'adv'`. 숫자 별칭 1 | 2 | 3.
- 초급은 지금 심플의 **화면 배치**를 바탕으로 하되 **내용 난이도까지** 낮춘다. 중급은 지금 자세히의 기본 흐름. 고급은 새로 만든다.
- 단계마다 달라지는 것: 설명 장, 보이는 변수, 실험 카드, 예측 질문, 계기 칸, 결과 해설, 정리 문제, 기호 말투.

## 2. 단계 정의

| | 초급 | 중급 | 고급 |
|---|---|---|---|
| 목표 | 중학교 수준에서 관찰·비교로 현상을 안다 | 고등 기본 개념과 핵심 식을 쓴다 | 모든 변수·갈래, 식 유도, 한계 조건, 정량 비교 |
| 대상 | 중학교 개념이 약하거나 고등 물리를 처음 보는 학생 | 수업을 따라가는 학생 | 심화·탐구 학생 |
| 변수 | 1~2개 (나머지는 고정) | 핵심 변수 전부 (지금 자세히) | 숨은 변수까지 전부 (행성·g·e·천체 등) |
| 실험 카드 | 2~3개, 장면 중심 | 지금 분량 | 전부 + 한계·비교 카드 |
| 계산 | 없음. '크다/작다/같다' 비교 | 결과 값 읽기, 식에 대입 1~2개 | 유도, 근사 한계, 측정값과 이론값 비교 |
| 기호 | 최소. 말로 풀고 기호는 작은 칩 | 고등 기호 (v₀, θ, E_k) | 기호 + 식 유도 팝업 |
| 어려운 말 | 벡터, 구심력 같은 말 제거 | 사용 | 사용 + 정의의 한계 언급 |
| 예측 질문 | '무엇이 먼저 닿을까?' 장면형, 보기는 말 | 지금 문구 | '값을 구하고 이유 쓰기' |
| 정리 문제 | 고르기 2~3개 | 지금 3문항 (개념·계산·오개념) | 심화 서술·계산을 기본으로 펼침 |
| 설명 장 | 중학교 다시 보기 1~3장 + 목표 + 핵심 1~2장 + 정리 (6~7장) | 중학교 장 접힘 + 본 단원 약 10장 | 중학교 장 숨김(열 수 있음) + 유도·한계 장 포함 12~13장 |

### 갈래가 있는 두 시뮬레이터

- orbit-gravity: 초급은 **대포 갈래만** 기본(속력 띠로 관찰). 위성 갈래는 중급, 케플러·천체 선택·유도는 고급. 초급에서 다른 갈래는 [다른 갈래 보기]로 접는다.
- double-slit-quantum: 초급은 **빛 갈래만**, 변수는 색(파장)과 슬릿 간격 2개, 관찰만. 중급은 L까지 3변수와 Δy=λL/d, 광자 한 개씩 쏘기. 전자·물질파·측정기·d≪L 한계는 고급.

### 시뮬레이터별 초급·중급·고급 요약

| 단원 | 초급 | 중급 | 고급 |
|---|---|---|---|
| 포물선·에너지 | 각도(또는 높이) 1~2개, 지구 고정. 옆으로 던진 공 vs 떨어뜨린 공, 에너지 막대(숫자 없음). 성분 기호 없음 | v₀, θ, h, 성분 화살표, 에너지 막대 숫자, 달·화성 비교 | g·행성·h 전부, 높이 있을 때 최적각, 사거리 유도, E_k·E_p·E 시간 그래프, 공기 저항 없음 한계 |
| 충돌·운동량 | 질량(같음/2배) 1~2개, 속도 프리셋. '움직임의 양' 막대(숫자 없음), 트럭·승용차 힘 비교 | 운동량·보존·부호, 튕김·달라붙기, 막대 숫자 | 충격량·힘-시간 그래프, 반발 계수 e 슬라이더, 에너지 손실 정량 |
| 궤도·탈출 | 쏘는 속력 1개, 지구 고정, 대포. 느림→추락, 7.9→원, 더 빠름→멀리. m/s 병기 | 위성(높이→속력·주기), 탈출 속도 11.2, 식은 결과만 | 천체 선택, v²=GM/r 유도, 에너지 합 0 기준, 케플러 T²/a³ 비교 |
| 이중 슬릿 | 빛, 색·간격 2개, 관찰('파란빛은 줄 간격이 좁아져요') | 3변수, Δy=λL/d, 광자 하나씩 | 전자·물질파·측정기, 근사 한계, 경로차→Δy 유도, 모형 눈금 환산 |
| 볼록렌즈 | 물체 거리 1개(멀리·가까이), f 고정, '상의 모습'(거꾸로/바로, 커짐/작아짐)만 | s·f, 상 거리·배율 숫자, 작도 | 1/f=1/s+1/s' 일치 확인, s=f·2F 경계, 측정 오차 비교 |

세부 장 배치는 단원별 문서(projectile-energy.md 등)에 R9 절로 옮긴다.

## 3. 5종 공통 규칙 (보이는 것·숨기는 것)

1. **초급**
   - 보임: 중학교 다시 보기, 관찰 변수 1~2개, 막대·띠 같은 정성 표시, 장면형 예측, 쉬운 말 계기('상의 모습', '움직임의 양').
   - 숨김: 식 칸·계산 줄, ƒ 식 팝업(버튼 글자는 '공식 보기'로 바꾸고 팝업 첫 줄 '이 실험에서 쓰는 식은 이것 하나예요'), '더 알아보기', 속도 성분·벡터·구심력, 갈래 다수, ⚙ 안의 많은 설정.
   - 단위: 기호는 작은 칩으로, 값 옆에 말 뜻을 붙인다(λ는 '색 ↔ 파장'). 속력은 m/s 병기(7900 m/s = 7.9 km/s).
   - 예측 띠는 접힌 상태로 시작해 그림을 가리지 않는다.
2. **중급**
   - 지금 자세히의 기본 흐름·식·기호. '더 보기'는 접힌 선택 읽기로 유지. 중학교 장은 접힌 한 줄 [중학교에서 배운 것 3장 다시 보기 ▸].
3. **고급**
   - 모든 변수·갈래·카드 펼침, '더 알아보기'는 본문에 펼침, 식 유도·한계 조건은 고급 전용 장(`lv:['adv']`), 정량 비교(표·그래프), 정리 심화 문항 기본 펼침. 중학교 장은 목차 묶음에서만 열 수 있음.
4. **말투**: 초급 '~해요' 쉬운 말과 장면 문장, 중급 지금 문체, 고급 정의·조건을 명시하는 문체.
5. **기호 도입 순서**: 한 장에 새 기호 하나씩. 정의 없이 먼저 쓰지 않는다.
6. **심화는 단계가 결정**한다. '더 보기'는 중급용 선택 읽기만 맡는다.

## 4. 심플·자세히와의 관계 (통합안과 이유)

- **통합**: 심플=화면 배치만 줄이고 내용 난이도는 같았다. 학생에게 '난이도 신호'가 아니었다. 초급·중급·고급과 따로 두면 선택이 둘이 되어 모순 조합이 생긴다.
- 대응: 심플 → **초급**, 자세히 → **중급**. 고급은 신규.
- 초급 화면은 심플 배치(변수 레일 2~3, 상황 칩, 계기 소수, 프리셋)를 기반으로 하되 `cfg.levels.basic`에서 변수 2개 이하·계기를 더 줄인다.
- `cfg.simple`은 호환용: `cfg.levels.basic`이 없으면 `cfg.simple`을 basic으로 자동 변환. `cfg.levels.mid`가 없으면 기존 전체 구성, `adv`가 없으면 mid에 '고급 전용 요소만' 덧붙여 점진 적용.
- `SK.isSimple()`은 `level==='basic'` 호환 함수로 남긴다. `SK.setSimple(on)`은 `setLevel(on?'basic':'mid')`로 위임.
- 장·질문 필터: `data.simple` 목록은 basic 목록으로 자동 변환. 새 필드 `levels:['basic','mid','adv']`(또는 `lv:[1,2,3]`/`min:2`). 필드가 없으면 중급·고급에서만 보임. 한 질문의 단계별 변형: `text.basic / text.adv`.
- 중학교 장: `type:'review'`, id `mid-school-1..3`. 초급 기본 펼침, **중급 접힘(본 단원 1장 위 띠 + 목차 맨 위 묶음), 고급은 띠 없이 목차 묶음만**(열면 `showReview(true)` 로 초급처럼 장 순서에 들어온다).

## 5. 화면 배치와 선택 UI

- **허브**: 제목 아래 부제 줄에 '내 수준 [초급|중급|고급]' 한 줄 분절(크게). 단계별 한 줄 설명(초급 중학교 수준·관찰 / 중급 고교 기본 / 고급 유도와 심화). 첫 방문엔 초급 기본 + '중학교 개념이 약하면 초급, 수업 따라가면 중급' 한 줄 안내. 기존 우상단 [심플|자세히] 제거. 카드 칩(장·실험·정리 수)과 [열기] 링크 `?level=`이 단계에 따라 바뀜. 카드 설명 아래 초급에서 하는 일 한 줄.
- **머리줄(설명·실험 공통)**: 제목 옆 단계 칩 하나('중급 ▾'). 누르면 팝업에서 세 단계를 한 줄 설명과 함께 고른다. 1024x768 이하에서 [바로 실험] 버튼과 겹치는지 점검.
- **⚙ 설정 '화면 구성'**: 같은 [초급|중급|고급] 한 줄. 기본 경로는 머리줄 칩.
- **키**: `M` = 초→중→고 순환(이전 '심플↔자세히' 대체). ⋯ 안내문 'M 단계 바꾸기'.
- **교사 모드 칩**: 단계 칩 옆에 '이 단계 권장 시간'.
- **설명 점 표시줄**: 중학교 장은 '복습 1/3' 표시와 다른 색 점, 장 번호(1장~)는 본 단원부터. 점 표시줄은 '복습 3 · 본 단원 8'처럼 구간 표시. [장 목록 ▾]에서 복습 묶음이 맨 위 구분선으로.

## 6. 주소 · 키 · 저장값 · 옛 주소 대응표

우선순위(높음 → 낮음): **주소 `?level=` > 옛 `?simple=` > 단원 개별 저장 > 전역 저장 > 옛 저장 > 기본값**.

| 구분 | 새 규칙 | 옛 것과의 대응 |
|---|---|---|
| 주소 | `?level=basic\|mid\|adv` (별칭 `1\|2\|3`) | `?simple=1` → basic, `?simple=0` → mid |
| 주소 옵션 | `&keep=0` : 주소 단계를 이번만 적용, 저장값은 덮어쓰지 않음(교사 시연 링크용) | 없음 |
| 전역 저장 | `physsim.level` = basic\|mid\|adv (허브에서 고른 값, 5종 공유) | `physsim.mode`: 'simple' → basic, 'full' → mid. 새 키가 있으면 새 키 우선. 옛 키는 읽기만 하고 지우지 않음 |
| 단원 개별 저장 | `physsim.level.<slug>` : 시뮬레이터 안에서 바꾸면 그 단원만 기억 | 신규 |
| 허브에서 변경 | **묻지 않고** `physsim.level` 저장 + `physsim.level.*` 전부 삭제 + 토스트 '단원별로 골랐던 N개도 함께 바꿨어요'. 단원만 다르게 골랐으면 카드 칩 `.is-own` | 신규 |
| 기본값 | 저장·주소 모두 없으면 허브·시뮬레이터 모두 **초급** | 이전 기본은 자세히(=중급). 첫 방문 학생이 고교 개념으로 바로 들어가지 않게 초급으로 바꿈(팀장 확인) |
| 기타 주소 | `?teacher=1`, `?view=sim`은 그대로. 단계와 독립 | |
| 키 M | 단계 순환 | 심플↔자세히 토글 |

호환 규칙:
- 코드가 `SK.isSimple()`, `?simple=1`, `physsim.mode`를 참조하는 곳은 깨지지 않게 위 변환을 거친다.
- `tools/shot.py` 예: `sims/<slug>/index.html?view=sim&level=basic`. `?simple=1`도 계속 동작해야 한다(회귀 점검 대상).
- 옛 `physsim.simpleToastShown` 안내 토스트는 새 단계 안내 토스트로 대체하되 키는 재사용 가능.

## 7. 교사 모드와 단계

- 교사 모드(`?teacher=1`)와 단계는 **서로 독립**. 한쪽을 바꿔도 다른 쪽은 변하지 않는다.
- 교실 운영: 시연 = 교사 기기에서 `?level=`로 고정(`keep=0` 권장), 학생 = 각자 기기에서 고른 단계(기기별 저장). 허브 [열기] 링크에 현재 단계가 자동으로 붙어 시연 링크를 공유하기 쉽다.
- 교사 모드를 켜면 단계 칩 옆 '이 단계 권장 시간', 교사 메모에 단계별 운영 팁('초급에서는 이 장을 건너뜁니다'). 허브 하단 시간 배분도 단계별(초급 설명 10·실험 20·정리 10 내외, 중급 45분 5·10·20·10, 고급은 설명 감소·실험·정리 증가. 실제 시간은 시연 후 조정).
- 교사용 안내 문서에 한 장: '시연 = 교사 기기 단계 고정, 학생 = 각자 선택'.

## 8. 실험 중 단계 바꾸기

- 값·재생 위치·기록은 유지하고 **컨트롤만 숨기거나 보인다**(같은 DOM 이동 방식).
- **올릴 때**: 기존 값 유지, 새 변수는 기본값으로 채움.
- **내릴 때**: 숨겨진 변수는 값을 되돌리지 않고 계산에 계속 쓰되 화면에서만 숨김. 값이 기본과 다르면 작은 안내 '이전에 바꾼 값이 있어요'.
- **실험 카드**: 새 단계에 같은 번호가 있으면 이어서, 없으면 처음 카드. 가까운 카드로 자동 교체하지 않고 '이 카드는 고급에서만 나와요' 안내만(팀장이 둘 중 하나로 확정).
- **예측 띠**: 이미 답한 것은 유지, 새 단계 질문은 다음 실험부터. 기록 표·정리 입력은 지우지 않는다.
- 열려 있는 설명 팝업은 장 목록만 재구성하고 현재 장이 새 목록에 없으면 가장 가까운 앞 장으로. 바뀔 때 토스트 '중급으로 바꿨어요 — 값은 그대로'.
- 설명 화면 장 번호·점 개수가 바뀌므로 현재 장은 id로 추적한다.

## 9. 중학교 다시 보기 장 규칙과 건너뛰기

- 위치: 각 단원 설명 맨 앞 1~3장. 1장 용어·그림, 2장 쉬운 식·관찰 규칙, 3장 '중학교에서는 ~까지 배웠어요. 이제 ~를 더해요' 다리 문장(장 사이 고정 칸으로도 둠).
- 표기: '복습' 배지. 장 번호 대신 '복습 1/3' 또는 '중1·중2'.
- 성취기준: **코드는 확인된 것만**. 현재 코드는 모두 미확인이므로 쓰지 않고 '중학교 과학 ○학년 ○○ 단원'으로, 불확실하면 '(확인 필요)'. 교과서 문장은 베끼지 않고 새로 쓴다. teacherNote·docs/교과설명도 같은 표기.
- 건너뛰기: 복습 장 맨 위 [이미 알아요, 본 단원으로 →] 한 번으로 본 설명 1장으로. 복습 마지막에 확인 질문 1개(자가 진단). 모든 단계에서 [중학교 내용 다시 보기]로 다시 열 수 있다.
- 단계별 기본: 초급 펼침 / 중급 접힘(띠) / 고급 목차 묶음만. 건너뛰기 선택은 세션 안에서만 기억(`physsim.lesson.<slug>.reviewSkip`).
- 단원별 중학교 근거(단원 수준, 코드 없음): 포물선 = 중1 힘과 운동, 중2 운동과 에너지(확인 필요); 충돌 = 중2 운동과 에너지, 힘(작용·반작용)(확인 필요), 운동량·충격량은 고등 신규; 궤도 = 중1 지구계·태양계, 중력(확인 필요); 슬릿 = 중학교 파동·빛 단원(학년 확인 필요); 렌즈 = 중학교 빛(굴절·렌즈 상) 단원(학년 확인 필요).

### 기획 원고에서 고친 것 (물리·교육과정)
- 포물선 복습 2: '일을 할 수 있어요' → '무언가를 움직일 수 있어요'.

## 12. 구현 형식 (lesson 필드 · 클래스)

### 장 필드 (`sims/<slug>/lesson.js` → `SimKit.lesson({chapters:[…]})`, 해석은 `shared/lesson.js`)
| 필드 | 뜻 |
|---|---|
| `levels:['basic','mid','adv']` | 이 장이 나오는 단계. 없으면 `['mid','adv']`. 옛 `data.simple` 목록이 있으면 목록에 든 장 = 3단계 전부(호환, 새 파일은 `data.simple` 을 쓰지 않는다) |
| `type:'review'` | 중학교 다시 보기 장. `levels` 를 무시하고 규칙(§9)으로 처리. 필드: `no`·`of`(복습 1/3), `source`(코드 없는 출처), `body`, `svg`, `terms:[…]`(용어 칩), `bridge`(다리 문장), `selfcheck:{q, choices[3], answerIdx, why}`, `teacherNote`(첫 줄 '성취기준 코드 미확인') |
| `title`·`question`·`body`·`goals`·`condition`·`table`·`how` | 문자열(배열) 또는 `{basic:…, mid:…, adv:…}` — 지금 단계 값을 쓴다(`SK.atLevel`). 없는 단계는 가까운 단계 값 |
| `eq` | 배열 또는 `{basic:[…], mid:[…]}`. 초급 식은 말로 쓴 한 줄('위치 에너지 + 운동 에너지 = 일정'), 기호표(`symbols`)·`now`·'더 보기'는 초급에서 자동으로 숨는다 |
| `questions[].levels`·`q`·`cardName` | 확인 질문의 단계(없으면 `simple:false` → 중·고급, 아니면 3단계). `q`·`cardName` 은 `{basic, mid}` 객체 허용 |
| `tabs[].levels` | check 장 탭이 나오는 단계. 초급에서 빠진 탭은 '다른 갈래 보기 ▸' 로 연다 |
| `wrap.quiz[].levels` | 정리 문항 단계(없으면 `['mid','adv']`). 단계마다 **갈래(mode) 없는 문항 3개·kind 3종**(`check()` 가 콘솔에 경고). 초급은 `levels:['basic']` 3문항 |
| `wrap.more[].levels` | 심화 문항(없으면 중·고급, 초급은 없음). 고급이면 정리 모달 '더 생각하기' 가 펼쳐진 채 열린다(`SimLesson.quizMoreOpen()`) |

`showReview(on)` · `reviewShown()` · `counts(lv)` → `{chapters(본 단원), review, quiz}` · `quizMoreOpen()` · `level()`. 열린 채 단계가 바뀌면(`SK.onLevel`) 장 목록을 다시 만들고 지금 장이 없으면 가까운 앞 장.

### teacherNote 표기 규칙
- 복습 장: 첫 줄 '성취기준 코드 미확인 — 단원명만 표기(학년·단원명 확인 필요)', 이어서 그 장에서 일부러 뺀 것·중학교 범위가 불확실한 것을 쓴다. 성취기준 코드 패턴(`[9과…`·`[중…`)을 쓰지 않는다(`tools/audit.py --r9` e).
