# R7 3차 교과 설명 흐름 (기획 C: 구조·연결·수업 시나리오) — 마감본

> 2차 문서를 3차 진단(교사P·Q·R, 학생F·S·T, 디자인A·B·C)으로 고쳐 마감한 것. 3차는 **새 기능 없이 중복 제거·일관성·정확성**. 구현 대상: shared/lesson.js · shared/sim.js · shared/diagram.js · sims/*/lesson.js · index.html.
> 성취기준은 docs/01_커리큘럼분석.md 확인분만: 포물선 [12역학01-02]·[12물리01-04]·[12물리01-05](정성) / 충돌 [12물리01-03] / 렌즈 [12물리03-02] / 슬릿 [12물리03-01]·[12물리03-03] / 궤도 [12역학01-04]·[12역학01-05](케플러는 원운동에만 정량).
> 용어: 실험 = "실험 ①", 설명 = "설명 N장", 운동 에너지 E_k·위치 에너지 E_p·역학적 에너지 E·충격량 I, 궤도 R(천체 반지름)/r(중심에서 거리).

## 0. 3차 핵심 결정
1. **"실험" 이름 중복 해소(진단 7명 일치)**: 머리줄 [설명][실험]은 **화면 전환 + 현재 화면 눌림 표시**만. 실험 고르기는 하단 **[실험 고르기 ▾]** 한 곳(5종 같은 자리·같은 모양). 충돌 머리줄의 "실험 ① … ▾" 알약은 **삭제**, 현재 실험 이름은 예측 띠/상태 칩에만.
2. **무대 위 상태 칩은 1개**("지구 · 수평 발사 · 실행 전" 형식). 산꼭대기·공기 없음·시간 배속·흐른 시간·화면 폭 정보는 ⚙ 설정 '화면 정보'로. 5종 상한 1칩.
3. **예측 띠는 무대 눈금을 가리지 않는다**: 무대 바깥 고정 한 줄(눌러 접기), 포물선 y축은 최고점 기준 자동 확대.
4. **'↓ 이어서' 칩은 본문 위에 띄우지 않는다**: 본문 아래 예약 여백 안에 둔다. 끝까지 내리면 사라짐.
5. **교사 모드 설명 장은 한 화면**: 성취기준·더 보기·교사 메모는 **기본 접힘**(2차의 `teacherOpen` 자동 펼침 폐지). 메모는 "교사 메모 ▸ 펼치기" 글자와 화살표 표시.
6. **교사 차시 진행 띠(이번 차수 유일한 신규 UI)**: '수업 진행 5·10·20·10분' 글자 알약을 **도입·설명·실험·정리 4칸 띠**(현재 칸 강조, 칸을 누르면 이동)로 교체. 타이머는 §7 팀장 결정 1.
7. **식·기호 표기 한 약속**: 분수는 가로 막대 렌더러({{frac:}}), 인라인 '÷'·'/'는 F=Δp/Δt, v=√(GM/r), T=2πr/v, g=GM/r², Δy=λL/d 만이라도 통일, 곱은 가운뎃점(·) 또는 ×. 변수 첨자(x,y,1,2)는 이탤릭, 이름 첨자(k,p,max,0)는 직립을 설명·그림·팝업이 같게.
8. **머리줄 칩 형식 통일**: 설명 머리줄은 "N / M · 장 제목"(단원명은 성취기준 팝업에서만). 세로 820에서도 **'바로 실험' 글자 유지**, 머리 제목과 본문 h1 중복은 한쪽만.
9. **허브 카드 5장 같은 틀**: 모두 [설명부터][바로 실험 ▾]. 갈래 없는 카드는 ▾ 대신 비활성 자리 또는 갈래 칩 이름 통일. 칩 줄은 한 줄 고정("설명 N장 → 실험 → 정리 3문항"), 설명 1장 그림을 축소 썸네일로 재사용.

### 1-2. 키·진행 표시
- `→`·PageDown·Space 다음 / `←`·PageUp·Shift+Space 이전 / Home·End / 숫자 장 점프 / Enter(마지막 장)=실험 시작 / **J·Esc 어느 장에서나 실험으로** / F 전체 화면 / ? 키 안내. 태블릿은 좌우 밀기(60px).
- 클리커 흐름: 설명 마지막 장 → 실험 시작 → 실험 단계 ④ 한 번 더 → 정리 모달, 정리 모달 PageUp = 닫기.
- 진행 표시: 머리줄 칩 "N / M · 장 제목"(누르면 목차 팝오버) + 하단 점 + 읽음 표시. 교사 모드는 그 아래 4칸 진행 띠.
- 입력 중에는 글자 단축키만 무시.

## 2. 설명 ↔ 실험 전환·되돌아가기
```
[허브] -설명부터-> [설명 1..N] -[실험으로]/[실험 시작]/J-> [실험: 예측→실행→비교] -⋯[정리]-> [정리 모달]
   \-바로 실험(?view=sim)---------------------------------^    |          |
            머리줄 [설명] ← 현재 카드의 explainId 장 팝업, [ƒ 식] ← 식 팝업, 해설/정리 문항 "설명 N장 ↩"
```
| 지점 | 동작 |
|---|---|
| 첫 진입 | 설명 1장(쿼리·skip 규칙 §8). 머리줄 [바로 실험] 항상 노출 |
| 설명→실험 | 설명 층을 닫고 실험 화면(DOM 은 그대로 보존). 예측 띠는 접힌 한 줄로 대기 |
| 실험→설명 | 머리줄 [설명]: 현재 카드의 `explainId` 장. 닫으면 그림·값·실행 위치 그대로 |
| 식 팝업 | [ƒ 식]: 식·기호 칩·"지금 값 대입". 기호 칩 → 슬라이더·계기 강조 |
| 결과 해설 | 패널 스크롤 **한 겹** 안. 첫 줄 "오해 → 실험", 끝에 "개념 다시 보기 → 설명 N장" 칩, 5종 같은 자리 |
| 정리 문항 | 답 확인 뒤 "설명 N장 ↩" |
- 실험 선택은 하단 [실험 고르기 ▾] 하나. 머리줄 [실험]을 이미 실험 화면에서 누르면 아무 일 없음(눌린 상태 표시).
- fetch 없음(file:// 안전).

## 3. '해 보기' 연결
- 형식 `try:{preset:'카드id', set:{…}}`. 순서: 설명 닫기 → 카드 적용 → `set` 덮어쓰기 → 해당 슬라이더에 "설명 N장에서 가져온 값" 칩 2초 → 예측 띠를 그 질문으로 펼침(심플은 실행 대기).
- 버튼에 바뀌는 값 표기("각도 30°→60°"). 오해 카드·확인 질문·정리 문항·렌즈 7장 표 행이 모두 같은 API.
- 심화(더 알아보기·식 팝업만): 포물선 H 식·공기 저항 최적 각도, 슬릿 d sinθ≈dy/L, 충돌 반발 계수 e, 궤도 ½mv²=GMm/R, 렌즈 1/s+1/s′=1/f.
- 한계 조건은 한 줄 칩으로만(포물선 R식 h=0·공기 없음 / 슬릿 d≪L, θ 작을 때 / 렌즈 얇은 렌즈 / 궤도 원궤도). 별도 카드는 만들지 않는다(새 기능 금지).

## 4. 정리 단계
- 진입: ⋯ → [정리] 또는 비교 단계 끝 [정리] 칩.
- ① 오늘 기록 값 2~3개 인용 ② 형성평가 3문항(개념·계산·오개념) ③ 한 줄 요약. 학생은 선택 즉시 정오+해설(색+아이콘 병기), 정답은 선택 뒤 DOM. 교사는 [정답 공개]. 하단 [설명 다시 보기][다른 실험][닫기].
- quiz 형식 `{type, q, choices, answerIdx, why, chapter, try?}` 유일 원천.

## 5. 화면 덜어 내기(실험 화면 공통)
- 머리줄: [설명][실험][⚙ 설정][⋯] (설명·실험은 화면 전환·눌림). 심플은 [설명][⋯]에 ƒ·⚙ 흡수.
- 하단 줄 고정 형태: [ƒ 식] 지금 값 1~3개 + 결과 1칸(실행 전 숨김, '실행하면 값이 나와요' 작은 글) + [수치 더 보기] + [실험 고르기 ▾]. 같은 정보를 세 번 보이지 않는다(궤도 속력 슬라이더 라벨·칩 줄·속력 띠는 하나만).
- 충돌: 그래프 상자는 실행 전 낮은 한 줄('실행하면 그래프가 나와요'), 트랙을 키우고 그래프 나올 때 확장. 820 세로 빈 공간 해소.
- 안내 토스트(심플 '자세히 모드는 ⚙…')는 첫 진입 1회, 하단줄 위, 5초 뒤 사라짐(무대 눈금을 가리지 않음).
- ⚙: [화면 심플/자세히] [표시: 화면 정보·에너지 막대·범례] [글자 크기] [기본값].

## 7. 교사 차시 진행 띠 (3차 신규, 최소)
- 머리줄 아래 얇은 띠: [도입][설명][실험][정리], 권장 5·10·20·10분은 칸 툴팁에만. 현재 칸 = 지금 화면(설명 층=설명, 실험=실험, 정리 모달=정리, 도입은 허브/1장). 칸 클릭: 도입·설명=설명 1장, 실험=실험 화면, 정리=정리 모달.
- 타이머는 팀장 결정(§10-1). 구현 시에도 칸 누름 = 시작/일시정지, 경과 분만 표시, 알림음 없음.
- 띠가 한 줄에 안 들어가면 글자만 지우고 현재 칸만 강조.

## 8. 허브 · 첫 방문/재방문 · 쿼리
### 허브
- 헤더: 심플/자세히 + ⋯(키 안내·교사 모드). 흐름 띠(설명→예측→실행→비교→정리)는 카드 위.
- 카드 5장 **같은 구조**: 대표 도식(설명 1장 축소) · 제목 · 질문 한 줄 · 한 줄 칩 "설명 N장 → 실험 → 정리 3문항" · 읽은 장 점 · [설명부터](주) · [바로 실험 ▾](보조).
  - ▾ 메뉴: 슬릿 = 빛/전자, 궤도 = 위성/대포(짧은 이름). 갈래 없는 3종은 ▾ 자리를 비활성(또는 숨김) — 팀장 결정 §10-2.
- 칩 줄바꿈 없음(한 줄 고정 폭).

### 쿼리
| 값 | 뜻 |
|---|---|
| (없음) | skip≠1 이면 설명부터 |
| `?view=explain[&ch=장id]` | 설명(그 장부터), skip 무시 |
| `?view=sim[&preset=id]` | 설명 없이 실험. 갈래는 기존 `mode=값` 그대로 |
| `?simple=1` `?teacher=1` | 자유 조합. 모르는 값 무시 |

### 기억(localStorage, 모두 try/catch, 없어도 정상)
- `physsim.lesson.<slug>.skip`(체크한 경우만) · `.last`(마지막 장) · `.seen`(읽은 장, 허브 점이 읽음) · `.broke`(깨진 오해) · **신규 `.guess`(오해 카드 내 생각, 장별)**. 교사 모드·`?view=explain` 은 skip 무시. 첫 방문은 설명부터. 자동으로 skip 기억 안 함.
- 저장이 막혀도(private·file 제한) 읽음 점·선택 복원만 빠지고 흐름은 동일.

## 9. 한 차시 수업 시나리오 (45분: 도입5·설명10·실험20·정리10)
공통
| 시간 | 화면 | 교사 | 학생(아이패드) |
|---|---|---|---|
| 도입 5 | 허브→설명 1장 | 일상 질문 1개, 진행 띠 [도입] | 질문 읽고 예상 한 줄 |
| 설명 10 | 설명 2~N장 | →/클리커로 한 장씩(장당 약 1분), 오해 카드는 손들기 후 [해 보기] | 스와이프, 기호 탭, 내 생각 고르기 |
| 실험 20 | [실험으로] → 실험 2~3개 | 예측→실행→비교, [ƒ 식] 복습, [실험 고르기 ▾]로 이동 | 값 바꾸기, 기록 |

1. **포물선·에너지**: 도입 "던진 공은 왜 곡선?" / 설명 독립운동→v_x·v_y→최고점 v_y=0(a=g)→E_k+E_p=E(공기 저항 없을 때)→사거리 sin2θ(한계: h=0, 공기 없음) / 실험 ①수평 던지기(v₀ 10→20) ②나는 동안 에너지 ③30°·60°(v₀=20), 심화로 공기 저항 / 정리 최고점 가속도 · h=20 m 낙하 시간 2 s(g=10) · "무거운 공이 먼저".

## 10. 팀장이 정해야 할 것
1. 교사 타이머: 4칸 띠만 넣고 타이머는 뺄지(권장, 새 기능 금지), 넣는다면 경과 분 표시만.
2. 허브 갈래 없는 카드(1·3·5)의 ▾: 비활성 표시 vs 완전 숨김 vs 5장 모두 ▾ 제거하고 갈래를 카드 칩으로(권장 마지막 안: 칩 2개 '빛|전자' 같은 짧은 이름).
3. 하단 이름: [실험 고르기 ▾] 확정 여부(대안 [상황 ▾]). 머리줄 [실험]은 화면 전환·눌림 표시만 둠.
4. 심플 하단줄의 [ƒ]·[⚙]를 ⋯ 로 합칠지(진단 일치, 권장) — 심플 5개 버튼이 4개로.
5. 오해 '내 생각' 저장소: localStorage(기존 키 체계, 권장) vs sessionStorage(공용 기기에서 다음 학생에게 남지 않음). 아이패드 개별 학습 위주면 local, 교실 공용이면 session.
6. 교사 모드 머리줄에서 성취기준 칩 제거(장 안으로)해도 되는가.
7. 실기 아이패드 터치 검증은 캡처만으로 불가 — 마지막에 실기 확인을 팀 밖 일정으로 둘지.

## 11. 3차 점검 체크(기획 쪽 인수 기준)
- 5종에서 머리줄 [실험]과 하단 이름이 다르고 같은 자리인지, 충돌 알약이 없는지.
- 설명 '해 보기' → 실험 상황 즉시 적용 → 해설의 "설명 N장 ↩"이 해당 장으로 가는지(포물선·충돌·궤도 한 번씩, 슬릿·렌즈 한 번씩).
- 교사 모드 설명 장이 기본 접힘으로 스크롤 없이 한 화면인지, '↓ 이어서'가 마지막 줄을 안 가리는지(1280·820 세로).
- 820 세로에서 '바로 실험' 글자, scrollWidth 초과 0.
- 4 화면 크기 × 일반/심플/교사 × 설명·실험·팝업 콘솔 오류 0, 그림 라벨 겹침 점검 스크립트 통과.
