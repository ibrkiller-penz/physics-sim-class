# R7-1 교과 설명 흐름 (기획팀 C: 구조·연결·수업 시나리오)

> 대상: shared/explain.js(설명 화면)·shared/sim.js(연결·팝업)·허브. 문장 원고는 기획팀 A·B 의 5종 원고, 여기서는 **틀과 흐름**만 정한다.
> 성취기준은 docs/01_커리큘럼분석.md 에서 확인된 코드만: 포물선=[12역학01-02]·[12물리01-04](에너지 보존)·[12물리01-05](열로 전환, 정성) / 충돌=[12물리01-03] / 렌즈=[12물리03-02] / 슬릿=[12물리03-01]·[12물리03-03] / 궤도=[12역학01-04]·[12역학01-05]. (교사 진단의 "01-02"는 12물리가 아니라 **12역학**01-02 임에 주의.) 케플러는 "원운동에만 정량, 타원 정량 제외"를 설명에도 그대로 지킨다.

## 1. 설명 화면 공통 구조

### 1-1. 장 종류와 순서 (한 sim 당 6~7장, 장당 1~2분, 한 장 = 한 메시지)
| 순 | 종류(type) | 내용 | 비고 |
|---|---|---|---|
| 1 | `goal` 배우는 것 | 단원 질문 1줄 + 배우는 것 3줄 + 성취기준 칩(확인된 코드만) + "실험은 예측→실행→비교→정리" 한 줄 | 단계 안내는 첫 장에서만 |
| 2 | `concept` 핵심 개념·용어 | 용어 3~5개, 탭하면 작은 팝오버 풀이 | 한 장 강조 3곳 이하 |
| 3 | `formula` 식과 기호 | 큰 식 1줄 + 기호표(기호·뜻·단위) + **적용 조건** 1줄(공기 저항 없음, d≪L 등) | 기호 누르면 그림 화살표 강조(가능하면) |
| 4 | `diagram` 그림 | 인라인 SVG 1장(실험 그림과 같은 색·기호), 제목 + 읽는 법 1줄 | 3·4장은 합칠 수 있음 |
| 5 | `life` 생활 속 예 | 2~3개, 짧게 | 심플에서 생략 |
| 6 | `misconception` 흔한 오개념 | 2~3개, "그렇지 않아요 → 왜" 쌍, 옅은 주홍 띠 + '흔한 오해' 라벨 | |
| 7 | `check` 확인할 질문 | 질문 카드 2~3개, 각 카드에 **[해 보기]** | 마지막 장 = 예측 질문의 원본 |
- 장 데이터: `SimExplain.init({chapters:[{type,id,title,body,eq,svg(fn),terms,questions:[{q,presetId,set,predict}],more,teacherNote}]})` 한 구조. 링크는 장 `id`(문자, 예 `energy`)로 건다. 번호는 표시용이라 장 순서가 바뀌어도 링크가 안 깨진다.
- 교사 메모 `teacherNote` 는 교사 모드에서만 DOM 에 넣는다(학생 모드 DOM 에 정답 없음). 접힘 기본.
- 심화 `more`(식 유도·한계 조건)는 장 하단 접는 블록. 심플에서는 숨김.

### 1-2. 넘김 단위·조작·진행 표시
- 넘김 단위 = **장**. 전자칠판: 큰 글자(본문 1280에서 22px 이상, 1920에서 32px 안팎), 왼쪽 글 40%·오른쪽 그림 60%. 세로 아이패드(폭 900 미만): 위 그림·아래 글, 장 안 세로 스크롤 한 겹 허용, 하단 [이전][다음] 66px 이상.
- 키: `←` `→` `PageUp` `PageDown` `Space`(다음) `Shift+Space`(이전) `Home`/`End`, 숫자 1~7 = 장 점프, `Esc` = 닫기(실험으로 복귀 가능할 때), 마지막 장에서 `Enter` = [실험 시작]. 클리커(PageUp/Down)·좌우 스와이프 지원. 팝업이 열려 있으면 Esc 만 우선.
- 진행 표시: 상단 점(●○○○○○) + "3 / 6 · 식과 기호". 점을 누르면 이동, 읽은 장은 점을 채운다(§6).
- 설명 키와 실험 키(V, 한 장면 앞뒤, 숫자키 카드)는 **서로 다른 화면 상태에서만** 작동: 설명이 열린 동안 실험 키는 잠그고 닫으면 기존 그대로 돌려준다.

## 2. 설명 ↔ 실험 전환 지점
```
[허브 카드] --설명 읽기--> [설명 1..N장] --[실험 시작]--> [실험: 예측→실행→비교→정리]
     \--바로 실험------------------------------------------^     | 도구줄 [설명]
                                                                v
                                             [설명 팝업(해당 장)] --해 보기--> 카드 적용
```
| 지점 | 동작 |
|---|---|
| 첫 진입(기본) | 설명 1장. 재방문 + "다음부터 바로 실험" 저장이면 바로 실험(§6) |
| [실험 시작] (마지막 장, 그리고 모든 장 하단 보조 링크 "바로 실험") | 설명을 닫고 실험 화면. **예측 창은 자동으로 띄우지 않는다**(R6 심플과 같음). 해 보기로 들어왔을 때만 그 질문으로 예측이 열린다 |
| 실험 중 도구줄 [설명] | 공통 팝업 틀(가로 큰 모달 / 세로 전체 시트)로 **현재 카드와 연결된 장**을 연다(`preset.explainId`). 닫으면 그림·값·실행 위치·선택 카드 그대로 |
| 해설 카드 용어 "개념 보기" | 설명 팝업이 그 장으로 열림. 패널 스크롤 안 한 겹 유지(해설 카드 안에 링크만 추가) |
| 정리 질문 | 각 질문에 "설명 [장 제목] 다시 보기" 링크 |
| 실험 화면 상단 칩 | 해 보기로 들어온 경우만 "설명 N장으로 돌아가기" 칩 1개(한 번 닫으면 사라짐), 그림 안 가림 |
- 설명은 별도 HTML 이 아니라 **같은 페이지의 상태**(`html.is-explain`, 실험 중엔 팝업). fetch 없음(file:// 안전), 실험 상태는 DOM 에 남아 잃지 않는다.

## 3. '해 보기' 연결 방식
- 데이터: `questions:[{q:'최고점에서 가속도는?', presetId:4, set:{angle:60}, predict:'…'}]`. `presetId` 는 각 sim 의 기존 실험 카드(0부터).
- 동작 순서 고정: ① 설명 닫기 → ② `SK.applyPreset(presetId)`(값·상황·장면) → ③ `set` 이 있으면 그 변수만 덮어쓰기 → ④ 실행 버튼으로 포커스 → ⑤ `predict` 가 있으면 예측 시트를 그 질문으로 열고, 없으면 실행 대기.
- 카드 하나에 질문이 여러 개일 수 있다(카드와 안 맞으면 `set` 으로 보정). **한 실험에는 질문 하나**: 해 보기 질문 = 그 카드 예측 질문과 같은 문장.
- 현재 카드 순서(구현 시 인덱스 대신 id 로 바꿀 것)
  - 포물선: 수평으로 던지기 / 나는 동안 에너지 / 30°와 60° / 달에서 던지기 / (최고점 화면정지 카드, 이름은 코드에서 확인)
  - 충돌: 같은 질량 튕기기 / 달라붙으면 / 트럭 vs 승용차 / 대포를 쏘면 / 에어백
  - 렌즈: 초점거리 찾기 / 2F에 두기 / 프로젝터 크게 / 돋보기(허상) / 렌즈 반쪽 가리기
  - 슬릿: 빛 5(간격 재기·빨강과 파랑·d 2배·L 멀리·슬릿 하나) + 전자 계열(전자 하나씩·광자·구슬·측정기)
  - 궤도: 시작 선택(뉴턴 대포·ISS·탈출·케플러 자료 등)을 마지막 장 해 보기 3개로 흡수
- 슬릿·궤도의 "무엇을 해 볼까요/알아볼까요" 시작 창은 폐지하고 마지막 장 해 보기로 옮긴다. 실험 중 바꾸기는 [실험 고르기] 팝업.

## 4. 정리 단계(실험 뒤)
- 정리 질문 보드는 화면에 늘 두지 않는다. 도구줄 [정리] → 큰 모달(그림을 가려도 되는 팝업은 정리·기록뿐). 순서:
  1. 오늘 알아낸 것(기록 표에서 값 2~3개 자동 인용)
  2. 확인 문제 3개: 개념 확인 · 값 계산 · 오개념 판정(각각 설명 장 링크). 교사 모드는 [정답 공개] 토글
  3. 한 줄 요약 + 자기 평가 한 줄
- 하단: [설명 다시 보기] [다른 실험 고르기] [닫기].
- 형성평가 문항 원고는 2차. 1차는 기존 정리 질문을 모달로 옮기고 설명 장 링크만 붙인다.

## 5. 모드별 동작
| | 자세히(기본) | 심플(?simple=1) | 교사(?teacher=1) |
|---|---|---|---|
| 첫 진입 | 설명 전 장(6~7) | **축약 3~4장**: 배우는 것·핵심 식+그림·오개념 1개·확인 질문. 생활 예·심화 생략 | 자세히와 같음 + 장마다 발문·예상 답(`teacherNote`, 접힘) |
| [설명] 도구 | 도구줄 아이콘(⚙와 같은 규격) | 같은 위치, 터치 크기만 크게 | 같음 + 장 하단 "수업 진행" 칩(5·10·20·10분) |
| 해 보기 | 카드 적용 + 예측 시트 | 카드 적용, 예측 시트 없이 실행 대기 | 자세히와 같음(예측 자동 열기 옵션 유지) |
- 모드를 바꿔도 보던 장 `id` 는 유지. 심플에 없는 장이면 가장 가까운 앞 장으로.
- 교사 정보는 학생 모드 DOM 에 넣지 않는다.

## 6. 허브 카드 흐름 · 첫 방문/재방문 · 쿼리
### 허브
- 상단 한 줄 흐름: **설명 → 예측 → 실행 → 비교 → 정리 · 한 차시 약 45분(도입5·설명10·실험20·정리10)**.
- 카드 = 제목 + "이 단원에서 배우는 것" 한 줄 + 칩 `① 설명 6장 → ② 실험 5가지` + 버튼 [설명 읽기](주)·[바로 실험](보조). 장식 기호 제거, 1번 카드 "처음이면 여기부터" 칩 유지. 슬릿 카드의 빛/전자 보조 링크는 카드 안 같은 자리 칩으로 두어 높이 통일.
- 읽은 장 수를 점(●●○○○○)으로 표시(저장 가능할 때만).
- 모드·교사 쿼리 조립은 기존 `setTeacher` 패턴을 공유해 [설명 읽기]·[바로 실험] 링크에도 붙인다.

### 쿼리 `?view=` (저장값보다 먼저)
| 값 | 뜻 |
|---|---|
| (없음) | 첫 방문이면 설명, 아니면 저장 규칙대로 |
| `explain` / `explain&ch=<장id>` | 설명 1장부터 / 그 장부터(skip 저장 무시) |
| `sim` / `sim&preset=<n>` | 설명 없이 바로 실험 / 카드 n 적용(교사가 링크로 학생 배포) |
- `?simple=` `?teacher=` 와 자유 조합. 모르는 값은 무시.

### 기억 (localStorage, 전부 try/catch, 없어도 정상 동작)
| 키 | 값 | 용도 |
|---|---|---|
| `physsim.explain.<slug>.seen` | 읽은 장 id 목록 | 허브 점, 이어 읽기 |
| `physsim.explain.<slug>.skip` | 1 | "다음부터 바로 실험" 체크 시 |
| `physsim.explain.<slug>.last` | 마지막 본 장 id | 설명 팝업 복귀 |
- 첫 방문(저장 없음) = 설명부터. `skip`=1 이면 바로 실험하고 도구줄 [설명]만 남김(마지막 장·⚙ 안에서 해제). 교사 모드·`?view=explain` 은 skip 무시. 저장이 막히면 항상 설명부터.

## 7. 한 차시 수업 시나리오 (45분)
공통 시간표
| 시간 | 화면 | 교사 | 학생(아이패드) |
|---|---|---|---|
| 도입 5 | 허브 → 설명 1장 | 일상 사례 1개 발문 | 질문 읽고 예상 한 줄 |
| 설명 10 | 설명 2~6장 | ←→ 로 한 장씩, 오개념 장은 손들기 | 스와이프로 따라 읽기 |
| 실험 20 | [실험 시작] 또는 해 보기 | 카드 2~3개: 예측→실행→비교, 기록 | 값 바꾸기, [기록] |
| 정리 10 | [정리] 모달 | 확인 문제 3개, 정답 공개 | 한 줄 요약 |

1. **포물선·에너지** (12역학01-02, 12물리01-04): 도입 "던진 공은 왜 곡선?" / 설명 독립운동→v_x·v_y→최고점 v_y=0(속도≠0)→E=Ek+Ep(공기 저항 없을 때. 있으면 열로, 총량 보존)→같은 높이 같은 속력·30°와 60° / 실험 나는 동안 에너지→30°와 60°→달에서 / 정리 "최고점 가속도의 방향·크기? 달에서 사거리?".
2. **이중 슬릿** (12물리03-01·03-03): 도입 "빛이 틈을 지나면?" / 설명 파동 용어→경로차 d sinθ=mλ→Δy=λL/d(d≪L, 650 nm=6.5×10⁻⁷ m)→전자 한 개씩 쌓이는 무늬(λ=h/p)→오개념(전자가 둘로 쪼개짐) / 실험 빛 카드(간격 재기→빨강과 파랑→d 2배) 뒤 전자 하나씩 / 정리 "λ·d·L 이 커지면 Δy 는? 한 슬릿만 열면?". 전자 줄무늬는 모형 단위임을 설명에 명시.
3. **충돌·운동량** (12물리01-03): 도입 "큰 차가 더 센 힘을 받나?" / 설명 p=mv(부호)→I=FΔt=Δp→외력 없으면 보존→튕김·붙음 모두 운동량 보존, 운동 에너지는 비탄성에서 감소→작용·반작용 크기 같음→에어백 / 실험 튕기기→달라붙기→트럭 vs 승용차→에어백 / 정리 "붙을 때 줄어든 에너지는 어디로?".
4. **중력·궤도·탈출 속도** (12역학01-04·01-05): 도입 "대포를 더 세게 쏘면?" / 설명 뉴턴 대포→F=GMm/r², 위성은 낙하 중→v=√(GM/r) 질량 무관→탈출 v=√(2GM/r)(지표 기준 7.9·11.2 km/s)→케플러 제3법칙(원운동 정량만, 표 읽기) / 실험 해 보기 3개(대포 속력→ISS 질량만 바꾸기→탈출) / 정리 "ISS 안 사람이 뜨는 이유? 3 km/s 로 쏘면?".
5. **볼록렌즈** (12물리03-02): 도입 "돋보기로 종이를 태우는 이유" / 설명 굴절·F·2F→작도 3광선→물체 위치 3구간 표→(심화 접기) 1/s+1/s′=1/f, 실상 s′>0·허상 s′<0, m=−s′/s→오개념(렌즈 반쪽을 가려도 상은 어두워질 뿐) / 실험 초점거리 찾기→2F→돋보기(허상은 스크린에 안 맺힘)→반쪽 가리기 / 정리 "s=8 cm 이면 스크린에 상이 맺히나?".

## 8. 팀장이 정해야 할 것
