# R7 2차 교과 설명 흐름 (기획 C: 구조·연결·수업 시나리오)

> 1차(R7-1) 문서를 2차 진단(교사P·Q·R, 학생F·S·T, 디자인A·B·C)으로 개정한 것. 구현 대상: shared/lesson.js(설명 층) · shared/sim.js(머리줄·예측·식 팝업·정리 모달) · shared/diagram.js · sims/*/lesson.js · index.html(허브).
> 문장 원고는 기획 A·B 담당, 여기서는 **틀·연결·흐름·시나리오**만 정한다. 성취기준은 docs/01_커리큘럼분석.md 확인분만: 포물선 [12역학01-02]·[12물리01-04]·[12물리01-05](정성) / 충돌 [12물리01-03] / 렌즈 [12물리03-02] / 슬릿 [12물리03-01]·[12물리03-03] / 궤도 [12역학01-04]·[12역학01-05]. 케플러는 "원운동에만 정량"을 지킨다.
> 용어 통일: 학생 화면에서 "카드"는 **"실험 ①"**, 설명 장은 **"설명 N장"**.

## 0. 2차 핵심 결정 요약
1. **한 장 = 한 화면**: 장당 본문 3문단(문장 ≤3)·식 ≤2·그림 1. 넘치는 것은 `more`(더 보기 접기)나 장 분할. 성취기준은 접힌 칩 한 개 "성취기준 N ▸".
2. **실험 화면 [식 ƒ] 팝업**: 현재 실험 ↔ 설명 장의 식·기호표를 작은 팝업으로. 기호를 누르면 슬라이더·계기를 강조(§3).
3. **정리 퀴즈는 한 곳**: lesson.js `quiz` 3문항이 유일한 원천. 설명 끝 장에서는 뺀다. 실험 뒤 [정리] 모달에서만 연다(§5).
4. **예측은 패널을 덮지 않는다**: 패널 오른쪽 위가 아니라 그림 아래 한 줄 띠(§6).
5. **머리줄 4개**: [설명] [실험 ▾] [⚙] [⋯]. 기록·정리·도움말·전체 화면은 ⋯ 안(기록 n/5는 배지).
6. **설명→실험 바로가기 상시 노출**: 첫 진입에도 머리줄 [바로 실험]. (1차의 "첫 진입 숨김" 폐지.)
7. 갈래(빛/전자, 궤도 유형)는 **허브 칩·설명 마지막 장 선택에서 받아 시트 생략**(§8).

## 1. 설명 화면 공통 구조

### 1-1. 장 종류·순서 (장 id 로 링크, 번호는 표시용)
| 순 | type | 내용 | 한 화면 규칙 |
|---|---|---|---|
| 1 | `goal` | 단원 질문 + 배우는 것 **3줄 이하** | 성취기준은 접힌 칩 1개. 글자 단계·단계 안내 문구는 ⚙로 |
| 2 | `concept` | 핵심 용어 3~5개(점선 밑줄 탭=팝오버) | 강조 3곳 이하 |
| 3 | `formula` | 식 ≤2 + 기호표(기호·뜻·단위) + 적용 조건 1줄 | 기호표는 식 카드 아래 칩 열(탭=뜻). 아래 §3 의 `sym` 데이터를 겸함 |
| 4 | `diagram` | 인라인 SVG 1장, 읽는 법 1줄 | 세로 화면 그림 높이 ≤35vh, 라벨 겹침 금지 |
| 5 | `life` | 생활 예 2~3개 | `more` 접기, 심플 생략 |
| 6 | `misconception` | 오해 2~4개 = **오해 카드** | 카드마다 "내 생각 → [해 보기] → 결과 문장"(§4) |
| 7 | `check` | 확인 질문 | **갈래 탭**(슬릿: 빛/전자) 탭당 ≤5개. 질문마다 [해 보기] 1개 + 바뀌는 변수 칩 |
- **'실험 뒤 정리' 장(wrap)은 첫 진입 순서에서 제외**한다. 설명 장 수 = 1~7 종류(9~11장→분할 후에도 실험 전 장만). 정리 내용은 [정리] 모달로만(§5).
- 긴 장 분할 규칙: 본문이 칸 높이를 넘으면(개발 중 콘솔 경고) 장을 둘로 나눈다. 예: 렌즈 6장 표 → "그림"/"표 정리"(열 4개: 위치·상 거리·크기·종류, f=10 cm 예는 조건 한 줄), 궤도 케플러 → 법칙 1개당 1장, 슬릿 1장 목표 목록 3개 이하.
- `teacherNote`·정답은 교사 모드에서만 DOM 에 넣는다(학생 DOM 에 없음).
- 용어·기호는 sim별 용어 사전(`terms` + `sym`)을 **해설·퀴즈·툴팁·식 팝업이 같이 참조**한다(같은 말·같은 기호). 식 조판은 공통 렌더러 하나(분수 쌓기, 위·아래 첨자 같은 x, 변수 이탤릭, 단위·숫자 로만체), 도식 라벨도 같은 규칙.

### 1-2. 넘김 단위·키·진행 표시
- 넘김 단위 = **장**. 가로: 왼쪽 글·오른쪽 그림. 세로(<900): **장 번호→제목→글→그림** 순서(그림이 제목을 밀지 않음), 하단 [이전][다음] ≥44px.
- 키(설명 층): `→` `PageDown` `Space` 다음 · `←` `PageUp` `Shift+Space` 이전 · `Home`/`End` · 숫자 장 점프 · `Enter` 마지막 장 = [실험 시작] · **`J` 어느 장에서나 실험으로** · `Esc` 도움 닫기(2차: 첫 진입에서도 실험으로 나가기 허용 — 막지 않는다) · `F` 전체 화면 · `?` 키 안내.
- **클리커 통일(PageDown/PageUp)**: 설명 끝 → [실험 시작] → 실험 단계(예측→실행→비교) → [정리] 모달 순으로 한 키로 이어 넘긴다(전역 "다음/이전 흐름"). 화면 아래에 현재 위치 한 줄("설명 3/7 → 실험 → 정리").
- 진행 표시: 머리줄 보조 문구는 "3 / 7 · 단원 이름"만(장 제목은 본문에만, 중복 제거). 이 표시를 누르면 **장 이름 목차 팝업**(장 건너뛰기), 하단 점은 보조. 머리줄에 항상 [바로 실험].
- 설명 키와 실험 키는 서로 다른 상태에서만 동작. 단 **실험 중 예측 창이 열려 있어도 Space(예측 없이 실행)·←→(단계)는 동작**한다. 입력칸 자동 포커스는 없애고, 입력 중에는 글자 단축키만 무시한다.

## 2. 설명 ↔ 실험 전환·되돌아가기 지점
```
[허브] --설명부터--> [설명 1..N] --[실험 시작]/[바로 실험]--> [실험: 예측→실행→비교]
   \--바로 실험(갈래칩)-----------------------------------------^   |  |
                                                  머리줄 [설명]/[식 ƒ]/칩 '설명 N장 ↩'  |
                                                                 v  v
                              [설명 팝업(해당 장)] / [식 팝업] --해 보기--> 값 적용 --> [정리 모달]
```
| 지점 | 동작 |
|---|---|
| 첫 진입 | 설명 1장. 머리줄 [바로 실험]은 항상 보인다. 저장된 skip 이면 바로 실험 |
| [실험 시작] | 설명 닫고 실험 화면. 예측 창은 **접힌 띠로 대기**(자동 팝업 없음). 해 보기로 오면 그 질문으로 띠가 펼쳐짐 |
| 실험 [설명] | 현재 카드의 `explainId` 장을 큰 팝업(세로는 전체 시트)으로. 닫으면 그림·값·실행 위치·선택 그대로 |
| 실험 [식 ƒ] | 그 장의 식·기호표 작은 팝업(§3). [설명 N장 ↩] 칩으로 전체 장 연결 |
| 해설 카드 | 해설 문장은 설명 장의 `terms`·기호를 가져와 쓴다. "개념 다시 보기 → 설명 N장"(해설은 **패널 스크롤 안 한 겹** 유지, 첫 줄은 "오해: … → 실험: …") |
| 정리 문항 | 문항마다 "설명 N장 ↩" 칩(답 확인 뒤 표시). 학생에게 정답 힌트 문구 없음 |
| 상단 칩 | 해 보기로 온 경우 "설명 N장 ↩" 1개(한 번 닫으면 사라짐). 항상 보이는 '‹ 설명 N장' 고정 칩은 [설명] 버튼 옆으로 통합 |
- 설명은 같은 페이지의 상태(`html.is-lesson`), 실험 중엔 팝업. fetch 없음(file:// 안전).

## 3. 식 팝업 · 기호 연결 (신설)
- 데이터(lesson.js): 장마다 `sym:[{k:'v0', label:'v₀', mean:'처음 속력', unit:'m/s', target:'slider:v0' | 'meter:vx' | 'bar:Ek', note?}]`. `target` 키는 sim.js 가 SK.flash 로 강조할 슬라이더·계기·막대의 data-var 와 같은 문자열.
- 실험 머리줄 [식 ƒ]: 현재 실험 카드의 `explainId` 장의 `eq`(식 1~2줄) + 기호 칩 + **"지금 값 대입" 한 줄**(예: v₀=10, h=20 → t=√(2h/g)=2.0 s). 기호 칩(≥44px) 한 번 탭 → 해당 슬라이더·계기를 단원색 테두리로 1.5초 깜빡이고 말풍선("v₀ = 처음 속력 슬라이더"). 팝업은 그림·슬라이더를 덮지 않는 가장자리(가로=그림 왼쪽 아래, 세로=하단 시트).
- 설명 장에서도 식 속 기호를 누르면 기호표 해당 줄 강조 + 그림 화살표 강조. 계기판 기호(점선 밑줄) 탭 → [식 ƒ]가 그 기호 위치로 열림. 렌즈 배율 칸은 "배율 0.5배 · 거꾸로 (m = −s′/s = −0.5)"처럼 식과 같은 기호로 병기.
- **정답 누출 방지**: 슬릿 이론 Δy 는 기록 후에만 식 팝업의 대입 결과로 보인다(칩 잠금 문구 제거).
- 심화(교육과정 밖, "더 알아보기" 접기): 포물선 H=v₀²sin²θ/2g·공기 저항 최적 각도(<45°), 슬릿 d sinθ≈dy/L, 충돌 반발 계수 e, 궤도 ½mv²=GMm/R, 렌즈 1/s+1/s′=1/f. 식 팝업과 교사 메모에서만 노출.

## 4. '해 보기' 연결 · 오해 카드
- 형식 `try:{preset:'id', set:{…}}` (preset 은 카드 id 문자열, 순서 변경에 안 깨짐). 순서 고정: ① 설명 닫기 → ② 카드 적용 → ③ `set` 덮어쓰기 → ④ 해당 슬라이더에 "설명 N장에서 가져온 값" 칩 2초 → ⑤ 예측 띠를 그 질문으로 펼침(심플은 실행 대기).
- 버튼에 바뀌는 값을 쓴다: "각도 30°→60°".
- **오해 카드 3줄 규칙**: ① 내 생각(두 선택) ② [해 보기] ③ 결과 문장. 실험에서 돌아오면 같은 카드에 "깨졌어요 ✓ + 실험 결과 한 줄"을 표시(저장 가능하면 유지). 장당 오해 1개 이상에 실험을 직결.
- 보강할 해 보기(진단 반영)
  - 포물선: 수평 속도 10→20이어도 낙하 시간 같음(실험 ①, 해설 후속 안내) · 최고점 a≠0 아님(a=g) · 30°↔60° 사거리 같음(v₀=20) · h=10 m 에서 최적 각도 ≠45°. 문항 g=10 은 [이 값으로 해 보기]가 g=10 을 직접 적용.
  - 충돌: "운동량은 부호가 있는 합" — m₁=m₂=1, v₁=+2, v₂=−2 달라붙기 → 합 0·정지·운동 에너지 전부 열. (v₂ 슬라이더가 ±3 까지 있으므로 새 카드 없이 `set` 으로 가능; 없으면 카드 추가) 질문 "정지하면 운동량이 사라졌나?"
  - 궤도: 오해 4번을 "높은 궤도의 위성이 더 빨리 돈다"로 교체(v=√(GM/r): ISS 7.7 vs 정지 3.1 km/s, 위성 모드 높이 슬라이더로 확인). 기호 "R 천체 반지름, r 중심에서 거리(r≥R)"를 기호표에 명시, 산 높이 20 km = r=R+20 km. 정리 문장은 "위성 질량과는 무관, 중심 천체 질량 M과 거리 r에 따라 결정"으로 정정(학생F 지적). 질문 "v를 √2배 하면?"
  - 렌즈: 오해 4가지 각각 [해 보기]+결과 문장, 가림판은 "위/아래 절반" 상태 적용.
  - 슬릿: 빛/전자 탭, "전자는 입자이니 두 줄 무늬?"를 전자 하나씩 쌓기로.
- 사실 정정(원고 담당에 전달): 포물선 심화 문항의 "공기 저항 시 역학적 에너지 일정" → "줄어들고 줄어든 만큼 열, 총에너지 보존"; 교사 메모에 "최적 각도 45°보다 작음(약 35~40°)" 추가.

## 5. 정리 단계 (실험 뒤, 모달 한 곳)
- 진입: 머리줄 ⋯ → [정리] (또는 실험 비교 단계 끝의 [정리] 칩, 클리커 다음 흐름).
- 구성: ① 오늘 기록에서 값 2~3개 자동 인용 ② **형성평가 3문항**(개념 1 · 계산 1 · 오개념 판정 1) ③ 한 줄 요약. 기록 표는 정리 모달 안 탭.
- `quiz` 데이터 통일: `{type:'choice'|'short', q, choices[], answerIdx(0부터), why, chapter:'장id', try?:{…}}`. 심화 문항은 `more`로 분리("더 해 보기", 교사 공개 쪽). 표시 번호는 ①②③ 하나로 통일(내부 인덱스는 0 기준).
- 학생: 한 열, 문항 1/3 씩, 보기를 큰 카드(≥44px)로 고르면 즉시 정오+해설(정답은 색+아이콘 병기, 색만 구분 금지)+"설명 N장 ↩". 정답은 선택 후에 DOM 에 넣는다.
- 교사: [정답 공개] 전체 한 번(문항별도 가능). 학생 DOM 에는 정답이 없고 교사 모드에서만 생성. 공개 뒤 해당 장 링크.
- 하단: [설명 다시 보기] [다른 실험] [닫기].

## 6. 화면 덜어 내기와 예측 위치 (2차)
- 머리줄: [설명] [실험 ▾] [⚙] [⋯]. 1280 이하에서도 설명·실험 글자 라벨 유지(학생F). ⋯ 안: 기록 n/5 · 정리 · 도움말 · 전체 화면 · 시간 배속. 심플은 [설명][⋯]만.
- 단계 띠는 한 칩("1 예측")으로 줄이고 머리줄 아래 얇게. 예측 단계가 끝나면 자동 접힘.
- **예측 창**: 패널 위 dock 폐지 → 그림 아래 한 줄 띠(질문 한 줄 + 보기 칩 가로 + [예측 없이 실행] 글자 링크). 패널은 항상 보이고 조작 가능(예측 중 값은 띠에 "v₀=10 m/s, h=20 m" 한 줄 요약). 세로는 하단 얇은 접힘 띠, 펼치면 시트 + 패널 하단 여백. 패널을 만지면 자동 접힘. [예측하기] 버튼은 하나.
- 계기판 기본 핵심 1~2개, 나머지는 [수치 더 보기]. 에너지 막대·범례는 기본 꺼짐(⚙ 화면 표시). 막대 라벨은 "운동 에너지 E_k / 위치 에너지 E_p / 역학적 에너지 E"(설명과 같은 말).
- ⚙: [화면(심플/자세히)] [표시] [글자 크기(보통/크게)] 그룹, 항목 이름 짧게+한 줄 설명, 2열 칩, [기본값으로].
- [실험 ▾]: 항목마다 "확인하는 개념 + 설명 N장" 칩, 현재·완료 표시.

## 7. 모드별 동작
| | 자세히(기본) | 심플(?simple=1) | 교사(?teacher=1) |
|---|---|---|---|
| 설명 장 | 전 장(장당 6~8 이하), 더 보기 접기 | **축약 3~4장**: 배우는 것·식+그림·오해 1·확인 질문. 생활 예·심화 생략 | 자세히와 같음 + 장 하단 `teacherNote`(접힘) + 정답 공개 |
| 머리줄 | [설명][실험 ▾][⚙][⋯] | [설명][⋯], 단계 안내 최소 | 같음 + 차시 진행 띠 |
| 식 팝업 | 식+기호 칩+대입 한 줄 | 식 1줄+기호 칩만 | 같음 + 심화 접기 |
| 해 보기 | 카드 적용+예측 띠 | 카드 적용, 예측 없이 실행 대기 | 자세히 + [이 장 해 보기를 칠판에 띄우기] 일괄 |
| 정리 | 3문항 즉시 해설 | 3문항, 해설 짧게 | [정답 공개] |
- 교사 **차시 진행 띠**(머리줄 아래 얇게): 도입·설명·실험·정리 4칸, 칸을 누르면 설명 1장/실험/정리 모달로 이동, 권장 5·10·20·10분 표시, 타이머 선택. 설명 장에 소요 안내("설명 10분 ≈ 장당 1분")는 교사 모드에만.
- 모드를 바꿔도 보던 장 id 유지(심플에 없으면 앞 장).

## 8. 허브 · 첫 방문/재방문 · 쿼리
### 허브
- 헤더: 심플/자세히만 두고 키보드 안내·교사 모드는 ⋯ 로(교사 모드 끔 글자 잘림 해소). 흐름 띠(설명 → 예측 → 실행 → 비교 → 정리)는 카드 위로 올려 글자 키움.
- 카드: 제목 + 질문 한 줄 + 칩 한 줄 "설명 9장 · 실험 3가지 · 정리 3문항 · 약 45분" + [설명부터](주) + [바로 실험 ▾](보조). 갈래가 있는 슬릿·궤도는 [바로 실험] 안 분할 단추(빛/전자, 궤도 유형)로 합쳐 5장 높이를 맞춘다. 읽은 장 점(저장 가능할 때).
- 카드 하단 또는 교사 모드: [차시 안내] 링크(도입 질문, 시간 배분, 정답 공개 위치 = 본 문서 §9 요약).
- 궤도 카드는 12역학(진로 선택) 코드 표기를 12물리와 구분.

### 쿼리
| 값 | 뜻 |
|---|---|
| (없음) | 저장 skip 이 1 이 아니면 설명부터 |
| `?view=explain[&ch=장id]` | 설명 1장/그 장부터(skip 무시) |
| `?view=sim[&preset=id][&branch=light|electron|…]` | 설명 없이 바로 실험. **갈래 시트 없이** branch 또는 마지막 갈래로 진입 |
- `?simple=` `?teacher=` 와 자유 조합. 모르는 값 무시. 갈래 시트(실험 고르기)는 [실험 ▾]를 누를 때만 연다.

### 기억(localStorage, 모두 try/catch, 없어도 정상)
- 1차 구현 키 `physsim.lesson.<slug>.skip`(1=다음부터 바로 실험) 유지, 추가 `…last`(마지막 장 id), `…seen`(읽은 장 목록), `…broke`(깨진 오해 id). 교사 모드·`?view=explain` 은 skip 무시. 첫 방문은 설명부터, 건너뛰기는 **체크한 경우만** 기억(자동 기억 안 함).

## 9. 한 차시 수업 시나리오 (45분: 도입5·설명10·실험20·정리10)
공통 흐름
| 시간 | 화면 | 교사 | 학생(아이패드) |
|---|---|---|---|
| 도입 5 | 허브→설명 1장 | 일상 질문 1개, [차시 진행 띠] 시작 | 질문 읽고 예상 한 줄 |
| 설명 10 | 설명 2~N장 | →/클리커로 한 장씩, 오해 카드는 손들기 후 [해 보기] | 스와이프로 읽기, 기호 탭 |
| 실험 20 | [실험 시작] → 실험 2~3가지 | 예측→실행→비교, [식 ƒ]로 식 복습 | 값 바꾸기, 기록 |
| 정리 10 | [정리] 모달 3문항 | [정답 공개], 설명 N장 칩으로 복습 | 선택→즉시 해설, 한 줄 요약 |

1. **포물선·에너지**: 도입 "던진 공은 왜 곡선?" / 설명 독립운동→v_x·v_y→최고점 v_y=0(a=g)→E_k+E_p=E(공기 저항 없을 때)→사거리 sin2θ 대칭 / 실험 ①수평 던지기(v₀ 10→20 후속) ②나는 동안 에너지 ③30°와 60°(v₀=20) / 정리 개념:최고점 가속도 · 계산:h=20, g=10 낙하 시간 2 s · 오개념:"무거운 공이 먼저 떨어진다".
2. **이중 슬릿**: 도입 "빛이 좁은 틈을 지나면?" / 설명 간섭·경로차→Δy=λL/d(d≪L)→전자 한 개씩 쌓임 / 실험 빛(간격 재기→빨강과 파랑→d 2배) 뒤 전자 하나씩(허브 갈래 칩으로 진입) / 정리 개념:λ·d·L 이 커지면 Δy · 계산:Δy 구하기 · 오개념:"전자가 둘로 쪼개져 두 슬릿을 지난다". 전자 줄무늬는 모형 단위임을 설명에 명시.
3. **충돌·운동량**: 도입 "큰 차가 더 센 힘을 받나?" / 설명 p=mv(부호)→I=FΔt=Δp→보존·에너지 감소→작용·반작용 / 실험 같은 질량 튕기기→달라붙기(+2, −2)→트럭 vs 승용차(Δv −2/+6, 나중 속도 +4 병기) / 정리 개념:보존 조건 · 계산:달라붙은 뒤 속도 · 오개념:"정지하면 운동량이 사라진다".
4. **중력·궤도**: 도입 "대포를 더 세게 쏘면?" / 설명 F=GMm/r²→v=√(GM/r)(R 천체, r 궤도 구분)→탈출 속도→케플러(원운동만) / 실험 대포 속력 7.9→ISS(높이)→탈출 11.2 / 정리 개념:원궤도 속력 의존(M, r) · 계산:v 비교 · 오개념:"높은 궤도일수록 빠르다".
5. **볼록렌즈**: 도입 "돋보기로 종이를 태우는 이유" / 설명 굴절·F→세 광선→물체 위치 세 구간 표(장 분리)→배율 / 실험 초점거리 찾기→2F→돋보기(허상) 가림판 / 정리 개념:실상·허상 · 값:s=30 cm,f=10 cm 의 상 거리 · 오개념:"렌즈 반을 가리면 상 반이 사라진다".

## 11. 팀장 결정 반영 메모 (R7 2차 §1-10 → shared 구현, UI팀1 2026-10-30)
1. 정리 장(wrap)은 설명 순서에서 뺐다(`visible()` 제외, 데이터는 정리 모달 형성평가 3문항용). 설명 장 수 = 실험 전 장 수(허브 칩 9·11·9·11·11).
2. 클리커: 설명 마지막 장 →·PageDown·Space = 실험 시작 · 실험 단계 ④ 에서 한 번 더 = 정리 모달 · 정리 모달 PageUp = 닫기 · 기록 모달 PageDown = 다음 단계. 위치 표시줄·타이머는 3차.
3. 렌즈 결상 공식은 본문 정성 + 더 알아보기·식 팝업 심화(`more.eq`) — 식 팝업은 `eq` 가 있는 장만 쓰므로 렌즈는 식 장(magnify 등)에 `eq` 를 둘 때 [ƒ] 가 보인다.
4. 교사 차시 진행 띠·타이머는 3차. 2차는 설명 머리줄 '수업 진행 5·10·20·10분' 칩 + 정리 [정답 공개].
5. 갈래 쿼리는 새 `branch=` 없이 기존 `mode=`. `?view=sim` 시트 자동 열기 삭제, 허브 슬릿·궤도 [바로 실험 ▾] 분할 단추.
6. g = 10 문항은 [이 값으로 해 보기] = `{preset:0, set:{gEarth:10, h:20, v0:10, theta:0}}` 로 맞춘다(해설에 'g = 10 으로 계산').
7. 학생 문구 '카드 ①' → '실험 ①' (머리줄 칩·설명 확인 질문 카드). 해설·정리 문구는 각 sim 담당이 바꾼다.
8. 데이터 형식·API 는 `docs/SIMKIT.md §0R7-2`.
