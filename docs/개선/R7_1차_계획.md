## 1. 이번 차수 설계

### 1-1. 원칙 (10줄)
1. **설명 → 실험.** 페이지를 열면 교과 설명(장 넘김)이 먼저, [실험 시작]으로 실험. 실험 중 [설명]으로 돌아오고, 닫으면 그림·값·실행 위치 그대로.
2. **설명은 같은 페이지의 한 층.** 별도 HTML·fetch 없음. `html.is-lesson` 이면 실험 DOM 위에 전체 화면 층 `.lesson` 이 덮인다(실험 DOM 은 살아 있음). 첫 진입이든 실험 중이든 **같은 층 하나**(두 모양으로 따로 그리지 않는다 — 전자칠판은 큰 글자가 필요하고, 실험 상태는 DOM 에 남으므로 잃지 않는다).
3. **기능은 없애지 않고 자리만 옮긴다.** 단계·기록·정리·실험 카드·토글·교사 도구는 전부 남고, 버튼 → 팝업으로 간다. 키 조작 전부 유지.
4. **팝업 틀은 하나.** `SK.pop` — 팝오버(가로, 버튼 옆)·시트(세로, 아래)·모달(정리·기록 표만) 세 모양, 같은 머리줄(제목 + ✕), Esc·바깥 누르기·✕, **하나만 열림**, 포커스 복귀. 열린 동안 실험 그림은 가리지 않는다(모달 둘만 예외).
5. **늘 보이는 것은 7가지뿐.** 머리줄(제목·현재 카드 칩·도구 아이콘), 진행 점 한 줄, 실험 그림, 핵심 수치 2~3칸, [▶ 실행]과 작은 장면·속도 단추, 패널의 '수치 바꾸기'(+ 상황 칩 한 줄), [실험 ▾].
6. **⚙ 설정 = 표시·환경·기본값.** `SECTION_TITLES.tools`·`deep` 의 컨트롤 노드를 **그대로 옮긴다**(R6 심플 레일과 같은 appendChild 방식, 핸들러·값·기억 유지). 심플에서도 같은 ⚙.
7. **패널은 스크롤 없이.** 1280×720·1180×820 에서 '아래에 더 있어요' 가 뜨지 않는 것이 검사 항목. values 슬라이더 3개 + 상황 1줄까지.
8. **심플 ⊂ 자세히.** 도구 줄·⚙·[설명]·[실험 ▾]·팝업 틀은 두 모드가 같은 것을 쓴다. 차이는 패널 슬라이더 수·계기판 수·설명 장 수(심플 축약)뿐.
9. **한 실험에 질문 하나.** 설명 마지막 장의 '해 보기' 질문 = 그 카드의 예측 질문. 해 보기 → 설명 닫기 → 카드 적용(+값 덮어쓰기) → 예측(자세히만) → 실행 대기.
10. **정답은 학생 DOM 에 없다.** 교사 메모·정답 공개는 교사 모드에서만 DOM 에 넣는다(R5 규칙 유지).

### 1-3. 공통 팝업 틀 `SK.pop` (shared/sim.js + base.css `.pop`)

```js
var p = SK.pop({
  id: 'settings',            // 같은 id 로 다시 열면 토글
  kind: 'popover',           // 'popover'(가로: anchor 옆) | 'sheet'(아래에서 올라옴) | 'dock'(가로: 패널 자리, 세로: sheet) | 'modal'(정리·기록 표만)
  anchor: btnEl,             // popover 의 기준 단추 (닫을 때 포커스 복귀 대상)
  title: '설정', body: nodeOrArray, foot: [btn...],   // body 는 노드 이동 가능(닫을 때 원래 자리로 되돌림: {restore:true})
  onClose: fn, onKey: fn(e)  // 열린 동안 키는 Esc 먼저, 나머지는 onKey 에 위임
});
p.close(); SK.pop.close(); SK.pop.open === 'settings'
```
- **모양 규칙**: 머리줄 = 제목(32u/500) + ✕(48u); 본문 스크롤 한 겹(`overscroll-behavior: contain`); 바닥줄은 옵션. 폭: popover 400u(최대 92vw), dock = 패널 폭 570u, sheet = 화면 폭 − 2×gap, modal = 1250×700u(그림 자리). 세로(폭 < 900)에서는 popover·dock 이 **자동으로 sheet** (최대 높이 60%, 그림 위쪽 40% 보임).
- **동작 규칙**: 하나만 열림(다른 것을 열면 앞 것 닫힘), Esc·바깥 누르기(`pointerdown` capture, 팝업·anchor 안은 제외)·✕ 모두 같음, 열린 동안 anchor 단추는 `aria-expanded=true` + `--sim-tint` 바탕, 닫으면 anchor 로 포커스 복귀, Tab 은 팝업 안에서 순환. `prefers-reduced-motion` 이면 애니메이션 0.
- **통합**: 심플 `.sheet`(more·presets)·`info-pop`·`rec-full`·속도 `pop-menu`·`그 밖의 기능` 메뉴를 전부 이 틀로. `SK.dialog`(확인창, Enter/Esc)는 **그대로** 둔다(확인용). 예측 `SK.predict`·`SK.chooseMode` 는 창 내용은 그대로, 바깥 상자만 `kind:'dock'` 으로 바꾼다(`modal` 변수의 `type:'predict'|'mode'` 와 `onKey` 는 유지 — 기존 키 흐름 보존).
- **z**: `--z-sheet 40`(popover·sheet·dock) · `--z-modal 50`(modal·dialog) · `--z-notice 55`. 토큰은 있음.
- **그림 비가림 검사**: popover 는 anchor 의 아래·오른쪽 정렬 중 무대 사각형(`SK.el.stage.getBoundingClientRect()`)과 겹치지 않는 쪽을 고르고, 둘 다 겹치면 패널 자리(dock)로.

- 모양: 가로 1180+ 는 버튼 아래 오른쪽 정렬 팝오버 400u(패널 위에 겹쳐도 그림은 안 가림), 세로는 아래 시트.

| [정리] 모달의 질문 | 각 `think` 카드 아래 '설명 ○○ 다시 보기' (`think({... lesson:'energy'})` 옵션) |
| 저장 키 | `physsim.lesson.<slug>.seen`(읽은 장 id 목록, 허브 점) · `.skip`('1' 체크 시만) · `.last`(마지막 장 id). 전부 try/catch |

### 1-8. 팀장 결정 (기획·진단이 물은 것)
1. **성취기준 코드 확정**(docs/01 §3 표에서 확인): 포물선 `[12역학01-02]`·`[12물리01-04]`(연계 `[12물리01-05]`, 정성) / 충돌 `[12물리01-03]` / 슬릿 `[12물리03-01]`·`[12전자03-01]`(연계 `[12물리03-03]`·`[12전자03-02]`) / 궤도 `[12역학01-03]`·`[12역학01-04]`·`[12역학01-05]`(sim `standards` 와 같음, 케플러는 원운동 정량만) / 렌즈 `[12물리03-02]`(연계 `[12전자02-02]`). 교사P 가 쓴 '12물리01-02'는 **쓰지 않는다**(등가속도 운동·교통안전 성취기준이라 포물선과 맞지 않음). 칩에는 과목 약칭을 붙인다('역학 01-02' 식이 아니라 `[12역학01-02]` 코드 그대로 + `title` 에 과목명).

6. **새 프리셋 추가 안 함**(카드 5장 제한 유지): 기획이 제안한 `x-mass`·`x-air`·`x-stick31`·V 4000·s=30·s=f 는 전부 '카드 + `set` 덮어쓰기'.

9. **전자 모드 '모형 단위'**: 스크린 라벨 상시 표시(B7, 문구만). **궤도 힌트 '지표 기준'**(C5). **에너지 막대 'm 1.0 kg'**(A3). 셋 다 물리 계산 아님.
