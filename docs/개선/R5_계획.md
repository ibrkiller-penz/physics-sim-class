### 0-1. 교사P 물리 지적 검산 (팀장)
- 사거리 R = v₀² sin2θ / g = 400 × 1 / 9.8 = **40.8 m** · 달 g 1.62 → 9.8/1.62 = **6.05배** ✓
- 전자 드브로이 λ = h/√(2 m e V) = 6.626×10⁻³⁴ / √(2 × 9.109×10⁻³¹ × 1.602×10⁻¹⁹ × 1000) = 6.626×10⁻³⁴ / 1.709×10⁻²³ = **38.8 pm** ✓
- 원 궤도 v = √(g R) = √(9.8 × 6.371×10⁶) = **7.90 km/s** ✓ · 줄무늬 Δy = λL/d = 650×10⁻⁹ × 2.0 / 0.25×10⁻³ = **5.2 mm** ✓
- 결론: **계산·식 오류 0**. 교사P 의 지적은 전부 표기·문구(단위, 2f/2F, a.u., '멈춤', 트럭 3 kg)이며 물리 함수(`pe-physics.js`·각 sim step)는 이번에도 건드리지 않는다.

### 1-2. 예측·모드 창 (가장 많이 지적된 것)
1. **창을 낮춘다**: `.predict`·`.mode-card` `max-height: 42%`(실험 화면 기준), 패딩 16/24u → 12/20u, 질문 34u → 30u, 보기 2열 유지, 보기 높이 `auto`(③ 한 줄이면 한 줄). 1920 기준 창 높이 ≈ 370u → **≤ 280u**.
2. **자리 옵션**: `SK.predict({place: 'bottom'|'top'})`·`SK.modeCard({place})`. 기본 `bottom`(지금과 같음). sim 이 장면에 맞춰 고른다 — projectile 숫자 예측은 `top`(하늘이 비어 있고 x축 눈금이 보여야 함), 나머지는 §2 각 sim 항목.

### 1-3. 교사 발표 (전자칠판)
- 기록 표 **'표 크게 보기'**: `.rec-full` 오버레이(x40~1290 × y140~900+extra, 즉 실험 화면+하단 띠 자리) 에 같은 표 DOM 을 옮겨 그리고 글자 28u 이상, 모든 열 표시, `Esc`·`[닫기]` 로 복귀.

- 카드 전환 확인창: 바뀌는 값이 **2개 이상이고 기록이 있을 때만**. 문구 '기록 N개는 그대로 남아요 · 값 M개가 바뀌어요', 버튼 `취소` / `이 카드로 바꾸기`.

### 1-4. 문구·표기 (물리 계산은 그대로)
단위 없는 g 에 `m/s²` · 2f(길이)/2F(점) 구분 · a.u. → `칸(모형)` · '최고점에서 멈춤' → '최고점에서 화면 멈춤' · '위만' → '위쪽만 열기' · '트럭(3 kg)' → '트럭(승용차의 3배)' · 충돌 카드 부제에 단위. 정답을 암시하는 예시값(충돌 계기판 예시, 포물선 placeholder·범위) 제거.

### 1-5. 글자 하한
캔버스 글자는 설계 단위 **22 이상**(`--fs-caption`, 1280 에서 14.7px). 각 sim 이 18·20 으로 쓴 곳을 22 로 올리고, 자리가 모자라면 **라벨 수를 줄인다**(글자를 줄이지 않는다).
