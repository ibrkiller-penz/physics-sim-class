# R8 검토 — 개발 회의록 (팀장 주재)

- 일시: 2026-10-31
- 참석: 팀장(총괄), 디자인A·B·C, UI팀1·2·3
- 입력: 교사 3명(P 역학 / Q 빛·양자 / R 전자칠판 운영), 학생 6명(A 노트북 1280 / B 아이패드 세로 820 / C 옛 아이패드 1024 / D 심플 모드 1180 / E 상위권 1920 / F 키보드 전용) 검토, 디자인 3인·UI 3인 회의 준비 의견
- 사용자 요청: "한 번 더 검토하고 고도화 하자." 이전 요청 유지(교과 설명 → 실험 흐름, 화면은 단순하게, 부가 기능은 팝업·⚙ 설정으로). 단원 전체(5종 공통 구조)를 고쳐도 좋다.
- 원칙
  1. 높음은 전부 고친다. 중간은 뿌리가 같아 한 번에 풀리거나 5종 공통인 것, 또는 수업 흐름을 바꾸는 것만 고친다. 낮음은 담당 파일을 어차피 여는 경우에만 같이 처리한다.
  2. 물리 값·식·정답 키는 바꾸지 않는다(R7 회귀 금지 1). 문구와 표시만 바꾼다.
  3. 같은 파일은 한 팀만 만진다. `shared/*.css`·`tokens.css`·`shared/lesson.js`·`shared/diagram.js`·`index.html`·`sims/*/lesson.js` = 디자인팀, `shared/sim.js` + `sims/projectile-energy/`(lesson.js 제외) = UI팀1, `sims/double-slit-quantum/`+`sims/collision-momentum/`(lesson.js 제외) = UI팀2, `sims/orbit-gravity/`+`sims/convex-lens/`(lesson.js 제외) = UI팀3, `tools/` = UI팀1.
  4. CSS 와 JS 가 한 수정에 걸칠 때는 **클래스 이름을 이 회의록에서 정해** 디자인(CSS)과 UI(JS)가 각자 자기 파일만 만진다.
  5. 디자인A 메모대로 '확인됨'이지만 재촬영하지 않은 항목은 **수정 담당이 먼저 재촬영**한 뒤 고친다(이미지는 `_review/R8/<팀>/` 에 추가).

## 2. 결정 사항

### 2-1 의견이 갈린 것 — 팀장 결정

1. **'칸' 용어(C3)**: 바꾼다. 측정 n 은 '간격 수 n'(용어집 1684행과 같음), 전자 모드 길이 단위는 '눈금'. '한 칸 = 무늬 간격 Δy' → '간격 1개 = Δy'. 단계 칸 이름 '① 밝은 줄 하나 ② 다른 밝은 줄 ③ 사이 간격 수'. 근거: 한 낱말 한 뜻, 용어집과 화면이 이미 어긋남. 5종 용어표(docs/SIMKIT.md)에 기록.
2. **궤도 카드 ① 질문(E2)**: 7.9 한 점 질문을 **유지**한다. 경향 질문은 판정에 여러 실행이 필요해 cannonAnswer(정답 키)가 바뀌므로 R7 회귀 금지 1 에 걸린다. 대신 E1(눈금 이름·칩·다음 10 숨김)으로 답 암시를 없애고, 경향은 이미 있는 [다음 10 ▶] 흐름이 맡는다. R9 후보로 남긴다.
3. **궤도 에너지 막대(G1)**: 이번에 넣는다. 성취기준 12역학01-05 를 실험에서 직접 충족하고 포물선 단원과 이어진다. [수치 더 보기] 안에 막대 하나, 예측 중 숨김, 단위는 상대값(E_k 기준 1). 해석식 한 줄이라 물리 값 변경 없음.
4. **충돌 카드 ⑥(G2/D3)**: 신설. v₂ 슬라이더는 카드 ⑥을 고를 때만 레일에 올린다(화면 단순 원칙). 카드 수 6 → 실험 고르기 시트 2열(A13)이 먼저, 허브·설명의 '실험 5' 칩은 충돌만 '실험 6'.
5. **렌즈 지름(F2)**: 그리는 지름 `D_DRAW`(약 18 cm, 광선 최대 높이 8 cm ×2 +여유)만 분리하고 물리 지름 `D_LENS=6` 과 흐림·선명 기준은 그대로 둔다(회귀 1).
6. **결과 카드(A3)**: 기본 한 줄 접힘(✓/○ + takeaway 첫 문장, 줄임표 금지). 첫 실행에서만 펼침. 펼쳐도 max-height 는 패널 40%, 안쪽 스크롤. 슬라이더·칩을 만지면 자동 접힘. [v0 20으로 해 보기]는 접힌 줄 오른쪽에 유지. R7 A5 규칙('처음 한 번만 펼침')을 이 규칙으로 대체.
7. **기록 비교 모달(A7)**: 기록 2개 미만이면 비교 단계에서 모달을 열지 않고 띠에 '먼저 ▶ 실행 → 결과 기록하기 (S)'. 2개째에는 모달 대신 무대 아래 한 줄 비교 + [표 보기]. 모달을 열면 해설 기본 펼침, '직전' 행은 기록 1 과 같으면 숨김, 모달 열린 동안 토스트 생략. 한 줄 비교 문장은 각 sim 이 `cfg.compareLine(r1, r2)` 로 준다.
8. **정리 팝업(A8)**: ≥1600 폭에서는 모달을 화면 폭 전체로. 문항마다 [정답 공개]. 교사 모드와 ≥1600 에서는 '한 문항씩' 보기([이전 · 2/3 · 다음]) 기본. 기록 0개면 위에 '먼저 기록을 2개 만들어 봐요'. 남은 문항 수 표시.

14. **문구 표준 한 벌(A15~A18)**: 예측 상태줄 '먼저 결과를 예측해요 — 보기를 하나 골라요'(5종). 성취기준 칩 '첫 코드 + [N개]'. '기록하기' → '결과 기록하기', 첫 기록 토스트 '기록 1 저장 — ⋯ › 기록 비교에서 봐요'. [예측하기]는 고르기 전 '보기를 골라요'. [이 값으로 해 보기] → '11.2 km/s 로 해 보기'. 렌즈 F·2F 대문자. 계기 잠금 문구 '실행 뒤'(자물쇠 아이콘). 결과 칩 라벨 '상태'. 궤도 '공기 없는 높은 곳(20 km)'.
