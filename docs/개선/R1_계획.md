## 2. 디자인 방향 (결정)

### 2-1. 원칙 다섯 가지

1. **지금 할 일 하나.** 화면 맨 위에 단계별 '지금 할 일' 한 줄이 항상 있고, 그 단계의 행동 버튼이 그 띠 안에 있다.
2. **단계별 점진 공개.** 예측 단계는 장면 + 예측 카드 + 핵심 수치 2~3개만. 실행 단계에서 그래프·계기판. 비교 단계에서 기록 표가 커지고 패널이 접힌다. 정리 단계는 발문 카드가 장면 아래 고정 영역에 선다.
3. **잘림 0.** 말줄임(`text-overflow: ellipsis`)을 shared 에서 금지한다. 긴 글은 줄바꿈(`word-break: keep-all`, 최대 2줄)하거나 접기 버튼 뒤로 보낸다. 패널·표는 스크롤 그림자 + '아래에 더 있어요 ↓'.
4. **말은 풀어쓴다.** 기호·약어·키 이름을 단독으로 쓰지 않는다('즉시'→'바로 반영', '1배'→'속도 ×1', 'C'→'기록 모두 지우기'). 단축키는 마우스 오버·`?` 도움말에서만.
5. **개념 도우미는 공통 부품.** 용어 말풍선·개념 카드·식 풀이·예측 판정·답 확인·결과 해설을 shared 컴포넌트로 만들고 시뮬은 **내용(JSON)**만 넣는다.

레퍼런스(프랑스혁명 사이트)의 미색·명조·여백은 유지한다. 바꾸는 것은 **밀도와 위계**다: 헤더 가볍게, 실험 화면 크게, 보조 글자 키우고 진하게, 카드 색 채도 낮춤.

### 2-2. 새 화면 뼈대 (1920×1080, u)


- `.sim-top` 에서 **칩·오늘 알아볼 것·상태 요약을 뺀다.** 상태 요약은 `.sim-stage` 왼쪽 위 작은 칩 줄(`stage-corner--tl`, 20u 글자, 각 칩 한 단어: '지구' '공기 저항 없음' 'g 9.8').
- `.sim-task` 가 새로 생긴다(S1·S9 해결). 스테퍼는 번호 원 + 이름 + 완료 체크, 클릭 가능(호버 밑줄). 오른쪽에 '지금 할 일' 문장(26u, 먹색)과 그 단계의 **1개 주 행동 버튼**.
- 패널은 **수치 → 상황 → 표시 도구 → 심화** 순서로 바꾼다(결정서 §2 '상황→수치' 순서를 뒤집음. 이유: 전원이 '수치가 숨어 있다'고 했고, 수치가 요구 A의 핵심). 패널 높이 760u 안에 기본 수치 3개(각 120u)와 상황 1묶음이 들어가게 하고, 나머지는 `<details>` '더 많은 설정 ▾'.
- 하단 띠는 계기판과 그래프만 88u. 기록 표는 **비교 단계에서 패널 자리(570×760)에 크게**, 그 외 단계에서는 띠 오른쪽에 '저장한 실험 2/5 · [표 보기]' 칩 하나.
- 토스트(`notice`)는 `.sim-stage` **바깥** 하단 띠 위 y800 선에 띄우고 3초 후 사라짐. 모달이 떠 있을 땐 모달 위에.

- **double-slit-quantum**: 모달 재설계·URL 생략; 프리셋은 예측 → 값 변경 순서; '비교' 단계 체크리스트(기록 3개·λ 비례); 수식 박스를 띠 고정 영역 + 색 점 연결; 용어 전면 교체·측정 그림 안내; 전자 모드 가속 전압(V)→λ 계산; 구슬 모드 이유 문장; 프리셋 5 선택지·해설 재작성; 이론값은 기록 뒤 '답 확인'.
- **collision-momentum**: 예측 단계는 장면+슬라이더만, 그래프는 실행 후 순차 공개(탭); 기본 프리셋 1 예측을 진입 시 띄움; 예측 answer/why 5개; 수레 장면 자동 축척; 그래프 글씨 바깥 범례; 결과 해설(작용·반작용/에어백/열·소리) 고정; 합 전/후 패턴 구분·'손실' 글자; 정리 발문 장면 밖; 교사 H 버튼 숨김.
- **orbit-gravity**: 모달 재설계·패널 중복 제거; 예측 질문과 설정값 일치, 프리셋 변경값 칩 표시; 라벨 충돌 처리·HUD 위치·진한 글자; 발사 속력 슬라이더 맨 위, 눈금 축약('2만 km'); 결과 3상태 뜻 + 탈출 속도 비교 한 줄, '현재 속력/처음 속력' 분리, 추락 시 설명; ISS 프리셋 제목·해설, 질량 무관 이유, 케플러 3단계 안내·자동 결론, 발문 3개 정답 작성; 탈출 궤도 시 '지구 전체로 보기' 자동 버튼.
- **convex-lens**: 단계 통일(규칙 카드→비교, 발문→정리) + A1 확인; 패널 재배치(f·물체 거리 맨 위, 광선 칩 한 줄 60u, Q·W·E·D 숨김); 캔버스 라벨 충돌·흰 칩·스크린 정면 축소·손잡이 안쪽; 허상 상 거리 '10 cm (렌즈 앞쪽)' 통일; '상의 모습' 한 줄 요약; 규칙 카드 빈칸 보기 버튼 + 답 확인; 프리셋 1 질문 재작성; 용어 풀이(초점거리·2f·실상·허상·배율·선명도); 예측 answer/why.

## 5. 하지 않기로 한 것과 이유

| 제안 | 결정 | 이유 |
|---|---|---|
| 프리셋을 왼쪽 열/패널 위 카드 목록으로 이동(교사A·C) | 안 함 | 실험 화면 폭이 줄어 전자칠판 뒷자리 가독성이 떨어진다. 하단 2줄 카드로 잘림을 없애면 목적은 달성된다. |
| 폰 세로 배치 완전 지원(학생01·09) | 2차 | 설계 기준이 전자칠판·태블릿이다. 이번에는 안내 띠만. 세로 배치는 shared 전체 재배치가 필요해 2차. |
| 그래프 3개를 전부 탭으로 전환(교사C 대안 중 하나) | 충돌만 탭, 나머지 유지 | 포물선 에너지 막대처럼 장면과 동시에 봐야 의미가 있는 그래프가 있다. |
| 전자 모드에서 실제 슬릿 간격(μm) 사용 | 안 함 | 모형과 현실 차이를 이미 명시. 가속 전압→λ 계산만 추가하고 기하는 모형 단위 유지('a.u.' 명시). |
| 교사 H 전체 공개 폐지 | 안 함 | '답 확인' 을 학생에게 열되, 교사가 토론 전 잠글 수 있어야 한다. |
| 예측 카드를 건너뛰어도 Space 가 그냥 실행 | 안 함 | 예측 → 확인이 교육 흐름의 핵심. 대신 이유 안내와 큰 '예측 없이 바로 실행' 버튼. |
| 허브 카드 색을 없애고 아이콘만 | 안 함 | 번호 배지 + 상단 선 + 채도 낮춤으로 색약 문제와 차분함을 함께 해결. 아이콘 제작은 2차. |

## 6. 검수 기준 (R1 끝에 확인)

1. 1280×720, 1366×768, 1920×1080 세 해상도에서 **말줄임·잘림 0**, 패널 기본 수치 3개 전부 보임.
2. 각 시뮬 첫 화면에서 아무 안내 없이 "지금 할 일" 문장과 주 버튼 하나가 보인다.
3. 예측 → 실행 후 5종 모두 '내 예측 → 맞았어요/아니었어요 — 이유' 가 뜬다.
4. 학생 화면에 '교사용', '손들기', 'H 키', 성취기준 코드가 보이지 않는다(교사 모드에서만).
5. 각 시뮬에 `?` 도움말(이렇게 해요·개념·용어) 3탭이 채워져 있다.
6. 렌즈 '정리' 단계에 발문 3개가 뜬다.
7. 실행 중 S 는 거부되고 안내가 뜬다.
8. 학생01·03·10 (물리 약한 학생) 시나리오로 R2 검토 재실시.
