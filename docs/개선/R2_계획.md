> 작성: 팀장 · 2026-10-28
> 입력: 사용자(현직 교사) 평가("디자인이 어설프다, UI 가 불편하고 어렵다, 설명이 불친절하다") + R1 결과 보고(shared + 5종) + 검토단 2차 의견(학생 10 · 교사 3, `_review/R2/`)

## 0. R1 이 실제로 좋아졌는가 — 판정

검토단 13명이 **모두** 좋아졌다고 한 것: 허브 '처음이면 여기부터', 4단계 스테퍼+✓, '지금 할 일' 문장, 예측 카드(큰 보기 버튼)와 '맞았어요 — 이유' 자동 판정, 수치 칸(숫자+슬라이더+±+기본값↺), 기록 표의 굵은 글씨·▲ 차이, 정리 질문 판, 도움말 '이렇게 해요' 번호 목록, 미색·명조 통일. 교사B: 물리 오류 없음.
→ R1 의 뼈대(띠·스테퍼·점진 공개·개념 도우미)는 **유지**한다. 2차는 뼈대를 바꾸지 않고 **가리는 것·겹치는 것·두 번 있는 것·읽을 수 없는 것**을 없애고, 설명을 **한 줄 요약 → 펼치기** 구조로 다시 깎는다.

번호는 `docs/SIMKIT.md` §0-3(R2 체크리스트)에 그대로 옮긴다.

### A. 가림·겹침 (P0)
- **A1 토스트**: `.notice-zone` 을 `.sim-stage` 안 위 가운데(y148, 최대 폭 760u, 1줄, `--fs-meta`, 반투명 먹색)로. 한 번에 1개, 새 토스트가 오면 즉시 교체(겹침 금지). 2.5초. `notice(text)` 는 **28자 초과면 콘솔 경고** 후 띠 문장(`taskLine`)으로 보낸다. '끝났어요…' 자동 토스트 삭제(띠 문장이 같은 말을 함). 모달이 떠 있으면 모달 위.
- **A2 결과 해설 → `.panel-note`**: `finish()` 뒤 패널 맨 위에 카드. 구조: 1행 판정 `내 예측: 동시에 → 맞았어요`(선택지 **글자**, 번호 없음; 숫자형은 `예측 40 m · 실제 40.8 m · 차이 0.8 m` 세 칸 큰 숫자), 2행 `takeaway` 1줄(keep-all 2줄까지), [왜 그럴까? ▾] 펼치면 `why` + takeaway 전문. [접기]는 `--tap`. 단계가 비교·정리로 바뀌면 패널이 바뀌므로 자동 숨김; `rec-big`·`think-board` 머리 오른쪽에 '해설 보기 ▾' 칩으로 같은 내용 팝오버. 예측·실행 단계로 돌아가면 **이전 실행의 해설은 지운다**(다시 실행 전까지 빈 상태). `reveal`·`takeaway` 시그니처 유지, `takeaway(fn)` 반환을 `{line, more}` 로 받으면 두 줄로 나눔(문자열이면 1줄로 취급).
- **A3 예측 창 재배치**: §2-2. 숫자형: 라벨 `얼마나 멀리 갈까?  [ 예: 40 ] m`(단위는 입력칸 바로 옆, placeholder 는 **예시 숫자**, 범위는 칸 오른쪽 22u 회색), `numeric.max` 에 **함수** 허용(`max: () => 1.5 * PH.rangeFor(...)`), 상한 밖 숫자는 막지 않고 '아주 멀리 간다고 봤군요'로 받는다. 보조문은 숫자형 '적은 다음 ▶ 실행으로 확인해요', 선택형 '고른 다음 …'. 버튼: 주 [예측하기] 1개, 보조 '예측 없이 바로 실행' 26u 밑줄 링크. 선택지 번호 원은 첫 줄 높이 고정, 두 줄 들여쓰기. `predict({figure})` 로 SVG 그림 1장 허용(이중슬릿 '레이저 → 틈 두 개 → 스크린').

### B. 버튼·이름 (P0)
- **B1 주 버튼 규칙**(§1-3): 띠 버튼은 실행이 아닌 행동에만. 실행 단계 문장 기본값 '아래 ▶ 실행을 눌러요'. 하단 `btnRun` 은 실행 전 '▶ 실행', 끝난 뒤 '↻ 다시 실행'(outline, 주 색 아님). **하단 `btnRec` 삭제**, `rec-chip` 은 '저장한 실험 1/5 (최대 5) · 표 보기'. 실행 중·일시정지 중에는 띠 버튼이 '기록하기'로 바뀌지 않는다(`record()` 거부와 같은 조건). '다음 단계 ▸'와 '○○하러 가기 ▸' 중 **하나만**(단계 이름이 들어간 쪽).
- **B2 라벨**: '한 칸 뒤로/앞으로' → '한 장면 뒤로/앞으로'(툴팁 '실행 장면을 되감아 봐요'), '처음 설정으로' → '기본값으로 되돌리기', 패널 ↻ 설명과 같은 말, '⋯ 더보기' → '그 밖의 기능 ▾'(메뉴 항목: 기록 모두 지우기 · 전체 화면 · 도움말 · 교사 모드).
- **B3 단축키 표시 버그**: `keyHint()` 는 `.sim[data-input=touch]` 또는 기본에서 `display:none`, 마우스 오버·도움말 단축키 탭에서만. 하단 [기록하기] 삭제로 'S' 도 사라짐. 터치 기기(`pointer: coarse`)에서는 '단축키' 탭 숨김.
- **B4 문장 규칙**: 띠·토스트 문장에서 `[기록하기]` 대괄호 금지 → '기록하기 버튼으로'. `josa(word, '으로/로')` 유틸을 shared 에 두고 모든 `(으)로`·`(을)를`·`(이)가` 치환. 단위 뒤 조사 붙여쓰기 검사(`7.9 km/s로`).

- **D1 도움말 세로 깨짐 버그**: `.help-step`을 `grid-template-columns: var(--tap) minmax(0,1fr)`, 본문 `min-width:0; width:100%`, `.term` 은 `display:inline; white-space:nowrap; word-break:keep-all`. 서랍 폭 `min(720u, 100vw - 40u)`. 탭 글자 `--fs-control`. 1280 에서 본문 한 줄 20자 이상인지 shot 검증 항목 추가.

### 4-2. double-slit-quantum
- 측정: 밝은 줄 중심 **스냅**(±1.5 mm 안이면 중심으로), 두 점 사이 밝은 줄 개수로 **n 자동 제안**('두 칸을 쟀어요 → n = 2 로 할까요?'), 이론과 1.8배 이상 차이면 확인 문장. 다시 실행 시 측정 선 유지(λ·d·L 이 바뀌면 '이전 측정은 다른 조건이에요' 표시 후 지움). 안내 상자는 첫 pointerdown 에 사라짐, 확대창 400×400u 이상, 단계 '① 시작점 누르기 → ② 끝점 누르기 → ③ n 맞추기'는 하단 띠 왼쪽 칸에. 띠 문장 '밝은 줄 두 곳을 눌러 간격을 재요'.
- 문안: '혼한'→'흔한' + 전체 맞춤법. 보기 ② '밝은 줄이 두 개만 생긴다'. 질문 아래 '슬릿 = 빛이 지나가는 틈' + `figure`. 보강·상쇄 첫 등장 괄호 풀이. 기록 확인창 '간격을 아직 안 쟀어요…' / 버튼 [지금 재러 가기][재지 않고 기록하기]. 체크리스트 옆 '기록하기 버튼으로 한 번 더 저장해요'.
- 콘텐츠: 개념 요약 줄('두 틈에서 나온 물결이 만나 밝은 곳과 어두운 곳이 생겨요'), `symbols` 표, `why` 에 d sinθ = mλ → sinθ ≈ y/L → Δy = λL/d, live 5.2 mm. 측정기 why '슬릿 간격이 좁아 두 띠가 겹쳐 하나로 보여요 … 핵심은 줄무늬가 사라진다'. 확률 문장 '점 하나는 예측 못 하지만 수천 개는 늘 같은 줄무늬'. 전압 문항 'V 4배 → p 2배 → λ ½'. 정리 Q2 `hint`. `think({when})` 로 모드별 숨김(직접 hidden 조작 제거).
- 패널: 변수 설명을 단위 칩으로 줄여 λ·d·L 이 한 화면에. 모드 선택 라벨 유지(값 physics/quantum). 자체 CSS 의 preset-info 폭·L 라벨 회피 코드 제거. 모드 창 [이걸로 시작] 실제 클릭 확인.
