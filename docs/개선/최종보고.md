## 0. 출발점 — 사용자(현직 교사) 평가

> "사이트 디자인부터 영 어설프다. UI가 너무 불편하고 어렵다. 관련 내용도 친절하게 할 수 있도록 처리해 달라."

기존 필수 요구(수치를 슬라이더·숫자로, 상황 바꾸기·교과서 탐구 프리셋, 기록·비교, 성취기준에 맞춘 변수)는 유지한 채, 두 차례 고도화로 **디자인 → 조작 흐름 → 설명 콘텐츠** 순서로 고쳤습니다.

### 이번 점검에서 직접 고친 것 (공통 틀 3곳)
1. **`shared/sim.js`** — 숫자 예측 창에서 **Esc**가 입력칸만 비활성화하고 창을 닫지 않던 문제. 이제 칸이 비어 있으면 창을 닫고, 글자가 있으면 한 번은 지우기(두 번째 Esc로 닫힘). 포물선 첫 화면에서 교사가 Esc·Space를 눌러도 아무 일이 없던 불편을 해소.
2. **`shared/shell.css`** — 교사 모드에서 성취기준 칩이 제목을 밀어 두 줄로 꺾이던 문제(R2 포물선·이중 슬릿 요청). 제목은 한 줄 고정, 칩이 대신 줄바꿈.
3. **`shared/base.css`** — 기록 표 머리글이 '물체 거리 (cm)'처럼 3줄로 접히던 문제(R2 렌즈 요청 1). 이름은 줄바꿈 없이 한 줄, 단위는 다음 줄 = 2줄 고정.

## 2. 무엇이 어떻게 좋아졌는지 (사용자용 요약)

### 디자인
- **실험 화면에는 그림만** 남겼습니다. 글 상자·수식·발문은 모두 오른쪽 패널(이번 실험 결과)과 도움말·정리 질문으로 옮겼고, 안내 토스트는 위 가운데 한 줄(28자·2.5초)만 뜹니다.
- 미색 양피지·명조 제목·여백 많은 발표 화면(프랑스혁명 사이트 톤)으로 허브와 5종을 통일했습니다. 식별색 채도 −20%, 본문 대비 6.6:1, 캔버스 글자 최소 22u(전자칠판에서 읽히는 크기).
- 허브는 카드 높이 통일, 선화 아이콘, '무엇을 하나요' 2줄, [열기] 하나, '처음이면 여기부터' 표시.

### 조작(UI)
- **지금 할 일 띠**: ① 예측 → ② 실행 → ③ 비교 → ④ 정리 스테퍼와 상황에 따라 바뀌는 한 문장("끝났어요 — 기록하기 버튼으로 저장해요"), 주 버튼 1개, 다음 단계 버튼 1개.
- **버튼 이름 통일**: ▶ 실행 / ↻ 다시 실행, 기록하기(끝난 뒤에만), ○○하러 가기 ▸, 기본값으로 되돌리기, 한 장면 뒤로/앞으로, 속도 ×1 ▾, 그 밖의 기능 ▾. 화면에서 키 이름('S로', 'H로 공개')을 모두 지웠습니다.
- **패널 순서 고정**: 수치 → 상황 → 표시 → 더 많은 설정. 수치 칸은 성취기준 핵심 2~3개만, 범위·'버튼 한 번에 얼마'·기본값으로 ↺ 표시. '아래에 더 있어요 ↓'.
- **실험 카드 5장**: 12자 이내 이름 + '무엇이 바뀌는지'(`changes`). 누르면 예측 질문이 먼저 뜨고, 예측 창이 떠 있는 동안 결과(궤적·무늬·상)는 가려집니다. 예측 창은 화면 아래쪽에 떠서 위쪽 장면이 보입니다.
- **기록·비교**: 비교 단계에서 패널 자리에 기록 표 큰 판(2개 필요 안내, 바꾼 값 자동 표기, 줄마다 ✕ 삭제, ●▲■◆★ 기호, 열 우선순위로 1280에서도 안 넘침).
- **첫 화면 안내** 한 번, 처음 한 번만 뜨는 실험 고르기 창(이중 슬릿·위성), 허브에서 `?mode=`로 바로 진입.

### 설명 콘텐츠(친절함)
- **예측 판정 자동**: 실행이 끝나면 '내 예측 ② → 맞았어요/아쉬워요 — 이유'. 숫자 예측은 '예측 40 m · 실제 40.8 m (차이 0.8 m)'.
- **이번 실험 결과**: 상황별 한 줄 + '왜 그럴까? ▾' 전문. 5종 합계 30여 가지 상황.
- **? 도움말**: 이렇게 해요 / 개념 카드(한 줄 요약 → 풀이 → 예시 → 그림 → 식 보기(기호·뜻·단위) → 왜 그럴까? → 지금 값으로) 4~6장, 마지막은 '흔한 오해 바로잡기' / 용어 11~16개(화면 순서, 점선 글자에 올리면 풀이) / 단축키.
- **정리 질문**: 시뮬레이터마다 4~8개. 선택형은 고르면 바로 ✓/✗와 이유, 서술형·계산형은 힌트 접힘 + [답 확인하기]로 모범 답.
- **교사 모드**: 성취기준 코드·대응표·40~50분 수업 흐름·발문을 카드형으로. '답 확인 잠금', 자동 예측 끄기, ✋ 손들기 수.

## 5. 남은 과제 (우선순위 순)

1. **현장 확인** — 교실 PC·태블릿에서 file:// 더블클릭과 https://penedu.web.app/physics/ 접속, 전체 화면, 60 fps(이중 슬릿 1000개/s + 파면) 실측. 개발 환경은 headless Chrome으로만 확인했습니다.
2. **교사팀 검수** — 교과서 쪽수·탐구 활동 제목(확인 필요), 각 시뮬 수업 안내 문구·정리 질문 모범 답, README §5 흐름.
3. **태블릿(1180×820) 배치** — 지금은 비례 축소. 세로·좁은 화면 전용 배치(패널을 아래로) 다듬기.
4. **기록 표 큰 판** — 기록 이름 열(✕·견본·기호·이름·'n개 바뀜' 칩) 폭 줄이기, 1280에서 열 5개가 밀림 없이 들어가게.
5. **공통 틀 소소한 API** — `dialog` Esc/취소 구분, 자동 비교 이동 끄기 옵션, 용어 모드별 필터, `status` 칩 `title`, 수치 칸 단위 표기, `inlineTerms` 계기판 제외.
6. **포물선** — 숫자 예측 창이 떠 있을 때 1~5 키로 카드 고르기(지금은 마우스만), 예측 창 위치가 h = 0 공을 가림.
7. **위성** — v₀ 눈금 이름(지구를 돎·탈출)이 달·화성에서는 맞지 않음, 카드 아래 줄 폭(약 10자).
8. **렌즈** — 렌즈 바로 앞 허상 상황에서 ② 광선이 정면 창 뒤로 지나감.
9. **도움말 그림**이 고정 그림이라 값을 바꿔도 따라 바뀌지 않음 — 살아 있는 그림은 다음 고도화 과제.
10. **6종째 후보** — `newton-cart`(1순위), `magnet-brake`(2순위). 명세는 기획팀.
