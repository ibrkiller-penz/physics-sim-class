## 1. 이번 차수 설계

### 1-1. 원칙 (8줄)
1. **패널은 절대 안 덮는다.** 예측·실험 고르기·식 팝업 어느 것도 오른쪽 패널(x1310~1880)을 가리지 않는다. 예측은 무대 위쪽 띠, 식 팝업은 무대 왼쪽 아래 팝오버, 실험 고르기만 기존 dock(패널 자리) 유지하되 자동으로는 안 연다.
2. **한 장 = 한 화면.** 1280×720 자세히에서 글 칸 스크롤 0. 본문 3문단(문장 ≤3)·식 ≤2·그림 1. 넘치면 접거나(더 보기) 장을 나눈다. 넘치면 콘솔 경고.
3. **같은 말·같은 기호.** sim 하나에 용어·기호 사전 한 벌(`terms`). 설명·식 팝업·해설·정리·계기판 라벨이 그 표기를 쓴다. 변수 기울임, 아래첨자 직립(`$v_0$`·`$E_k$` 표기 = `SK.mathNodes` 규칙 그대로).
4. **정리 문항은 한 곳.** `quiz` 3문항(개념·계산·오개념)이 유일한 원천. 설명 첫 진입 순서에서 wrap 장은 뺀다. [정리] 모달에서만. 정답·이유는 학생이 고른 뒤에만 DOM 에, 교사 [정답 공개]는 교사 모드에서만 생성.
5. **머리줄 4개.** [설명] [실험 ▾] [⚙] [⋯]. 1280 이하·교사 모드에서도 설명·실험·설정 글자 유지. 기록·정리·도움말·전체 화면·수업 정보는 ⋯ 안.
6. **오해는 실험으로 깬다.** 오해 항목마다 '내 생각 → [해 보기] → 결과 문장'. 실험에서 돌아오면 '깨졌어요 ✓'.
7. **기능은 없애지 않는다.** 1차 팝업 틀·⚙·[실험 ▾]·기록·정리 모달·키 전부 유지. 자리만 옮기고 데이터 형식만 통일한다.
8. **새 프리셋 없음.** 새 해 보기는 '카드 + `set`'(1차 결정 6 유지). 충돌 `v2`·포물선 `gEarth`·`m` 처럼 ⚙ 안 값도 `SK.controls[k].set` 으로 채운다(이미 동작).

### 1-5. [ƒ 식] 팝업 + 기호 ↔ 실험 대응 (shared/sim.js 신설 `SK.formulaPop`, shared/lesson.js `symbols`)

① **데이터** — `sims/<slug>/lesson.js` 의 `formula` 장 `symbols` 에 `target` 을 더한다(새 필드명 `sym` 은 만들지 않는다. 기획 원고의 `sym` 표 = 이 `target` 열).
```js
{ id: 'split-v', type: 'formula', title: '속도를 둘로 나누기',
  eq: [{ tex: '$v_x = v_0 \\cos θ$', caption: '수평 속도' }, { tex: '$v_y = v_0 \\sin θ - g t$', caption: '수직 속도' }],
  symbols: [
    { sym: '$v_0$', name: '처음 속력', unit: 'm/s', target: 'v0' },          // SK.controls 키(슬라이더·칩·토글·⚙ 안 값)
    { sym: '$θ$',   name: '던지는 각도', unit: '°',  target: 'theta' },
    { sym: '$v_x$', name: '수평 속도',  unit: 'm/s', target: 'meter:vx' },   // 계기판 data-key
    { sym: '$E_k$', name: '운동 에너지', unit: 'J',  target: 'bar:Ek' },     // sim 이 SK.flashTargets 에 등록한 임의 대상
    { sym: '$R$',   name: '사거리',     unit: 'm',   target: 'record:R' }    // 기록 표 열 → '기록 표에 있어요' 안내만
  ],
  now: function (p, v) { return '지금 값: $v_0$ = ' + p.v0 + ' m/s, $θ$ = ' + p.theta + '° → $v_x$ = ' + (p.v0 * Math.cos(p.theta * Math.PI / 180)).toFixed(1) + ' m/s'; }   // '지금 값 대입' 한 줄. 정답 누출 방지는 sim 이 판단(기록 전이면 결과값 생략)
}
```
- `target` 해석(`SK.flashTarget(t, ms=1500)`): `k` → `SK.controls[k]` 있고 패널에 보이면 `SK.flash(k, 1500)` + 말풍선 `.flash-tip`(라벨 '처음 속력 v₀') 1.5초; ⚙ 안(tools·deep)에 있으면 `SK.notice('⚙ 설정 › 더 많은 설정에 있어요')`; `meter:key` → `.meter[data-key=key]` 에 `is-flash` 1.5초(수치 더 보기 안이면 notice); `bar:`·`stage:` → `SK.flashTargets[name]()` 콜백(sim 이 등록: 에너지 막대 칸·그림 화살표 등 `SK.isFlashing('bar:Ek')` 로 render 에서 그림); `record:` → notice '기록 표(⋯ › 기록)에서 봐요'. 없는 target 은 `warnOnce`.
- `terms`(§1-7)에 같은 기호가 있으면 `name` 생략 가능(사전에서 가져옴).

② **팝업** — `.sim-band` 맨 왼쪽 `[ƒ 식]` 칩(44u, `aria-label '식과 기호 보기'`) → `SK.pop({id:'formula', kind:'popover', anchor: 칩, overlap:true, cls:'pop--formula', title:'식과 기호'})` 폭 520u, 최대 높이 360u, anchor 위쪽(무대 왼쪽 아래 일부를 잠깐 가림 — 패널은 절대 아님). 세로는 시트.
- 내용(위→아래): 장 칩 줄(식이 있는 장만, 현재 카드의 장 `lessonApi.chapterForPreset` 이 `formula` 가 아니면 가장 가까운 앞 `formula` 장을 기본 선택) · `eq` 1~2줄(`.eq`, `frac` 지원) · 기호 칩 줄(각 ≥44×44u, `<button data-sym>` — 누르면 `SK.flashTarget`; 1.5초 동안 칩도 단원색 테두리) · `now(p, values)` 한 줄(있을 때) · 바닥 [설명 N장 ↩](`SK.lessonLink`) · 심화 `more` 는 '더 알아보기 ▸' 접힘(교사 모드 펼침).
- 심플: 식 1줄 + 기호 칩만(`now`·더 알아보기 숨김).
- 계기판 라벨(`.meter__label` 의 `{{용어}}` 점선 밑줄)을 탭하면 같은 팝업이 그 기호 장으로 열림(`SK.formulaPop({sym:'v_x'})`).
- 키: 공용 글자 키는 남은 것이 없어(A~Z 전부 사용) **키 없음**. 도움말 '단축키' 탭엔 '식: 계기판 왼쪽 ƒ 단추' 한 줄.
- `lesson.js` 없거나 `formula` 장에 `eq` 가 없으면 [ƒ] 숨김(하위 호환).

③ **설명 층 쪽** — `symTable` 의 기호 칸을 `<button data-sym>` 으로: 누르면 그림 안 같은 기호 라벨(`D.label` 이 `data-sym` 을 붙임)이 1.2초 강조. 실험 화면으로 가지 않는다.

```js
{ id: 'wrap', type: 'wrap', title: '실험 뒤 정리', summary: ['한 줄 요약'],
  quiz: [   // 정확히 3개: kind concept · calc · misconception 순
    { kind: 'concept', q: '수평으로 던진 공이 땅에 닿을 때까지 걸리는 시간을 정하는 것은?', choices: ['처음 속력 $v_0$', '던지는 높이 $h$ (와 $g$)', '공의 질량 $m$'], answerIdx: 1,
```

- `answerIdx` 0부터. 정답 위치는 문항마다 다르게(기획A). 표시 번호는 `SK.circ(i+1)` 하나로.

- 진입: ⋯ › 정리, 단계 ④ 주 행동 [정리 ▸](기존 `goStep(3)` 의 자동 열기 유지), **PageDown 단계 ④에서 한 번 더 → 정리 모달**(§1-8).

### 1-10. 팀장 결정 (기획·진단이 물은 것)
1. **wrap 장 첫 진입 제외 — 확정.** 데이터는 두고 `visible()` 에서 뺀다. 정리는 모달만. 설명 장 수는 원고 기준 −1(포물선 9·슬릿 11·충돌 9·궤도 11·렌즈 11 — 실험 전 장만 센다).
2. **충격량 기호 = I**(2022 개정 교과서 표기). 충돌 실험 화면 **라벨·해설 문구만** `I`(계기 `J` 라벨 '충격량 $I$'), 코드 변수 `J`·계산은 그대로(물리 계산 불변).
3. **새 프리셋 없음.** 전부 카드 + `set`(충돌 `x-sign` = 카드 ② 달라붙기 + `{m1:1, m2:1, v1:2, v2:-2}`, `v2` 는 deep 에 있으나 `SK.controls.v2.set` 동작 — 1차 §1-4 확인).
4. **궤도 11장 유지**(`orbit-heights`·`kepler-1`·`kepler-2`). 한 장 한 화면이 우선. 심플은 `goal·cannon·orbit-speed·escape·check` 5장.
5. **g=10 문항**: 허용. [이 값으로 해 보기] = `{preset:0, set:{gEarth:10, h:20, v0:10, theta:0}}`. 해설에 'g = 10 으로 계산' 명시.
6. **클리커 전역 흐름**: 2차는 §1-9 범위(설명 끝 → 실험 시작, 단계 ④ → 정리 모달). 위치 표시줄·타이머는 3차.
7. **렌즈 결상 공식**: 1차 결정 2 유지(본문 정성, `1/f = 1/s + 1/s′`·`m = −s′/s` 는 더 알아보기·식 팝업 심화). 실험 배율 칸은 '0.5배 · 거꾸로 선 실상' 그대로, `m = −0.5` 는 식 팝업 `now` 에서만.
8. **교사 차시 진행 띠·타이머**: 3차. 2차는 설명 머리줄 '수업 진행 5·10·20·10분' 칩 + 정리 [정답 공개]까지.
9. **갈래 쿼리 이름 = 기존 `mode`**(`?view=sim&mode=physics|quantum`, `cannon|sat|kepler`). 새 `branch=` 는 만들지 않는다(1차 동작 유지).
10. **'카드 ①' → '실험 ①'** 학생 문구 전부(머리줄 칩·설명 질문 카드·해설·정리·허브). 코드 식별자·주석·교사 메모는 그대로.
11. **슬릿 이론 Δy 누출 방지**: 식 팝업 `now` 는 기록 전엔 '$Δy$ = λL/d 에 지금 값을 넣으면 …'까지만, 기록 뒤 값. 하단 띠 '🔒 기록하면 이론값이 보여요' 는 '기록 뒤 보여요' 로 짧게.
12. **설명 장 상한**: 본문 3문단(각 ≤3문장)·식 2·그림 1·goals ≤3·성취기준 접힘. 넘침 경고 0 이 검사 기준.
13. **식 렌더러**: 교체 안 함. `SK.mathNodes`(이탤릭 변수·직립 첨자) + `fracEl` 로 분수. `÷`·`/` 분수는 전부 `frac` 으로 고친다(포물선 사거리·궤도 F/4·g=GM/r²).
14. **에너지 막대·범례 기본값**: 바꾸지 않는다(기본 꺼짐 요청은 심플 모드가 이미 그 역할). 라벨만 통일.
15. **용어 `terms`**: 필수 아님(없으면 기존 `SK.term` 사전). 5종 모두 넣는 것이 이번 작업.
