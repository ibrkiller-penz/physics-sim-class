# R9 설계서 — 중학교 다시 보기 + 초급·중급·고급 (팀장)

- 일시: 2026-11-01
- 사용자 요청: "갑자기 고등학교 개념이 나오니까 너무 어려운 것 같아. 중학교에 나온 내용을 한번 짚어주고 시뮬레이터를 돌릴 수 있도록 하며, 시뮬레이터는 초급, 중급, 고급으로 선택해서 돌릴 수 있도록 하자." 이전 요청 유지(교과 설명 → 실험 흐름, 화면 단순, 부가 기능은 팝업·⚙).
- 입력: 교사 P(역학)·Q(빛·양자)·R(운영), 학생 M(중3)·H·S(고3 상위권) 진단, 기획 A(역학 3종 원고)·B(슬릿·렌즈 원고)·C(`_난이도체계.md`).
- 원고(확정본으로 간주, 아래 §0-3 수정 사항 반영 후 사용): `docs/교과설명/*_중학교.md`, `docs/교과설명/_난이도체계.md`.
- 원칙(R7·R8 유지): ① 물리 값·식·정답 키 불변 — **중급·고급의 기존 예측 질문·정리 문항 answer 는 그대로**, 초급은 별도 묶음으로 추가. ② 같은 파일은 한 팀만. ③ CSS↔JS 는 이 문서의 클래스 이름으로 각자 자기 파일만. ④ 성취기준 코드는 확인된 것만 — 중학교 코드는 **쓰지 않는다**.

## 0. 진단·기획 요약

### 0-1 모두가 같은 말을 한 것 (높음)
1. 5종 설명 1장부터 고등 기호($v_0$, $θ$, $E_k$, $Δy$, $λL/d$, F·2F)가 정의 없이 나오고 '중학교에서 배운 것' 장이 없다(학생 M·H·S, 교사 P·Q·R 전원).
2. [심플|자세히]는 화면 배치 선택이지 난이도 선택이 아니다. 초급·중급·고급을 따로 더하면 '심플인데 고급' 같은 모순 조합이 생긴다 → **하나로 합친다**(교사 P·Q·R, 기획 C, 학생 M·H·S).
3. 현재 `data.simple` 장 목록에 고등 심화 장(포물선 `energy`, 슬릿 `path-diff`·`dy`·`matter-wave`, 궤도 `escape`)이 들어 있어 초급으로 쓸 수 없다(학생 M, 교사 Q).
4. 갈래가 있는 두 단원(궤도 대포/위성/케플러, 슬릿 빛/전자)은 초급에서 갈래 하나만(교사 R, 기획 B·C).

### 0-3 기획 원고에서 고친 것 (물리·교육과정)
- 포물선 복습 1: '공기를 무시하면 무거운 공도 가벼운 공도 같이 떨어져요' 유지. 복습 2 의 '일을 할 수 있어요' → 초급 금지어는 아니나 '일' 이 물리 용어라 **'높은 곳의 물체는 떨어지면서 무언가를 움직일 수 있어요'** 로 바꾼다.
- 충돌 복습 2 확인 질문(트럭·승용차 힘 같음)은 중급 오해 카드 `truck-force` 와 겹친다 → 복습에서는 **'힘은 같아요'를 답으로 미리 알려주는 질문을 빼고** '가벼운 쪽과 무거운 쪽 중 속도가 더 많이 바뀌는 쪽은?'(답: 가벼운 쪽)으로 바꾼다(오해 카드의 발견 기회 보존).
- 궤도 복습 1 '무중력(우주에서 몸이 뜨는 느낌을 부르는 일상어)' 는 6장 `weightless` 와 이어지므로 **'우주에서 몸이 뜨는 것은 중력이 없어서가 아니에요 — 이유는 뒤에서'** 한 줄로 바꾼다(정답 누설 금지와 호기심 유지).
- 궤도 복습 2 행성 주기 수치(0.24·0.62·1·1.88 년)는 sim 자료와 같아 유지.
- 슬릿 복습 1 '파동의 속력 = 진동수 × 파장' 은 중학교 범위 불확실 → **쓰지 않는다**('주기 = 1 ÷ 진동수' 만).
- 슬릿 복습 2 nm 설명 '머리카락 굵기의 7만분의 1' → 0.07 mm ÷ 650 nm ≈ 108 배라 **틀림**. '머리카락 굵기(약 0.07 mm)의 100분의 1쯤' 으로 고친다.
- 렌즈 복습 1 '유리 속에서 빛이 느려져 수직선 쪽으로 꺾여요' 는 중학교 범위 밖 설명 → '유리로 들어가면 수직선 쪽으로 꺾여요' 까지만(이유는 고등).
- 렌즈 복습 3 '② 가까이 → 큰 거꾸로 화살표(스크린 더 멀리)' 유지. 초급 카드 ①의 '가운데(초점거리의 2배)' 는 초급 금지 표현(2F) 없이 '렌즈에서 20 cm' 로.
- 모든 복습 장 학년·단원 표기: **'중학교 과학 ○○ 단원(학년·단원명 확인 필요)'** 로 통일. 코드 없음. teacherNote 첫 줄에도 같은 문구.

## 1. 난이도 체계 확정

### 1-1 단계 정의
| | 초급 basic (1) | 중급 mid (2) | 고급 adv (3) |
|---|---|---|---|
| 한 줄 | 중학교 수준 · 관찰·비교 | 고교 기본 · 핵심 식 | 식 유도 · 한계 조건 · 정량 비교 |
| 화면 배치 | 지금 심플 배치(`html.is-simple`) | 지금 자세히 | 지금 자세히 + 더 많은 설정·갈래·표 기본 펼침 |
| 변수 | 1~2개(나머지 고정, 값은 유지) | 핵심 변수(지금 패널) | 전부(⚙ '더 많은 설정' 항목을 패널로 올림) |
| 실험 카드 | 2~4개(§4) | 지금 전부 | 전부 + 고급 카드 1~2개 |
| 계기 | 1~2칸, 숫자 없는 막대·'넓다/좁다' 말 | 지금 | 지금 + 이론·측정 비교 칸 |
| 식 | 숨김. 'ƒ 식' 단추 글자 **'공식 보기'**, 팝업 첫 줄 '이 실험에서 쓰는 식은 이것 하나예요' | 지금 | 지금 + 유도 장 |
| 예측 질문 | 장면형·말 보기(카드 `basic` 변형) | 지금 | 지금(수치형 변형은 2차) |

| 금지어(초급) | 벡터, 성분, 구심력, 위상 차, 경로차, 충격량, 반발 계수, 실상·허상, 2F, 물질파, 광자 | — | — |
| 권장 시간 | 설명 10 · 예측 5 · 실험 20 · 정리 10 | 5 · 10 · 20 · 10 (지금) | 5 · 5 · 25 · 10 |

### 1-2 심플·자세히 정리 (호환 대응표)
| 옛 것 | 새 것 |
|---|---|
| `?simple=1` / `?simple=0` | `?level=basic` / `?level=mid` 로 읽음. 주소는 그대로 두어도 동작(syncQuery 는 `level=` 로 다시 씀) |
| `localStorage physsim.mode` 'simple'/'full' | 읽기만(basic/mid). **쓰지 않고 지우지 않음** |
| `SK.isSimple()` | `SK.level()==='basic'` 호환 함수 유지 |
| `SK.setSimple(on,o)` | `SK.setLevel(on?'basic':'mid', o)` 위임 |
| `SK.onMode(fn)` | 유지(`fn(on)`), 내부에서 `SK.onLevel` 에 연결 |
| `cfg.simple` | `cfg.levels.basic` 이 없으면 basic 으로 자동 변환(필드 그대로) |
| `data.simple`(lesson) | 장 `levels` 가 없으면: 목록에 있는 장 → `['basic','mid','adv']`, 없는 장 → `['mid','adv']` |
| 확인 질문 `simple:false` | `levels:['mid','adv']` |
| `html.is-simple` / `.simple-only` CSS | basic 일 때 그대로 붙는다(레이아웃 재사용). 추가로 `html[data-level]` |
| 키 M 심플↔자세히 | 초→중→고 순환 |
| `physsim.simpleToastShown` | `physsim.levelToastShown` (새 키) |
| 허브 우상단 [심플\|자세히] | 제거. 부제 줄 [초급\|중급\|고급] |
| 카드 칩 '심플' | '초급'·'중급'·'고급' 칩(늘 보임) |

### 1-3 주소 · 키 · 저장 (우선순위 높음 → 낮음)
`?level=` > `?simple=` > `physsim.level.<slug>` > `physsim.level` > `physsim.mode` > 기본 **basic**

| 항목 | 규칙 |
|---|---|
| `?level=basic\|mid\|adv` (별칭 `1\|2\|3`) | 적용 후 **단원 개별 키**에 저장 |
| `&keep=0` | 이번만 적용, 어떤 키에도 저장하지 않음(교사 시연 링크). 실험 중 칩으로 바꾸면 그때는 저장 |
| `physsim.level` | 허브에서 고른 전역값 |
| `physsim.level.<slug>` | 시뮬레이터 안 칩·⚙·M 으로 바꾼 값 |
| 허브에서 바꾸면 | `physsim.level` 저장 + `physsim.level.*` 전부 삭제 + 토스트 |
| `?teacher=1`, `?view=`, `?mode=`, `?ch=` | 그대로, 단계와 독립 |
| 허브 [열기]·갈래 링크 | 현재 단계 `?level=` 자동 부착(`buildQuery`) |

### 1-4 허브 · 머리줄 UI
- 허브 제목 아래 부제 줄: `내 수준` + `.mode-seg.hub-level`(3칸, 각 칸 title 한 줄 설명) + 첫 방문(저장값 없음)에만 `.hub-level__hint` '중학교 개념부터 보려면 초급, 수업을 따라가면 중급, 식 유도까지 고급'. 우상단 `#modeSeg` 제거. ⋯ 팝오버 키 안내 'M 단계 바꾸기'.

- 독립. 교사 모드 ON 이어도 단계 칩·설정·M 그대로. 수업 안내 서랍 첫 줄에 '지금 단계: 중급 (권장 5·10·20·10)'.

- 시연 = 교사 기기 `?level=mid&keep=0` 링크, 학생 = 각자 기기. README 교사 안내에 한 단락.

### 1-6 실험 중 단계 바꾸기 (공통 규칙 — UI팀1 구현, 각 sim 은 `SK.onLevel` 에서 자기 것만)
1. 값·재생 위치·기록 표·예측 답·정리 입력 **유지**. 컨트롤 노드만 옮기거나 숨김(기존 enterSimple/leaveSimple).
2. 올릴 때: 새로 보이는 변수는 현재 값 그대로(이미 기본값).
3. 내릴 때: 숨는 변수 중 값이 기본과 다른 것이 있으면 토스트 '이전에 바꾼 값이 있어요 — ⋯ 더 보기에서 확인'(5초). 되돌리지 않음.
4. 현재 카드가 새 단계 목록에 없으면 토스트 '이 카드는 중급부터 나와요' (카드 유지).
5. 갈래(mode)가 새 단계에 없으면(궤도 sat/kepler → 초급, 슬릿 quantum → 초급): 토스트 '이 갈래는 중급부터 나와요' + 갈래 유지(값 보존). 초급 레일의 상황 칩은 숨김. sim 이 `SK.onLevel` 에서 처리.
6. 바꾼 순간 토스트 '중급으로 바꿨어요 — 값은 그대로'(3초, 다른 토스트와 합쳐 한 번).
7. 열린 설명 층: 장 목록 재구성, 현재 장 id 가 새 목록에 없으면 가장 가까운 **앞** 장.

## 2. 공통 API (팀 사이 약속 — 이름 고정)

### 2-1 shared/sim.js (UI팀1)
```js
SK.LEVELS = [ {id:'basic', n:1, label:'초급', desc:'중학교 수준 · 관찰과 비교'},
              {id:'mid',   n:2, label:'중급', desc:'고교 기본 · 핵심 식'},
              {id:'adv',   n:3, label:'고급', desc:'식 유도 · 한계 조건 · 정량 비교'} ];
SK.level()                 // 'basic'|'mid'|'adv'
SK.levelN()                // 1|2|3
SK.setLevel(lv, {save:true, silent:false, source:'chip'|'key'|'settings'|'init'})
SK.onLevel(fn)             // fn(lv, prev) — setLevel 뒤, enter/leaveSimple 뒤에 부름
SK.levelCfg()              // 현재 단계의 cfg.levels[lv] (basic 은 cfg.simple 과 병합된 결과)
SK.levelLabel(lv)          // '중급'
SK.isSimple(); SK.setSimple(on,o); SK.onMode(fn)   // 호환(§1-2)
SK.atLevel(x)              // x 가 {basic:..,mid:..,adv:..} 객체면 현재 단계 값, 아니면 x 그대로 — 문구 변형용 (sim·lesson 공용)
SK.levelAllows(levels)     // levels 배열(없으면 ['mid','adv'])에 현재 단계가 있는지
```
- `cfg.levels = { basic:{task, params(≤2), situation(≤1), meters(≤2), presets, predict, extras, modes, chips:[{text}]}, mid:{presets?, modes?}, adv:{presets?, modes?, expose:[key…], openMore:true} }`
  - `basic` 없으면 `cfg.simple` 사용(params 는 3개까지 허용 — 경고만). `basic.chips` 는 할 일 줄 옆 고정 칩(예: '절벽 20 m').
  - `mid.presets`/`adv.presets` 없으면 전체. `modes`(갈래 목록) 없으면 전체. `adv.expose` 는 ⚙ '더 많은 설정'에 있던 컨트롤 key 를 패널로 올림(`SK.exposeControl(key, true)` — 노드 이동). `adv.openMore` 는 설정 '더 많은 설정' 그룹 펼침 기본.
  - 프리셋(카드) 단계 변형: `PRESETS[i].basic = {name?, q?, choices?, answer?, why?, set?}` — basic 일 때만 덮어씀. **mid·adv 는 기존 필드 그대로(answer 불변)**. `SK.presetView(p)` 가 병합해 준다(실험 고르기 시트·예측 띠·해설 모두 이 함수를 거침).
  - 카드 필터: 현재 단계 `presets` 목록 밖의 카드는 실험 고르기 시트에서 숨김(숫자 키도 목록 순서). `SK.presetAllowed(i)`.
- 머리줄 칩 `SK.el.levelChip`, 설정 분절 `SK.el.levelSeg`(기존 `SK.el.modeSeg` 이름은 별칭 유지). html: `data-level="basic|mid|adv"`, `.is-simple`(basic), `.is-level-adv`.
- 계기 숫자 숨김: `meters` 항목 `{key, plain:true}` → `.meter.is-plain`/`.simple-meter.is-plain` (값 글자 대신 라벨만, 막대·말 계기용). 사용처: 포물선 에너지 막대 숫자, 충돌 p·k.
- 토스트 문구(§1-6)는 sim.js 가 한 곳에서 만든다. 'ƒ 식' 단추: basic 일 때 글자 '공식 보기', 팝업 첫 줄 고정 문구.
- 저장·주소 해석(§1-3)은 `readLevelPref()`/`saveLevelPref(lv, {scope:'unit'|'global'})`/`syncLevelQuery(lv)`.
- 키 M: `setLevel(next)`, 순환. 도움말 '[M] 단계 바꾸기(초급→중급→고급)'.
- 허브에서 쓰는 해석 규칙은 index.html 이 **같은 순서로 따로 구현**(sim.js 를 허브가 불러오지 않음). 함수 이름 `readLevel()`·`setLevel()`, 키 이름은 §1-3 과 같아야 한다.

## 6. 회귀 금지
1. 물리 값·식·정답 키 불변. 중급·고급의 PRESETS `answer`, `wrap.quiz` `answerIdx`, 오해 카드 `try` 불변. 초급 변형은 `basic` 객체·`levels:['basic']` 문항으로만 추가.
2. `?simple=1` → 초급 화면(레일·막대·시트) 그대로 동작, `?simple=0` → 중급. `physsim.mode` 만 있는 브라우저도 같은 단계로 열린다. `physsim.mode` 를 지우거나 덮어쓰지 않는다.
3. 중급 = 지금 자세히와 화면·장 목록·카드·정리 문항이 **같다**(복습 띠 한 줄만 추가). 5종 중급 캡처가 R8 최종 캡처와 띠 외에 다르지 않다.
4. 단계 전환 중 값·기록·예측 답·재생 위치·정리 입력이 사라지지 않는다(audit c).
5. 정답 누출 금지(R8 2 유지): 초급 말 계기·막대가 예측 중에 답을 보이지 않는다. 슬릿 초급 `band` 는 실행 뒤에만.
6. 키보드: M 순환, 기존 키(J·Y·U·S·Esc·숫자) 유지. 칩 메뉴는 Esc 로 닫히고 포커스 복귀.
7. 교사 모드·교사 발표·타이머·손들기 독립 동작. `?teacher=1&level=…&keep=0` 로 열어도 저장값이 바뀌지 않는다.
8. 복습 장 본문·teacherNote·docs 에 성취기준 코드 없음(grep `\[9과|\[중`). 초급 DOM 에 금지어 없음(audit d).
9. 'ƒ 식' 팝업·기호 칩·설명 ↔ 실험 연결(`chapterFor`·`symFlash`)이 단계와 무관하게 동작. 복습 장 id 가 `links`·`chapterFor` 를 깨지 않는다.
10. 허브 카드 [열기]·갈래 링크·숫자 키 1~5 동작, 카드 바닥선 정렬(R7) 유지, 820 세로 배치 깨지지 않음.
11. 파일 경계: 디자인 = lesson.js·diagram.js·CSS·tokens·index.html·sims/*/lesson.js·docs(SIMKIT 제외)·README, UI팀1 = sim.js·PE·tools·SIMKIT, UI팀2·3 = 자기 sim 폴더(lesson.js 제외). 같은 파일을 두 팀이 만지지 않는다.
12. `node --check shared/*.js sims/*/*.js` 전부 통과, 콘솔 오류 0(5종×3단계×설명/실험).
