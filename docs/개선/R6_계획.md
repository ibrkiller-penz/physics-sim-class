## 1. 심플 모드 설계

### 1-1. 원칙 (8줄)
1. **같은 DOM·같은 상태.** 켜고 끄는 것은 `html.is-simple` 클래스 하나. `SK.ui`·`SK.params`·기록·예측·선택 카드·실행 위치를 다시 만들지 않는다. 핵심 변수 컨트롤은 **노드를 옮긴다**(appendChild) — 핸들러·값 그대로. 되돌릴 때 원래 자리(부모·다음 형제 기억)로 되돌린다.
2. **실험 화면이 주인공.** 무대 1360×672u(1920 기준, 일반 모드 약 1.15배). 예측 창·모드 창을 자동으로 띄우지 않는다.
3. **변수 3개 이하, 측정값 3개 이하, 상황 칩 한 줄 이하.** 나머지는 `⋯ 더 보기` 시트 하나. 시트 안 스크롤 한 겹뿐.
4. **큰 실행·다시.** 아래 막대 88u, `[▶ 실행 360×72]` `[↺ 다시 200×72]` `[속도 168×72]` … `[실험 ▾ 240×72]` `[⋯ 더 보기 200×72]`. 실행 중엔 같은 자리·같은 폭으로 `⏸ 멈추기`.
5. **칠판 글자·누름.** 글자 하한 28u(태블릿은 `max(18px, …)`), 값 64~72u, 측정값 64u, 누름 64u 이상, 사이 16u. 굵기 400/500. 비활성은 점선 테두리 + 보조색(opacity 금지).
6. **단원색 윗선 12u.** 머리줄 위에 시뮬레이터 대표색(`--sim`) 띠. 일반 모드에도 같이 넣는다(S3).
7. **토글은 두 모드에서 같은 자리.** 머리줄 오른쪽 `[심플 | 자세히]` 분절(288×64u, `aria-pressed` 쌍). 키 `M`. 허브에도 같은 분절.
8. **일반 모드 규칙은 `html.is-simple` 가 없으면 한 줄도 켜지지 않는다.** 심플 CSS 는 전부 `html.is-simple` 로 시작.

### 1-2. 켜는 방법·기억·우선순위
- URL `?simple=1` → 심플, `?simple=0` → 자세히. **쿼리가 저장값보다 먼저** 적용되고, 읽은 뒤 저장한다.
- 저장 키 하나 `physsim.mode` = `'simple' | 'full'` (허브·sim 공통, 모든 읽기/쓰기 `try/catch`). 저장 없음 + 쿼리 없음 → 자세히(기존 사용자 회귀 없음).
- 허브 분절을 바꾸면 5장 카드 [열기]·보조 링크에 `?simple=1`(또는 제거) + 교사 모드면 `&teacher=1`. 링크 쿼리 조립은 `index.html` 의 R5 `setTeacher` 패턴을 공용 함수 `buildQuery({simple, teacher})` 로 합친다.
- 심플 첫 진입 1회 토스트: "자세히 모드는 오른쪽 위 [자세히] 로 바꿔요" (키 `physsim.simpleToastShown`).
- `SK.isSimple()`, `SK.setSimple(on, {save:true})`, `SK.onMode(fn(simple))`. `cfg.simple` 선언 없는 sim 은 토글이 숨겨지고 항상 자세히(하위 호환).

### 1-3. 각 sim 이 선언하는 API (shared, `SimKit.init`)
```js
SimKit.init({
  …,
  simple: {
    task:    '속력과 각도를 바꿔 공이 어디까지 가는지 봐요',   // 안내줄 한 줄(40u). 함수(p) 가능
    params:  ['v0', 'theta'],            // 레일에 옮길 변수 key 1~3개 (addVar/addChoice/addToggle 의 key). 없는 key·모드에 따라 숨는 key 는 자동 생략
    situation: ['planet'],              // (선택) 무대 아래 칩 한 줄로 보일 choice key 0~1개 (style:'cards' 인 addChoice → 칩으로 다시 그림, 값은 같은 SK.ui)
    meters:  ['x', 'vx', 'vy'],          // 큰 측정 칸 1~3개 (SK.meters 의 key). 값 갱신은 기존 meters 경로가 .simple-meter[data-key] 에도 쓴다
    presets: [0, 1],                     // '실험 ▾' 시트에 보일 setPresets 인덱스(또는 name). 생략 = 전부
    predict: 'button',                   // 'button'(기본: 안내줄 [예측 ▸] 로만 연다) | 'off'(심플에서 예측 없음)
    extras:  [ { label:'에너지 막대', key:'energy' } ],   // (선택) 더 보기 시트 맨 위 토글 줄에 둘 addToggle key
    stage:   { legend:'none' }           // (선택) 심플에서 캔버스 보조 글자 처리를 sim 이 SK.isSimple() 로 읽어 스스로 그린다 (아래 1-7)
  }
});
```
- 모드 전환 때 `SK.view.resize()` 한 번(ResizeObserver 가 이미 있으면 그것이 처리) → `cfg.onResize` 로 sim 이 좌표 재계산. 전환 애니메이션은 120ms 투명도만, `prefers-reduced-motion` 이면 0.
- `SK.isSimple()` 로 sim 이 캔버스 안 글자·범례를 바꿀 수 있다(예: 눈금 5칸마다, 글자 28u). 물리는 건드리지 않는다.

- **세로 820×1180** (`(orientation: portrait) and (min-width: 601px)`): 디자이너 §3-2 채택 — 띠 10 · 머리줄 64 · 안내줄 56 · 무대 788×504 · 측정 3칸 252×88 · 변수 3장 788×104(이름 32·값 56·−/+ 72) · 막대 72(실행 280×64·다시 168×64·실험 148·더 보기 148). 누름 56 이상.
- 교사 모드와의 관계: `html.is-teacher.is-simple` 에서는 성취기준 칩·`수업 안내(교사)`·`수업 정보` 버튼을 머리줄에서 숨기고 더 보기 시트로 보낸다. 예측 창의 손들기 수는 그대로. 교사 모드 길게 누르기(H 3초)도 그대로.
- 키: 기존 키 전부 유지(Space·←→·1~5·S·R·C·, .·[ ]·F·T·?·H·V·Esc). **`M` = 모드 토글**(입력칸 포커스 중 제외). Esc 는 열린 시트를 먼저 닫는다.
