| 뉴턴 운동 법칙 | 움직이려면 계속 힘이 필요하다. 힘이 크면 속도가 크다(힘∝속도) | 힘은 **속도의 변화(가속도)**를 만든다 | 마찰을 없앨 수 없어 '힘 없이 계속 움직임'을 보기 어렵다 |
| 제동 거리 | 무거운 차가 더 빨리 멈춘다. 속력이 2배면 제동 거리도 2배 | 마찰만으로 멈출 때 제동 거리는 질량과 관계없고 **속력의 제곱**에 비례 | 실제 차로 실험 불가 |
| 작용·반작용 | 무겁거나 빠른 쪽이 더 큰 힘을 준다. 가만히 있는 물체는 힘을 주지 않는다 | 두 힘은 **항상 크기가 같고 방향이 반대** | 충돌 순간의 힘을 동시에 재기 어렵다 |
| 운동량 보존 | 운동량이 보존되면 운동 에너지도 보존된다 | 비탄성 충돌에서는 운동 에너지가 열 등으로 줄지만 운동량은 보존 | 수레 실험은 마찰 때문에 오차가 크다 |
| 역학적 에너지 | 높이가 같아도 경로가 다르면 바닥 속력이 다르다. 마찰로 에너지가 '사라진다' | 마찰이 없으면 바닥 속력은 높이만으로 결정. 마찰이 있으면 열로 전환, 총량 보존 | 열로 바뀐 양을 보기 어렵다 |
| 포물선 운동 | 수평으로 던지면 그냥 떨어뜨린 것보다 늦게 떨어진다. 최고점에서 속도·가속도가 0. 던진 방향으로 힘이 계속 작용 | 수평 등속 + 연직 자유 낙하로 **분리**. 최고점에서도 가속도는 g | 운동이 1초 안에 끝나 눈으로 분리해 보기 어렵다 |
| 원운동·인공위성 | 우주에는 중력이 없다(무중력). 위성은 떨어지지 않는다. 무거운 위성은 더 빨리 돌아야 한다 | 위성은 **계속 떨어지고 있다**(중력=구심력). 궤도 속력은 위성 질량과 무관 | 실험 불가 |
| 탈출 속도 | 로켓이 충분히 높이 올라가면 중력이 없어진다 | 중력은 줄어들 뿐 사라지지 않는다. 탈출 속도는 행성의 질량·반지름에 따라 다르다 | 실험 불가 |
| 정상파 | 정상파는 움직이지 않으니 파동이 아니다. 줄이 길수록 높은 소리. 반사하면 항상 뒤집힌다 | 정상파는 반대로 가는 두 파동의 **중첩**. 길수록 파장이 길어 낮은 소리. 고정단은 뒤집히고 자유단은 그대로 | 중첩 전의 두 파동을 따로 볼 수 없다 |
| 볼록렌즈 | 렌즈를 반쯤 가리면 상도 반만 생긴다. 스크린이 없으면 상이 없다 | 상의 모든 점은 렌즈 전체를 지난 빛이 모여 생긴다. 가리면 **어두워질 뿐** | 광선이 보이지 않는다 |
| 전자기 유도 | 자석이 구리관을 끌어당겨 느려진다. 자석이 코일 안에 가만히 있어도 전류가 흐른다 | 구리는 자석에 붙지 않는다. **자기선속이 변할 때만** 유도 전류. 맴돌이 전류가 운동을 방해(렌츠 법칙) | 관 속 맴돌이 전류가 보이지 않는다 |
| 이중 슬릿·양자 | 스크린에 밝은 줄이 두 개 생긴다. 전자는 한 슬릿만 지나는 작은 공. 하나씩 보내면 간섭이 없다 | 여러 줄의 간섭무늬. 하나씩 보내도 **쌓이면 간섭무늬**. 어느 슬릿인지 재면 무늬가 사라진다 | 단일 전자 실험은 학교에서 불가 (교육과정이 모의실험 권장) |

## 5. 시뮬레이터 후보 8종 (탐구 활동 → 변수·상황·프리셋 대응표)

### 공통 설계 규칙 (모든 후보)

1. **변인 통제가 기본 동작.** 프리셋을 누른 뒤 학생이 바꾸는 값은 **한 번에 하나**가 되도록, 나머지 값은 프리셋 값으로 고정된다. '기록 남기기'를 누르면 그때의 모든 변수 값이 기록에 함께 남아, 비교할 때 무엇이 달랐는지 표에 굵게 표시된다.
2. **반영 방식 표시.** 변수 옆에 작은 글자로 `즉시` 또는 `다시 시작`을 붙인다. 운동 중 바꾸면 물리적으로 말이 되는 값(마찰, 중력, 공기 저항, 표시 도구)은 `즉시`, 초기 조건(처음 속력, 발사 각도, 처음 위치)은 `다시 시작`.
3. **g 값.** 교과서 계산 문제는 g = 10 m/s²를, 실험 보고는 9.8 m/s²를 많이 쓴다. 기본값은 9.8로 하고 '계산 쉽게(g=10)' 전환을 둔다. 문항 재현 프리셋은 g = 10을 쓴다.
4. **심화 접기.** 성취기준 해설이 '다루지 않는다'고 한 것(결상 공식, 타원 궤도 정량, 반발 계수 계산 등)은 기본 화면에 두지 않고 `심화 ▸`로 접는다.
5. **비교.** 직전 실행 1회는 자동으로 흐리게 겹쳐 보이고, '기록 남기기'로 최대 5회까지 표와 그래프에 남긴다. R = 초기화.

  1. **기타 줄** — 현, L 0.65 m, n 1→2→3
  2. **[탐구 재현] 공명관으로 음속 측정** — 닫힌관, 512 Hz, 20 °C. 관 길이를 늘려 가며 첫 공명(약 0.17 m)과 둘째 공명(약 0.50 m) 찾기 → 두 길이 차 = λ/2 → 음속 = f × λ
  3. **[반사] 고정단 vs 자유단** — 펄스 하나 보내기, 고정단은 뒤집혀서 / 자유단은 그대로 돌아옴
  4. **열린관 vs 닫힌관** — 같은 길이 0.50 m에서 기본음 비교(닫힌관이 한 옥타브 낮음)
  5. **[오개념] 정상파는 두 파동의 합** — 진행파 두 개 보기 켜고 아주 느리게
- **심화(접기):** 줄 장력·선밀도로 줄의 파동 속력 바꾸기, 관 끝 보정

### 후보 7. `magnet-brake` — 전자기 유도와 자기 브레이크 (전자기와 양자)

- **성취기준:** [12전자01-05] 자기선속의 변화로 전자기 유도, 변압기·인덕터 등 활용. 연계 [12물리02-06], [12물리01-05](운동 에너지 → 열)
- **교육과정 탐구 활동:** 도체판과 자석을 이용하여 자기 브레이크 탐색하기
- **탐구 질문:** ① 구리관 속에서 자석은 왜 천천히 떨어질까? ② 관에 세로로 틈을 내면? ③ 코일에 자석을 넣을 때와 뺄 때 전류 방향은?
- **모형 안내:** 낙하관 속 맴돌이 전류는 '속력에 비례하는 저항력'으로 단순화한다(화면에 '단순화한 모형' 표시). 값은 실험 영상에서 흔히 보이는 정도(1 m 구리관에서 강한 네오디뮴 자석이 수 초)에 맞춘다.

| 변수 | 범위 · 기본값 | 반영 | 근거 | 학생이 발견할 것 | 깨는 오개념 |
|---|---|---|---|---|---|
| 자석 세기 | 약 / 보통 / 강 (0.1 / 0.3 / 0.5 T) | 다시 시작 | 선속 변화량 | 자석이 셀수록 더 느리게 떨어짐 | |
| 자석 질량 | 10 ~ 50 g, 5 간격, 기본 20 g | 다시 시작 | 끝 속력은 질량에 비례 | 무거우면 덜 느려진다(중력은 크고 저항력은 같은 방식) | |
| 관 길이 | 0.5 ~ 1.5 m, 0.1 간격, 기본 1.0 m | 다시 시작 | 자유 낙하 1 m ≈ 0.45 s와 비교 | | |
| (코일 모드) 감은 수 N | 50 ~ 500, 50 간격, 기본 200 | 즉시 | 유도 기전력 ∝ N × 선속 변화율 | 감은 수 2배 → 바늘 2배 | |
| (코일 모드) 자석 속력 | 0 ~ 2.0 m/s, 0.1 간격, 기본 0.5 (드래그도 가능) | 즉시 | 선속 변화율 | 빨리 움직일수록 전류 크다. **멈추면 0** | 자석이 코일 안에 있기만 하면 전류가 흐른다 |

- **상황 전환(5):** ① 모드: 낙하관 / 코일과 검류계 / 진자 도체판(자석 사이를 지나는 판) ② 관·판 재질: 구리 / 알루미늄 / 플라스틱 / 틈 있는 구리 ③ 자석 극 방향: N극 아래 / S극 아래 ④ 측정 도구: 자기선속-시간 그래프, 유도 전류 화살표(맴돌이 전류 고리), 높이 표시·시간 게이트, 에너지 막대(운동·위치·열) ⑤ 판 종류(진자 모드): 통판 / 빗살 판
- **프리셋:**
  1. **[탐구 재현] 플라스틱 관 vs 구리관 동시 낙하**
  2. **틈 있는 관** — 맴돌이 전류 고리가 끊어져 거의 자유 낙하
  3. **코일에 넣었다 빼기** — 넣을 때와 뺄 때 바늘 방향 반대, 멈추면 0
  4. **[탐구 재현] 자기 브레이크 진자** — 통판은 금방 멈추고 빗살 판은 오래 흔들림 (놀이기구 낙하 브레이크와 연결)
  5. **[오개념] 구리는 자석에 붙을까?** — 정지한 자석 옆에 구리판: 아무 힘 없음 → 움직일 때만 힘
- **심화(접기):** 렌츠 법칙 화살표 단계별 설명, 변압기(1차·2차 감은 수 비) 미니 화면

### 후보 8. `double-slit-quantum` — 이중 슬릿: 빛에서 전자 하나까지 (전자기와 양자 / 물리학)

- **성취기준:** [12전자03-01] 단일 양자 이중 슬릿으로 입자-파동 이중성, 확률 파동의 간섭으로 해석. [12물리03-01] 빛의 중첩과 간섭. 연계 [12전자03-02] 측정에 따른 상태 변화(정성)
- **교육과정 탐구 활동:** 이중 슬릿에 의한 빛의 간섭 관찰하기(물리학), **전자의 이중 슬릿 실험에 대한 컴퓨터 모의실험하기**(전자기와 양자)
- **탐구 질문:** ① 파장이 길면 무늬 간격은? ② 전자를 하나씩 보내도 무늬가 생길까? ③ 어느 슬릿으로 지나갔는지 확인하면 어떻게 될까?

| 변수 | 범위 · 기본값 | 반영 | 근거 | 학생이 발견할 것 | 깨는 오개념 |
|---|---|---|---|---|---|
| 빛의 파장 λ | 400 ~ 700 nm, 10 간격, 기본 650 nm(빨간 레이저 포인터) | 즉시 | 학교 실험 레이저. 색과 함께 표시 | 파장이 길수록 무늬 간격이 넓다 | |
| 슬릿 간격 d | 0.10 ~ 0.50 mm, 0.05 간격, 기본 0.25 mm | 즉시 | 시판 이중 슬릿 | 간격이 좁을수록 무늬가 넓다 | 밝은 줄은 슬릿 수만큼(두 개) |
| 스크린 거리 L | 0.5 ~ 3.0 m, 0.1 간격, 기본 2.0 m | 즉시 | 교실 실험 거리. 기본값에서 무늬 간격 약 5.2 mm | 멀수록 무늬 간격이 넓다 | |
| 보내는 빠르기 | 1 ~ 1000 개/s, 기본 20 (입자 모드) | 즉시 | 하나씩 쌓이는 과정 보기 | 처음엔 무작위 점 → 쌓이면 간섭무늬(확률) | 하나씩 보내면 간섭이 없다 |
| (전자) 가속 전압 | 심화로 접음. 드브로이 파장 표시 | 다시 시작 | 03-01 해설 '드브로이 관계식 바탕, 정성' | 전압↑ → 파장↓ → 무늬 촘촘 | |

- **상황 전환(5):** ① 보내는 것: 빛(파동) / 광자 하나씩 / 전자 하나씩 / 작은 구슬(고전 입자, 비교용) ② 슬릿: 둘 다 열기 / 하나 막기 ③ 어느 슬릿 측정기 켜기/끄기(켜면 간섭무늬 사라짐) ④ 표시: 스크린 점 / 세기 그래프 / 파면(물결) 그림 ⑤ 색 비교: 이전 기록 무늬를 다른 색으로 겹쳐 보기
- **프리셋:**
  1. **[탐구 재현] 레이저 이중 슬릿** — 650 nm, 0.25 mm, 2 m, 무늬 간격 재기
  2. **빨강 vs 파랑** — 650 nm와 450 nm 겹쳐 보기
  3. **[탐구 재현] 전자 하나씩** — 1개/s로 시작해 1000개/s까지 쌓기
  4. **구슬과 비교** — 구슬은 두 줄, 전자는 여러 줄
  5. **[기묘함] 어느 슬릿으로 갔나 확인하기** — 측정기 켜면 무늬가 사라진다
- **심화(접기):** 전자 가속 전압과 드브로이 파장, 슬릿 폭에 따른 회절 포락선
- **화면 문구 주의:** 전자 모드의 거리·간격은 실제 크기가 아니라 '확대한 모형'임을 표시한다(실제 전자 실험의 슬릿 간격은 마이크로미터 이하).
