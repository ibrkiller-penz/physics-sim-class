| 극단값 (m 0.5/3, v ±3, u 0/6, τ 0.01/0.2) | 깨지는 곳 없음. u = 0 이면 그래프에 '충격량 +0.00'이 나옴 | J = 0 이면 '포탄 속력이 0 이면 힘이 없어요'가 나오게 함 |

## 4. 교사·학생 관점

| 항목 | 결과 | 조치 |
|---|---|---|
| 캔버스 글자 최소 20u | 힘-시간 그래프 눈금·축 글자가 18u | 20u로 올림. 'F (N)'이 '0' 눈금과 겹쳐서 위로 옮김. 시간 단위는 마지막 눈금에 'ms'로 붙임. 기록 요약이 칸을 넘으면 마지막 1개만 보이게 함 |
| **기록 표의 숨은 변수** | 분리 모드 줄에 숨은 v₁(예: 2.0)이 찍혀서 "대포가 처음에 움직였다"로 읽힘. 벽 모드 줄에는 숨은 m₂가 찍힘 | 이 페이지에서만 `SimKit.valueText`를 감싸, 분리 줄 v₁ = '0', 벽 줄 m₂ = '–'로 보이게 함. 바뀐 칸 굵게 표시는 그대로 |
| 키보드만으로 수업 | 1~5 프리셋, Space, , . , S, R, E·P·X, ←/→ 단계로 수업 흐름 전부 가능 | — |
| 터치 끌기 | 실험 화면에 `touch-action: none`(shell.css)이 있어 끌기가 됨 | — |
| 오개념 장치 | 두 힘 화살표의 크기가 같고 곡선이 대칭임 · 달라붙기에 '열·소리로' 표시 · 에어백은 넓이가 같고 최대 힘만 다름 · 반동 합 0 → 모두 작동 | — |
