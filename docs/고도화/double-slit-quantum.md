# 고도화 점검표 — double-slit-quantum (이중 슬릿: 빛에서 전자 하나까지)

- 점검일: 2026-10-28 · 점검: 고도화팀(물리 교육 · 프런트엔드 QA · 학생 사용성)
- 대상: `sims/double-slit-quantum/` (index.html · double-slit-quantum.js · double-slit-quantum.css). `shared/`는 고치지 않음.
- 검증 방법: `node --check`, node로 `DSQPhys` 불러 해석해와 비교, 로컬 정적 서버(127.0.0.1)에서 브라우저 조작(1600×900 · 1280×720 · 820×1180 세로).
  file:// 직접 열기는 검증 도구가 로컬 파일을 막아 확인하지 못함(코드에 fetch·module·CDN·외부 URL 0건 확인).

## 1. 물리 정확성

| 항목 | 결과 | 조치 |
|---|---|---|
| Δy = λL/d 기본값 | 650 nm/0.25 mm/2.0 m → 5.200 mm, 450 nm → 3.600 mm | 통과 |
| 간섭 세기 식 cos²·sinc², 어두운 줄 | y = Δy/2에서 I ≈ 8×10⁻³² (0), 밝은 줄 0, ±5.13, ±10.25 mm(포락선 때문에 5.2보다 조금 당겨짐) | 통과. 어두운 줄로 재면 정확히 5.2 mm |
| 측정기 켬 = 확률 합(간섭항 없음) | I(0)=1.000, I(2.6)=0.967 → 줄무늬 사라짐 | 통과 |
| 슬릿 하나 | sinc² 넓은 띠(첫 0점 ±26 mm), 중심 이동 d/2 = 0.125 mm | 물리적으로 맞음. 이동량이 작아 눈으로 거의 안 보임 → 남은 문제 |
| 구슬 | 슬릿 그림자 두 띠, 간격 d(0.1+L)/0.1 = 5.25 mm, 측정기 무관 | 통과(명세의 y_s=±d/2는 σ 0.6 mm에 묻혀 한 띠가 되므로 개발자 변경이 타당) |
| 표본 추출(역CDF) | 10만 개 χ²/dof 0.87 | 통과 |
| 드브로이 | 100 V → 0.1226 nm, 10 V → 0.388, 1000 V → 0.0388 nm | 통과 |
| 극단값 | 빛: 0.40 mm(400/0.5/0.5) ~ 21.0 mm(700/0.1/3.0). 전자 상대: 0.42 ~ 36.4 눈금. a=d=0.10 mm에서도 분포 정상 | 계산은 정상. 단, **0.5 mm 히스토그램 칸이 0.4~1.3 mm 줄무늬를 뭉갬** → 아래 조치 |
| 긴 시간 실행 | 적분 없음(표본 누적), 5만 개마다 흐리게, flyers 200개 상한 | 통과 |

## 4. 교사 관점 (요구 C·D: 비교와 변인 통제)

| 항목 | 결과 | 조치 |
|---|---|---|
| **값을 바꾼 뒤 S 기록** | '즉시' 값(λ·d·L·슬릿·측정기)을 바꿔도 같은 실행으로 남아 두 번째 S가 "이 실행은 이미 기록했어요. R 후…"로 거절됨. 프리셋 5(끔→켬 비교), λ 하나씩 바꾸기 수업이 R 없이는 안 됨 | 고침: 값이 바뀌면 `SK.reset()`으로 새 실행으로 넘김. 바꾸기 전 무늬는 직전(oldP 값)으로 남기고, 실행 중이었으면 이어서 실행. 슬라이더를 끄는 동안(0.7초)은 직전을 한 번만 남김. S 직후엔 그 상태를 바로 직전으로 남김 |
| **기록 표 '바뀐 변수 굵게'** | λ·d·L 칸이 결과 칸(전자 '상대' 표기용)이라 공통 틀이 굵게 표시를 못 함 → 변인 통제가 표에서 안 보임 | 고침: 이 칸들에 직접 `is-changed` 표시(크게 보기 창 포함) |
| 빛 파동 모드 단계 | Space 없이 재고 S → 단계가 '예측'에 머묾 | 고침: S 때 '실행'으로 넘기고 기록 2개면 '규칙 찾기'로 |
| 형성 평가 발문 | 물리학 형성 평가가 프리셋 2(빨강→파랑)와 같은 문제 | 고침: "d 를 0.25 → 0.50 mm 로 두 배 하면?"(새 변수로 전이). 양자 입구는 "더 빠른 전자(가속 전압↑)면?"으로 드브로이 관계와 연결 |
| 키보드만으로 수업 | 1~5 프리셋, Space, S, R, M, K, W, Shift+1/2/3, →로 생각해 보기 | 통과 |
| 꼬리표 '기묘함' | 공통 목록에 없어 회색 기본 칩 | 고침: 시뮬레이터 CSS에서 식별색 칩으로 |

## 5. 학생 관점

| 항목 | 결과 | 조치 |
|---|---|---|
| 줄무늬가 좁을 때 히스토그램 | 0.5 mm 칸이 0.4~1.3 mm 줄무늬를 뭉개 '무늬 없음'처럼 보임(d↑·L↓ 탐구 때 오해) | 고침: 0.1 mm 칸에 쌓고 칸 폭을 Δy/4 이하(0.1~0.5 mm)로 자동 조정. 기본(5.2 mm)은 명세대로 0.5 mm. 그래프 제목에 지금 칸 폭 표시 |
| 계기판 '이론 Δy' | "줄무늬 없음"이 좁은 칸에서 잘림 | 고침: 계기판은 "무늬 없음"(기록 표는 그대로) |
| 그래프 제목 | 칸 폭 표시를 넣자 두 줄로 넘침 | 고침: "세기 · 이론 곡선 + 막대(0.5 mm 칸)" |
| 전자 '파장' 슬라이더 | 전자의 파장이 무엇으로 정해지는지 안내 없음(성취기준: 드브로이 관계식 바탕) | 고침: "전자가 빠를수록(가속 전압이 높을수록) 파장이 짧아요" 도움말 |
| 터치 | 확대창 두 번 누르기/끌기, n ± 72u, 슬릿 직접 눌러 막기 | 통과 |
| 오개념 장치 | 구슬 두 띠 vs 전자 여러 줄, 1개/s 무작위, 측정기 직전 무늬, 슬릿 하나 넓은 띠 모두 작동 | 통과 |

## 6. 남은 문제 (shared/ 또는 명세 결정 필요)

1. **[shared] 제목 줄 넘침**: 1920×1080 비례 화면에서 제목 "이중 슬릿: 빛에서 전자 하나…"가 잘리고 상태 줄이 두 줄로 겹침. `shell.css` 제목 줄 폭/말줄임 규칙 검토 필요.
2. **[shared] 기록 표 결과 칸 굵게**: `recordTable` 열에 `changed:true`(결과 칸도 바뀜 비교) 같은 옵션이 있으면 이 시뮬레이터의 DOM 보정 코드를 지울 수 있음.
3. **[shared] 안내 말풍선 위치**: 알림(notice)이 실험 화면 왼쪽 위 프리셋 설명·안내 줄을 가림.
4. **[명세] 슬릿 하나 '위치 이동'**: 실제 이동은 d/2 = 0.125 mm라 화면에서 안 보임. 수용 기준을 "넓은 띠 하나(줄무늬 없음)"로 고치길 권함.
5. **60 fps 실측**: 숨김 창이라 못 잼. 교실 PC에서 프리셋 5 → K 다섯 번 → Space로 확인할 것.
6. 극단 조합(빛 400 nm·d 0.5·L 0.5, 전자 상대 2·10·2)에서는 줄무늬 0.4 mm가 점 지름(0.5~0.6 mm)보다 작아 점 화면에서는 무늬가 안 보임(밝기 띠·히스토그램에서는 보임). 탐구는 한 변수씩 바꾸므로 수업 영향 적음.
7. `window.DSQDebug` 검수용 전역 — 출시 전 지워도 됨.
