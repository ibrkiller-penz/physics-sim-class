# 고도화 점검표 — orbit-gravity (인공위성과 탈출 속도)

- 점검일: 2026-10-28 · 점검: 고도화팀(물리 교육 · 프런트엔드 QA · 학생 사용성)
- 대상: `sims/orbit-gravity/` (index.html · sim.js · orbit-gravity.css). `shared/`는 고치지 않음.
- 검증 방법: node로 RK4 재현(별도 스크립트) + 로컬 정적 서버(127.0.0.1)에서 브라우저 실제 실행(JS로 한 프레임씩 진행). 콘솔 오류 0.
