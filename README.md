# 물리 시뮬레이터 실험실 — 바꾸고, 겨루고, 비교하는 물리 수업 5종

> 배포 주소: **https://penedu.web.app/physics/** (허브) · 폴더: `C:\Users\pc\Desktop\클로드 프로젝트\49_물리-수업시뮬레이터`
> 작성: 팀장 (AI 팀) · 2026-10-28 최종 통합 점검(고도화 1·2차 반영) 기준. 기획·검토·결정·명세는 `docs/`, 1·2차 고도화 의견과 조치는 `docs/개선/최종보고.md`.

고등학교 **2022 개정 교육과정 과학과 선택과목 물리**(「물리학」·「역학과 에너지」·「전자기와 양자」) 수업에서
**선생님이 전자칠판·TV(1920×1080)에 띄워 설명하고, 학생도 태블릿·PC로 직접 조작하는** 시뮬레이터 5종입니다.

- 인터넷이 없어도 됩니다. 글꼴·코드가 폴더 안에 있고 `index.html`을 더블클릭하면 열립니다. 배포 주소에서는 그대로 접속하면 됩니다.
- 다섯 개가 **같은 틀**로 만들어져 있어 하나를 익히면 나머지도 같은 화면 배치·같은 버튼·같은 키로 씁니다.
- 모든 실험은 **① 예측 → ② 실행 → ③ 비교 → ④ 정리** 네 단계로 진행하며, 화면 위 '지금 할 일' 띠가 다음에 무엇을 누르면 되는지 한 문장으로 알려 줍니다.
- 네 가지 기본 요구를 모두 지킵니다.
  - **A. 수치 바꾸기** — 주요 물리량은 슬라이더 + −/+ 버튼 + 숫자 입력칸(단위·범위·'버튼 한 번에 얼마' 표시). ⚡ 표시는 바꾸는 즉시 그림이 바뀌고, ↻ 표시는 ▶ 실행을 다시 눌러야 반영됩니다.
  - **B. 상황 바꾸기** — 중력(지구·달·화성), 공기 저항, 충돌 종류, 보내는 것(빛·전자·구슬), 가림판 같은 상황 전환과, 교과서 탐구에 맞춘 **실험 카드 5장**(하단, 1~5 키). 카드마다 '무엇이 바뀌는지'가 적혀 있고 누르면 예측 질문이 먼저 뜹니다.
  - **C. 기록·비교** — 실행이 끝나면 **기록하기**로 최대 5개 저장. 비교 단계에서 표(바뀐 값은 굵게, '바꾼 값: v₀ 20 → 15' 자동 표기)와 화면 겹침(●▲■◆★ 기호)으로 나란히 봅니다. 한 번에 한 가지만 바꾸도록 안내합니다.
  - **D. 성취기준에 맞춘 변수** — 수치 칸에는 성취기준과 직결된 2~3개만 두고, 나머지는 '더 많은 설정'으로 내렸습니다. 성취기준 코드·대응표·수업 흐름은 교사 모드(`?teacher=1`)의 **수업 안내(교사)**에서만 보입니다.

## 1. 여는 법

1. 허브(`index.html` 또는 https://penedu.web.app/physics/)에서 카드의 **[열기]**를 누르거나 **1~5** 키를 누릅니다. 처음이면 1번(포물선)부터 권합니다.
2. **F** 키 또는 오른쪽 위 **⤢ 전체 화면**. 한글 입력 상태에서도 됩니다.
3. 시뮬레이터 안에서 왼쪽 위 **← 허브** 버튼, 또는 **Esc 두 번**(1.5초 안)으로 허브로 돌아옵니다.
4. 화면은 1920×1080(16:9) 기준이며 1280×720 에서 같은 모양으로 비례해 줄어듭니다. 1180×820·1024×768 처럼 세로가 더 긴 태블릿 화면에서는 위아래 빈 띠 없이 실험 화면·조절 패널이 세로로 길어집니다(R4). 세로로 세운 태블릿(820×1180 등, 폭 601 이상)은 실험 화면이 전폭 위에, 계기·조절 패널(2열)이 그 아래, 실험 카드·실행 줄이 바닥에 오는 세로 배치로 바뀝니다(R5). 예측 창은 세로에서 패널 자리에 떠서 그림을 가리지 않습니다. 폭 600 이하(휴대전화 세로)는 '가로로 돌리면 더 크게 볼 수 있어요' 띠만 띄웁니다.
5. **심플 모드 / 자세히 모드 (R6)** — 허브와 시뮬레이터 오른쪽 위 **[심플 | 자세히]** 로 고르거나 **M** 키로 바꿉니다. 주소에 `?simple=1`(심플)·`?simple=0`(자세히)을 붙여도 되고, 고른 모드는 이 브라우저에 기억됩니다(`physsim.mode`, 주소가 기억보다 먼저).
   - **심플**: 전자칠판에서 바로 보여 주거나 처음 보는 학생용. 실험 화면을 크게, 성취기준의 핵심 변수 2~3개만 큰 슬라이더로(오른쪽, 손 닿는 아래쪽 정렬), 측정값 1~3개를 큰 숫자로, 아래 막대에 큰 **[▶ 실행] [↺ 다시] [속도]** 와 **[실험 ▾] [⋯ 더 보기]**. 단계 흐름·기록 표·정리 질문·나머지 설정·결과 해설은 **⋯ 더 보기** 시트 하나에 모여 있습니다. 예측 창은 저절로 뜨지 않고 안내줄 **[예측 ▸]** 로 엽니다. 실행이 끝나면 알림의 **[해설 보기 ▸]** 로 해설을 엽니다.
   - **자세히**: 지금까지의 화면(단계 띠·조절 패널·계기판·그래프·실험 카드 5장).
   - 두 모드는 같은 실험이라 바꿔도 값·실행 위치·기록·예측이 그대로입니다. 아직 심플 선언이 없는 실험은 토글이 보이지 않고 늘 자세히로 열립니다.
   - 심플에서 남긴 것(성취기준 핵심, `docs/01_커리큘럼분석.md`): 포물선 = v₀·θ(상황: 지구·달·화성) → 수평 거리·vₓ·v_y / 이중 슬릿 = λ·d(상황: 빛·전자 하나씩) → 줄무늬 간격 Δy(전자는 쌓인 점 수) / 충돌 = m₁·m₂·v₁(상황: 튕기기·달라붙기) → 운동량 합·운동 에너지 합(전→후)·판정 / 궤도 = 발사 속력 v₀(상황: 중심 천체, 대포 모드 고정) → 결과(추락·궤도·탈출)·지금 속력·속력 띠 / 렌즈 = 물체 거리 s·초점거리 f → 상 거리·배율·상의 모습. 숫자 키 1~5 는 심플에서 **[실험 ▾]** 시트에 있는 카드만 고릅니다.
   - 화면 크기: 16:9(1920·1280)는 무대 왼쪽·변수 레일 오른쪽, 4:3(1180×820·1024×768)과 세로(820×1180)는 무대 전폭 아래에 측정 줄·변수 줄·막대가 쌓입니다.

글꼴: 에스코어 드림 (S-Core) — 3 Light · 4 Regular · 5 Medium, 공식 OTF 원본 그대로 사용(3개 합계 약 2.1 MB, `shared/fonts/LICENSE_SCDream.txt`). 물리 기호는 시스템 세리프 이탤릭.

## 2. 화면 읽는 법 (다섯 시뮬레이터 공통)

```
[← 허브] 제목                               [수업 정보 ▾] [? 도움말] [⤢ 전체 화면]
① 예측 — ② 실행 — ③ 비교 — ④ 정리 | 지금 할 일 한 문장      [주 버튼] [다음 단계로 가기 ▸]
┌──────────────── 실험 화면 ─────────────────┐ ┌───── 오른쪽 패널 ─────┐
│ 위쪽: 상태 칩(상황·시간)                     │ │ 이번 실험 결과(끝난 뒤)   │
│ 가운데: 그림·그래프 (그림만, 글 상자 없음)    │ │ 수치 바꾸기  [기본값으로] │
│ 아래쪽: 예측 창·실험 고르기 창(여기에 뜸)     │ │ 상황 바꾸기               │
└────────────────────────────────────────────┘ │ 화면에 표시하기           │
계기판 3~4칸 · 작은 그래프 1개 · [저장한 실험 n/5 · 표 보기] │ 더 많은 설정 ▾  ↓ 아래에 더 │
[① 카드][② 카드][③ 카드][④ 카드][⑤ 카드]  [▶ 실행] [한 장면 뒤로/앞으로] [속도 ×1 ▾] [기본값으로 되돌리기] [그 밖의 기능 ▾]
```

- **지금 할 일 띠** — 네 단계가 ○ 번호로 보이고 끝낸 단계는 ✓. 띠의 문장은 상황에 따라 바뀝니다("먼저 사거리를 예측해요" → "끝났어요 — 기록하기 버튼으로 저장해요" → "기록이 2개 있어야 비교해요(지금 1개)"). 단계 번호를 눌러 바로 이동할 수 있습니다.
- **오른쪽 패널** — 위에서부터 **수치 → 상황 → 표시 → 더 많은 설정** 순서. 각 칸에 '0~30 m/s · 버튼 한 번에 1' 같은 범위 안내와 '기본값으로 ↺'가 있습니다. 범위 밖 숫자를 넣으면 입력칸 아래에 이유가 남습니다.
- **비교 단계**에서는 패널 자리에 **기록 표 큰 판**이, **정리 단계**에서는 **정리 질문 판**이 들어옵니다.
- **처음 들어오면** '처음이에요? ⚡는 즉시, ↻는 실행을 다시 눌러야…' 안내 카드가 한 번 뜹니다(알겠어요로 닫음).

## 3. 수업 진행 순서와 설명 기능

| 단계 | 화면에서 일어나는 일 | 교사가 할 일 |
|---|---|---|
| **① 예측** | 실험 카드를 고르면 예측 창(선택형 또는 숫자 입력)이 뜹니다. 창이 떠 있는 동안 결과(궤적·무늬·상)는 가려집니다. | 학생에게 답을 고르게 하고 **[예측하기]**. ✋ 손들기 수(교사 모드)로 선택지마다 손든 수를 적을 수 있습니다. 예측 없이 바로 실행도 가능. |
| **② 실행** | ▶ 실행. 끝나면 '내 예측 ② → 맞았어요/아쉬워요 — 이유'가 자동으로 뜨고, 오른쪽 위에 **이번 실험 결과**(한 줄 + '왜 그럴까? ▾'로 펼치는 설명)가 나옵니다. | 한 장면 뒤로/앞으로, 속도 ×0.1~×2로 순간을 짚어 설명. 띠의 **[기록하기]**로 저장. |
| **③ 비교** | 패널 자리에 기록 표. 바뀐 값은 굵게, '바꾼 값' 열 자동. 기록 2개가 되면 자동으로 이 단계로 옵니다. | 값 하나만 바꿔 다시 실행·기록. 표에서 '같은 열'을 찾게 하기. 시뮬레이터별 보조 카드(규칙 확인·체크리스트·같은 거리 찾기)도 여기에 있습니다. |
| **④ 정리** | 선택형·서술형 정리 질문 4~8개. 보기를 고르면 바로 ✓/✗와 이유, 서술형은 **[답 확인하기]**로 모범 답·해설(힌트는 접혀 있음). | '개념 다시 보기' 버튼으로 도움말 개념 카드를 띄워 정리. |

**? 도움말** (오른쪽 위, 또는 `?` 키) — 탭 4개: **이렇게 해요**(조작 순서 4~6줄) · **개념**(카드 4~6장: 한 줄 요약 → 쉬운 풀이 → 예시 → 그림 → 식 보기(기호·뜻·단위) → 왜 그럴까? → 지금 값으로 계산; 마지막 카드는 '흔한 오해 바로잡기') · **용어**(11~16개, 화면 순서) · **단축키**.
화면의 **점선 밑줄 글자**(예: 중력 가속도, 운동량)에 마우스를 올리거나 누르면 용어 풀이가 뜹니다.

**교사 모드** — 주소 뒤에 `?teacher=1`을 붙이거나 **H를 3초** 누릅니다. 제목 옆에 과목·성취기준 코드, **수업 안내(교사)** 버튼(성취기준 → 발견할 것 → 깨는 오개념 대응표, 40~50분 수업 흐름, 발문), '답 확인 잠금' 토글, 자동 예측 끄기가 생깁니다. 학생 화면에서는 아무것도 보이지 않습니다.

## 4. 키 조작표

화면에는 키를 적지 않고(학생 화면이 복잡해지지 않도록) 모든 조작은 버튼으로도 됩니다. 키는 `? 도움말 › 단축키`에도 있습니다.

### 공통 (허브 + 다섯 시뮬레이터)

| 키 | 하는 일 |
|---|---|
| **1 ~ 5** | 허브: 시뮬레이터 열기 · 시뮬레이터: 실험 카드 적용 (예측 창·실험 고르기 창이 떠 있으면 그 창의 선택지) |
| **F** | 전체 화면 켜기 / 끄기 |
| **Space** | ▶ 실행 / 멈추기 (끝난 뒤면 ↻ 다시 실행, 예측 창이 떠 있으면 창이 흔들림) |
| **→** PageDown / **←** PageUp | 단계 이동 (예측 › 실행 › 비교 › 정리) |
| **S** | 기록하기 (최대 5개, 실행이 끝난 뒤에만) |
| **C** | 기록 모두 지우기 (확인창) |
| **R** | 기본값으로 되돌리기 (기록은 남음) — R6: **두 번** 누르기(첫 번째는 '한 번 더 누르면 되돌려요' 3초). 바꾼 값이 없으면 바로 |
| **M** | 심플 ↔ 자세히 모드 (허브에서도) — R6 |
| **,** / **.** | 한 장면(1/60초) 뒤로 / 앞으로 |
| **[** / **]** | 속도 ×0.1 · ×0.25 · ×0.5 · ×1 · ×2 |
| **T** | 조작판 접기 — 실험 화면이 크게 |
| **V** (누르는 동안) | 예측 창·실험 고르기 창을 잠깐 비켜 그림 보기 (창의 [그림 보기] 버튼과 같음) |
| **?** | 도움말 열기 / 닫기 |
| **H 3초** | 교사 모드 켜기 / 끄기 |
| **Enter** / **Esc** | 예측 창: 확정 / 닫기 (숫자 칸에 글자가 있으면 Esc 한 번은 지우기) |
| **Esc** | 창·도움말·서랍·(심플) 시트 닫기 → 닫을 것이 없으면 1.5초 안에 두 번 = 허브로 |

- 숫자 입력칸에 커서가 있을 때는 공통 키가 꺼집니다(1~5를 쳐도 카드로 넘어가지 않음). Enter로 확정, Esc로 취소.
- 마우스를 3초 안 움직이면 커서가 숨고, 프레젠터 리모컨(PageUp/PageDown)만으로도 단계를 넘길 수 있습니다.

### 시뮬레이터별 추가 키 (모두 패널 버튼으로도 됨)

| 시뮬레이터 | 키 |
|---|---|
| 포물선 | **G** 지구 g 9.8 ↔ 10 · **L** 눈금 자동 맞춤 · **B** 떨어뜨린 공 함께 보기 · **A** 속도·가속도 화살표 |

### 5-1. 포물선 운동과 역학적 에너지 (`projectile-energy`)

- **발견할 것** — 떨어지는 시간은 높이로만 정해진다 · 30°와 60°는 같은 거리, 45°가 가장 멀다 · 공기 저항이 없으면 질량과 무관 · 에너지 합은 일정 · 최고점에서 속도는 0이 아니고 가속도는 g.
- **수치 칸** — 처음 속력 v₀(0~30 m/s) · 던지는 각도 θ(0~90°) · 던지는 높이 h(0~45 m). **상황** — 어디에서 던질까(지구 9.8/10·달·화성), 떨어뜨린 공 함께 보기. **더 많은 설정** — 공기 저항(쇠공·탁구공), 질량. 공을 당겼다 놓아도 v₀·θ가 정해집니다.
- **실험 카드** — ① 수평으로 던지기(h 20 m·각도 0°) · ② 날아가는 동안 에너지(h 20 m·각도 30°) · ③ 30°와 60°(각도 30 → 60) · ④ 달에서 던지기(g: 지구 → 달, '지구에서라면' 점선 함께) · ⑤ 최고점에서 속도는?(최고점에서 멈춤).
- **예측** — 처음 들어오면 숫자 예측 "공은 어디쯤 떨어질까요?"가 뜹니다. 실행 전에는 던지는 방향과 앞부분 30%만 점선으로 보여 답이 새지 않습니다.
- **흐름** — ① 카드 ① 예측(던진 공과 떨어뜨린 공, 무엇이 먼저?) → 실행 → 동시 착지 확인(7분) → ② v₀만 10·15·20으로 바꿔 기록 3개 → 표의 '비행 시간' 열이 모두 같음(10분) → ③ 카드 ②로 에너지 막대가 변하지 않음을 보고, 섬광 점을 눌러 값 읽기(12분) → ④ 카드 ③ → 기록 → 60° → 기록 → 45°도 기록. 카드 ⑤ 최고점 정지(10분) → ⑤ 정리 질문 5개(계산형 1개: 모범 답 20 m)와 '흔한 오해 바로잡기' 카드(10분).

### 5-2. 이중 슬릿: 빛에서 전자 하나까지 (`double-slit-quantum`)

- **발견할 것** — Δy = λL ÷ d(λ·L에 비례, d에 반비례) · 전자를 하나씩 보내도 쌓이면 줄무늬 · 어느 슬릿을 지났는지 알 수 있게 장치를 두면 무늬가 사라짐('사람이 봐서'가 아니라 '정보가 남아서').
- **실험 고르기** — 처음에 [빛으로 줄무늬 재기] / [전자 하나씩 보내기] 중 하나를 고릅니다(허브의 '빛 실험·전자 실험' 링크로 바로 들어갈 수도 있음). 패널 위 '지금: ○○ [실험 고르기]'로 바꿉니다.
- **수치 칸** — 빛의 파장 λ(400~700 nm, 보라·초록·빨강 눈금) · 슬릿 간격 d(0.1~0.5 mm) · 스크린 거리 L(0.5~3 m). 전자 모드는 보내는 빠르기(1·20·1000 개/s)와 가속 전압(100~5000 V → λ를 pm로 표시).
- **측정** — 확대창에서 밝은 줄 가운데 두 곳을 누르고 사이 칸 수 n을 맞추면 한 칸 간격이 나옵니다(하단 띠에 ① 시작점 → ② 끝점 → ③ 칸 수 진행 표시, '측정 방법 ?' 버튼). 이론값은 기록한 뒤 [답 확인하기]로 열립니다.
- **실험 카드** — 빛: ① 밝은 줄 사이 재기 · ② 빨강과 파랑(λ 650 → 450) · ③ 슬릿 간격 2배(d 0.25 → 0.50) · ④ 스크린을 멀리(L 2.0 → 3.0 m) · ⑤ 한 슬릿만 열면? / 전자: ① 전자 하나씩(1개/s) · ② 광자 하나씩 · ③ 작은 구슬이면? · ④ 측정기를 켜면? · ⑤ 한 슬릿만 열면?
- **흐름** — ① 빛 모드 카드 ① 예측(밝은 줄은 1개·2개·여러 개?) → 실행 → 간격 재기 → 기록(8분) → ② 카드 ②·③·④로 한 변수씩 바꿔 기록 → 비교 체크리스트(기록 3개·λ만 바꿈·Δy ∝ λ) 채우기(12분) → ③ 전자 모드 카드 ③(구슬) 예측 → 두 띠 → 카드 ①로 점이 쌓여 줄무늬가 되는 과정(1 → 20 → 1000 개/s)(12분) → ④ 카드 ④ 측정기 끔/켬 기록 2개 비교(8분) → ⑤ 정리 질문(모드별 선택형 2 + 서술형 2, Q2는 L 2.0 → 1.0 m 계산)(10분).

### 5-3. 일차원 충돌과 운동량 보존 (`collision-momentum`)

- **발견할 것** — 튕기든 붙든 운동량 합은 같다 · 두 수레가 주고받는 힘은 늘 크기가 같다 · 충격량이 같아도 시간이 길면 최대 힘이 작다(에어백) · 붙으면 운동 에너지가 줄어든다(열·소리).
- **수치 칸** — 수레 A 질량 m₁ · 수레 B 질량 m₂(0.5~3 kg) · A 처음 속도 v₁(분리 장면은 포탄 속력 u). **상황** — 장면(충돌·분리·벽), 충돌 종류(튕기기·달라붙기·중간), 범퍼(딱딱·보통·푹신). **더 많은 설정** — v₂, 반발 계수 e, 질량 중심 시점. 수레를 끌었다 놓으면 그 빠르기가 처음 속도가 됩니다.
- **실험 화면** — 위는 트랙, 아래는 그래프 판(탭: 운동량 | 힘-시간 | 운동 에너지, 안 본 탭에 ● 점). 충돌 순간은 자동 슬로 모션.
- **실험 카드** — ① 같은 질량끼리 튕기면(속도 교환) · ② 달라붙으면(튕김 → 붙음) · ③ 트럭 vs 승용차(질량 3배·정면) · ④ 대포를 쏘면(분리 장면) · ⑤ 에어백은 무엇을 줄일까(벽 장면 · 범퍼).
- **흐름** — ① 카드 ③ 예측(트럭과 승용차, 누가 더 큰 힘?) → 실행 → 힘-시간 탭에서 두 곡선이 대칭(8분) → ② 카드 ① 기록 → 카드 ②(달라붙기) 기록 → 표의 'p 보존?·K 보존?' 열 비교, 운동 에너지 탭의 '손실(열·소리)' 빗금(12분) → ③ 질량만 1 → 3 kg 기록(8분) → ④ 카드 ④ 반동(합 0), 카드 ⑤ 범퍼 딱딱 → 푹신 기록 2개 — 힘-시간 넓이 같고 높이만 다름(12분) → ⑤ 비교 단계 '규칙 확인하기' O/X 표, 정리 질문 6개(계산형: 2 kg·+3 m/s 달라붙기 → +2 m/s)(10분).

### 5-4. 인공위성과 탈출 속도 (`orbit-gravity`)

- **발견할 것** — 위성은 계속 '떨어지는' 중(중력이 구심력) · 높을수록 느리게, 주기는 길게(T² ∝ r³) · 궤도 속력·주기는 위성 질량과 무관 · 탈출 속도는 천체마다 다름. 타원 궤도는 모양만 보여 줍니다.
- **실험 고르기** — ① 뉴턴의 대포 ② 원궤도 위성 ③ 케플러 자료. 처음 한 번 고르고 패널 위 '지금: ○○ [실험 고르기]'로 바꿉니다.
- **수치 칸** — 대포: 발사 속력 v₀(0~12 km/s, '지구를 돎 7.9 · 탈출 11.2' 눈금)와 '순서대로 바꿔 쏘기' 칩(4 · 6 · 7.9 · 10 · 11.2, 기록하면 ✓). 위성: 고도(400 · 2만 · 3만 6천 km 눈금), 질량. 케플러: 행성 a·T 입력.
- **실험 카드** — ① 뉴턴의 대포(v₀ 7.9 km/s) · ② ISS도 낙하 중(질량만 바꾸기) · ③ 정지궤도 위성(고도만 바꾸기) · ④ 행성 주기 규칙(행성 6개 자료) · ⑤ 3 km/s로 쏘면?(천체: 달).
- **흐름** — ① 대포 카드 ① 예측(7.9 km/s로 쏘면 떨어진다·돈다·날아간다?) → 4 → 6 → 7.9 → 10 → 11.2 순서로 쏘며 기록, '보는 범위'를 지구 전체·타원까지로(12분) → ② 카드 ⑤ 달 → 화성 → 지구에서 3 km/s(8분) → ③ 위성 카드 ② 질량 세 단계 기록 → 주기 모두 92.4분. 카드 ③ 고도 세 단계 → T²–r³ 그래프(12분) → ④ 케플러 카드 ④ 6행 입력 → T–a → T²–a³ 직선(10분) → ⑤ 정리 질문 8개(모드별), 오개념 '무중력·중력이 0' 바로잡기(8분).

### 5-5. 볼록렌즈로 상 만들기 (`convex-lens`)

- **발견할 것** — 세 광선 작도로 상의 위치 · 2F(f 의 2배 자리)에서 같은 크기 · f 안쪽이면 바로 선 허상(스크린에 안 맺힘) · 렌즈를 반 가려도 상은 온전하고 어두워질 뿐 · 물체 거리 = 상 거리인 곳의 반이 f. 결상 공식은 화면에 띄우지 않습니다.
- **수치 칸** — 초점거리 f(5~20 cm, 카드 ①은 숨김) · 물체 거리 s(3~50 cm, 화면의 [물체] 손잡이로도). **상황** — 빛의 길 보기(평행·초점·중심 광선 칩), 가림판, 물체 종류. **더 많은 설정** — 물체 높이, 스크린 위치, 심화 그림. 오른쪽 위 '스크린 정면' 창에 물체와 스크린에 맺힌 모습을 같은 배율로 보여 줍니다.
- **실험 카드** — ① 초점거리 찾기(추천, 먼 풍경 · f 숨김) · ② 물체를 2F에 두기(s 30 → 20 cm) · ③ 프로젝터 크게(s 30 → 15 cm) · ④ 돋보기로 보기(s 30 → 5 cm) · ⑤ 렌즈 반 가리기.
- **흐름** — ① 카드 ⑤ 예측(렌즈를 반쯤 가리면 상도 반쪽?) → 정면 창에서 밝기만 줄어듦 확인(8분) → ② 카드 ①(f 숨김): 물체 40 → 30 → 20 → 15 → 12 cm, [스크린]을 끌어 '선명!'마다 기록(15분) → ③ 비교 단계 '같은 거리 찾기' → 반 = f, 규칙 카드 빈칸 채우기(10분) → ④ 카드 ④ 스크린을 치우고 허상, 카드 ③ 프로젝터(10분) → ⑤ 정리 질문 4개('숨긴 f는 몇 cm?'는 답 확인하기로 공개)(7분).

## 7. 고치는 법 · 확인하는 법

- **문구·값** — 각 시뮬레이터 JS에서 `SK.setPresets([...])`(카드 이름·`changes`·바꿀 값·`predict` 질문·`answer`·`why`), `SK.help({how, concepts, terms})`(도움말), `SK.think({...})`(정리 질문), `SK.takeaway(fn)`(이번 실험 결과), `SK.guide({...})`(교사 수업 안내)의 따옴표 안 글자만 바꿉니다.
- **변수 범위·기본값** — `SK.addVar('values', { key, label, unit, min, max, step, value, ticks, apply })`. 핵심 2~3개만 `values`에, 나머지는 `more`에.
- **허브 카드 글** — `index.html`의 `SIMS` 배열. **색** — `shared/tokens.css`의 `--color-*`만.
- **규칙** — file:// 로 동작해야 하므로 ES module·fetch·CDN 금지. 크기는 `--u` 단위, 버튼은 66u 이상, 캔버스 글자 22u 이상, 토스트 28자 이내, 띠 문장 25자 안팎. 자세한 API와 R1·R2 체크리스트는 `docs/SIMKIT.md`.
- **확인** — `node --check shared/sim.js sims/*/*.js` 전부 통과. 화면은 `python tools/shot.py sims/<slug>/index.html out.png [동작…] [--size 1280x720]`로 찍어 콘솔 오류 0인지 봅니다. 공통 자동 검사는 `_review/R2/edu1/check.py`.
